# Architecture

## Responsibility

Guides English reading and pronunciation for Korean learners.

## Boundary

Explain sounds through Korean-accessible cues without pretending Korean spelling is an exact phonetic substitute.

The skill wiki records maintenance context. [SKILL.md](../SKILL.md) remains the executable instruction source and must not depend on an agent loading this wiki during an ordinary user request.

## Flow

Segment the expression, mark stress and linking, explain difficult sounds, then provide a practical reading sequence.

## Resources

- [`SKILL.md`](../SKILL.md): invocation boundary and runtime instructions.
- This skill is instruction-only; `SKILL.md` contains its complete runtime behavior.
