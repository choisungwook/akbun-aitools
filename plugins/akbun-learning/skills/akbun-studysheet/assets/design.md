# akbun 라이트 샌드위치 디자인 (학습지용)

akbun 라이트 샌드위치 스타일을 HTML 학습지에서 재현하기 위한 자기완결적 스펙이다. 색·타이포·그림 언어·캡션 규칙을 담는다. 이 파일만 읽고 스타일을 재현할 수 있어야 하므로 다른 skill을 참조하지 않는다.

## 구조

**다크(`#212022`) 표지가 흰 내용 페이지를 여는 구조다.** 표지는 다크 배경에 노란 세로 바 + 흰 제목(핵심 키워드만 노랑)이고, 내용 페이지는 흰 배경 + 검정 본문이다.

## 색

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 다크 배경 | `#212022` | 표지 |
| 라이트 배경 | `#FFFFFF` | 내용 페이지 전부 |
| 본문 | `#000000` | 텍스트·도형선 |
| 포인트 | `#FFC000` | 표지 세로 바, 표지 핵심 키워드, 다이어그램 주인공 |
| 문제/강조 | `#FF0000` | 빨간 화살표·✕·경고 텍스트 |
| 형광펜 | `#FFE066` | 본문 키워드 하이라이트 |
| 워크로드 채움 | `#FFF2CC` | pod·앱 등 워크로드 박스 |
| 리소스 채움 | `#E2EFDA` | service 등 인프라 리소스 박스 |
| 그룹 채움 | `#F2F2F2` | 묶음 영역 |
| 코드 패널 | 배경 `#1E1E1E`, 기본 `#D4D4D4`, 키 `#569CD6`, 문자열 `#CE9178` | VS Code Dark+ 스타일 코드 |

## 타이포그래피

- 본문은 나눔바른고딕(없으면 시스템 고딕), 코드는 Consolas.
- 내용 페이지 머리는 `N. 섹션명` 헤더 + 제목. 배지·필 모양 장식을 쓰지 않는다.
- 불릿 계층은 ■(메인) → -(서브). 순서는 ①②③ 서클 숫자.

## 강조 문법

- 노랑은 포인트(주인공·핵심 키워드), 빨강은 문제·에러·주목할 흐름.
- 본문 키워드는 노란 형광펜 또는 빨간 글씨. 한 장에 강조는 1~2곳이면 충분하다.

## 그림 언어 (라이트 다이어그램)

- 컴퍼넌트 박스: 흰 채움 + 검정 얇은 테두리 + 검정 라벨. 살짝 둥근 모서리.
- 채움 구분: 워크로드는 연노랑, 인프라 리소스는 연초록, 묶음 영역은 연회색.
- 주인공: 지금 설명하는 요소 하나만 노랑(`#FFC000`) 채움 + bold 라벨, 나머지는 흐리게.
- 논리 경계: 둥근 모서리 얇은 검정 테두리, 라벨은 경계 안쪽 왼쪽 위.
- 화살표: 데이터 흐름은 검정 실선 + 삼각 화살촉. 문제 지점·주목할 경로는 빨강.
- 순서 마커: ①②③ 서클 숫자를 라벨 앞이나 흐름 위에 단다.
- 읽는 방향: 왼쪽 → 오른쪽, 요청 → 응답.
- 같은 구도를 반복하며 장면을 진행한다. 새 그림을 그리지 말고 마커·강조·설명만 바꾼다.

## 캡션·스크린샷

- 그림·캡처 아래 `[ 설명 ]` 형식의 짧은 캡션을 달 수 있다. 가져온 자료에는 `[ 출처: ... ]`를 단다.
- 터미널·콘솔 캡처는 다크 테마 그대로, 필요한 부분만 잘라 넣는다. 봐야 할 줄에 빨간 화살표·밑줄·박스 중 하나를 딱 한 곳 단다.
