# akbun 라이트 디자인 (학습지용)

akbun 라이트 스타일을 HTML 학습지에서 재현하기 위한 자기완결적 스펙이다. 색·타이포·그림 언어·캡션 규칙을 담는다. 이 파일만 읽고 스타일을 재현할 수 있어야 하므로 다른 skill을 참조하지 않는다.

## 구조

**모든 페이지가 흰 배경 + 검정 본문 light theme다.** 첫 페이지의 제목·부제·도입 문구·구성은 주제에 맞게 정한다. 노란 세로 바와 형광펜은 사용할 수 있지만 고정 레이아웃이나 문구는 아니다. 내용 페이지도 번호가 이해를 도울 때만 `N. 섹션명`을 쓰며, 각 페이지의 역할에 맞는 헤더를 선택한다. 페이지는 프레젠테이션처럼 **연회색 배경 위 16:9 비율 흰 슬라이드**로 띄우고, 좁은 화면에서는 16:9를 풀고 세로로 읽는다.

하단 내비게이션은 창 모드에서 화면 아래에 고정된 바지만, **전체 화면에서는 macOS dock처럼 숨는다.** 포인터가 화면 아래로 내려오면 떠 있는 알약(둥근 모서리 + 그림자)으로 올라오고, 포인터가 벗어나면 다시 아래로 내려간다. 슬라이드가 화면 높이를 다 쓰게 하고 읽는 동안 시야를 비우기 위함이다.

## 색

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 다크 | `#212022` | 하단 내비게이션 버튼 |
| 라이트 배경 | `#FFFFFF` | 표지 포함 전 페이지 |
| 본문 | `#000000` | 텍스트·도형선 |
| 포인트 | `#FFC000` | 첫 페이지의 초점, 핵심 개념, 현재 설명 중인 요소 |
| 문제/강조 | `#FF0000` | 빨간 화살표·✕·경고 텍스트 |
| 형광펜 | `#FFE066` | 본문 키워드 하이라이트 |
| 주 요소 채움 | `#FFF2CC` | 현재 설명의 주 대상·능동 요소 |
| 보조 요소 채움 | `#E2EFDA` | 지원 구성요소·리소스·외부 대상 |
| 그룹 채움 | `#F2F2F2` | 묶음 영역 |
| 코드 패널 | 배경 `#1E1E1E`, 기본 `#D4D4D4`, 키 `#569CD6`, 문자열 `#CE9178` | VS Code Dark+ 스타일 코드 |

## 타이포그래피

- 본문은 나눔바른고딕(없으면 시스템 고딕), 코드는 Consolas.
- 페이지 머리는 필요에 따라 섹션명·질문·단계·제목 중 하나를 선택한다. 배지·필 모양 장식은 쓰지 않는다.
- 불릿 계층은 ■(메인) → -(서브). 순서는 ①②③ 서클 숫자.

## 강조 문법

- 노랑은 포인트(주인공·핵심 키워드), 빨강은 문제·에러·주목할 흐름.
- 본문 키워드는 노란 형광펜 또는 빨간 글씨. 한 장에 강조는 1~2곳이면 충분하다.

## 그림 언어 (라이트 다이어그램)

- 컴퍼넌트 박스: 흰 채움 + 검정 얇은 테두리 + 검정 라벨. 살짝 둥근 모서리.
- 채움 구분: 주 요소는 연노랑, 보조 요소는 연초록, 묶음 영역은 연회색. 주제의 의미가 다르면 범례를 새로 정한다.
- 주인공: 지금 설명하는 요소 하나만 노랑(`#FFC000`) 채움 + bold 라벨, 나머지는 흐리게.
- 논리 경계: 둥근 모서리 얇은 검정 테두리, 라벨은 경계 안쪽 왼쪽 위.
- 화살표: 데이터 흐름은 검정 실선 + 삼각 화살촉. 문제 지점·주목할 경로는 빨강.
- 순서 마커: ①②③ 서클 숫자를 라벨 앞이나 흐름 위에 단다.
- 읽는 방향: 왼쪽 → 오른쪽, 요청 → 응답.
- 같은 흐름을 단계별로 설명할 때는 구도를 유지하고 마커·강조·설명만 바꾼다. 다른 관계를 설명할 때는 더 적합한 구도를 선택한다.

## 캡션·스크린샷

- 그림·캡처 아래 `[ 설명 ]` 형식의 짧은 캡션을 달 수 있다. 가져온 자료에는 `[ 출처: ... ]`를 단다.
- 터미널·콘솔 캡처는 다크 테마 그대로, 필요한 부분만 잘라 넣는다. 봐야 할 줄에 빨간 화살표·밑줄·박스 중 하나를 딱 한 곳 단다.
