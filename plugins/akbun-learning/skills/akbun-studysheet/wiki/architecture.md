# Architecture

## Responsibility

Creates one interactive HTML quick-start study sheet for someone encountering a topic, document, codebase, or incident for the first time.

## Boundary

Teach through problem, principle, structural understanding, and verifiable hands-on work in fewer than twenty light-theme sections.

The skill wiki records maintenance context. [SKILL.md](../SKILL.md) remains the executable instruction source and must not depend on an agent loading this wiki during an ordinary user request.

## Flow

Extract the learning objective and prerequisites, design the concept sequence and hands-on checks, assemble the reusable HTML components, then validate the standalone sheet.

## Resources

- [`SKILL.md`](../SKILL.md): invocation boundary and runtime instructions.
- [`assets/`](../assets/): supporting resources retained outside the maintenance wiki.
