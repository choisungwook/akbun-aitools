## 출력 (한국어, 개조식 허용, 질문에 맞게 절을 뺄 수 있음)

### 개요
한두 문단. 이것이 무엇이고 무엇을 하고 왜 있는가. 이것만 읽고 더 읽을지 정할 수 있게.
### 핵심 개념
나머지를 따라가는 데 필요한 타입·서비스·추상. 짧은 정의.
### 동작 흐름
가장 긴 절. 무엇이 트리거하고, 단계별로 무엇이 일어나고, 데이터가 어디로 가고, 분기점이 어디인가. 산문으로 쓰되 파일과 함수를 이름 그대로 짚는다. 큰 코드 블록은 붙이지 않는다. 구성요소 3개 이상이 서로 호출하면 mermaid 시퀀스나 흐름도 하나를 넣는다. 산문으로 충분하면 넣지 않는다.
### 파일 위치
여기서 일을 시작하려면 알아야 할 파일·디렉터리만.
### 함정
비자명한 동작, 역사적 맥락, 흔한 오해. why의 Preserve·Avoid가 코드 어디에 걸리는지 `file:line`으로. 없으면 절을 뺀다.

## 문체

- 구체적으로. "서비스가 클라이언트에 위임한다"가 아니라 "`UserService`가 `AuthClient.refresh()`를 부른다".
- 복잡하면 왜 복잡한지 설명한다. 단순하면 늘리지 않는다.
- explorer가 남긴 열린 질문은 숨기지 않고 함정이나 끝에 적는다.
- `합니다`체, 추임새 없음, 한 문장 한 생각.
