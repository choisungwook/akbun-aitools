# tech-blog

공부한 기술 하나를 원리와 실무 판단까지 설명하는 akbun 기술 블로그 글에 쓴다. 템플릿을 지정하지 않으면 이 템플릿을 쓴다.

## 글의 형식

- 모드: 설명. 실습이 있으면 그 절만 how-to
- 주제: 핵심 주제 하나. 둘 이상이면 글을 나눈다
- 문체: `합니다`체
- 매체: 블로그용 Markdown

## 골격

`<...>`는 입력으로 채운다. 입력에 재료가 없는 절은 만들지 않고 뺀다.

```markdown
# <제목: 다루는 기술과 요점>

<도입: 이 글이 답하는 질문과, 읽고 나면 무엇을 판단할 수 있는지>

## <요점 소제목: 왜 그렇게 동작하는가>

## <요점 소제목: 디폴트 값·설계가 무엇을 막으려 나왔는가>

## <실습: 목적과 결과 해석이 먼저인 how-to 절>

## <요점 소제목: 그래서 실무 판단이 어떻게 달라지는가>

## 더 공부할 것
```

## 문단 순서

- 도입은 배경 설명이 아니라 독자의 질문으로 시작한다.
- 원리 절은 일반적인 경우를 먼저, 예외를 뒤에 둔다.
- 실습 절은 원리 절 뒤에 둔다. 실습 안에서 원리를 다시 설명하지 않고 앞 절로 보낸다.
- 마지막 요점 절은 앞 절 요약이 아니라 실무 판단으로 끝낸다.
- `더 공부할 것`은 입력에 `확인 필요`나 열린 질문이 있을 때만 둔다.

## 점검 항목

- 소제목만 훑어도 원리에서 실무 판단까지 흐름이 이어지는가.
