# Architecture

## Responsibility

Turns source material into an akbun-style beginner layer using concise, structured Korean explanations.

## Boundary

Build the reader's model in the order big picture, parts, runtime sequence, and confusing points without pretending the layer is exhaustive.

The skill wiki records maintenance context. [SKILL.md](../SKILL.md) remains the executable instruction source and must not depend on an agent loading this wiki during an ordinary user request.

## Flow

Find the minimum mental model, order the components and sequence, isolate likely confusion, then write the compact beginner-oriented post.
