# AI Context

## 작업 맥락

`akbun-docs-review`는 기존 한국어 기술 문서의 교정에만 집중한다. 원문의 문체와 레이아웃, 코드는 유지하면서 언어와 표기를 다듬고, 근거가 충분한 사실 오류는 바로잡는다. 문서 구조와 스타일 변경은 다른 skill의 책임이다. 이전 이름인 `akbun-docs-reviewer`는 호환 이름으로 유지하지 않는다.

## 용어 정리

- 교정: 맞춤법·문법·어색한 표현·용어 표기를 바로잡고 문장을 읽기 쉽게 다듬는 작업이다.
- 기술 검증: 사실·수치·예제 동작을 확인해 근거가 충분한 오류는 수정하고, 불확실하거나 코드 수정이 필요한 오류는 별도 보고하는 작업이다.
- 레이아웃 보존: 헤더·문단·목록·이미지·코드 블록의 순서와 구조를 바꾸지 않는 것이다.
