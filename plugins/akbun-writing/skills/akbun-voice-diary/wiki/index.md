# akbun-voice-diary Wiki

This is the maintenance context the next agent reads before changing this skill. Runtime behavior remains in [SKILL.md](../SKILL.md).

## Purpose

Turns a rambling voice-chat account of the user's day into a fixed-format diary Markdown, saves it (local file by default, optionally Apple Notes or Google Docs), and schedules detected "things to study later" as Apple Calendar events on the coming weekend.
