같은 채널의 여러 영상은 하나의 제작 관점이 반복된 자료로 본다. 등장 횟수·조회수·구독 권유를 품질의 근거로 삼지 않는다. 광고를 포함한 시연에서는 편집 조작의 원리만 일반화하며 해당 제품·곡·채널의 사용을 권하지 않는다.

## 서로 다른 설명을 적용하는 방법

- 음악 먼저/나중: 음악의 감정 역할은 이야기 기획에서 정하고, 말·환경음을 진단할 때는 음악을 잠시 뮤트한다. 실제 배치 순서는 프로젝트에 맞춘다.
- 현실/창작: 풍경 기록은 실제 공간·행동을 우선한다. 화면 밖 소리도 공간상 타당하면 가능하다. 비유적·과장된 소리는 선택 이유와 검토 마커를 남기고 실제 녹음으로 기록하지 않는다.
- 많은 레이어/적은 레이어: 기능이 다른 레이어만 남긴다. 효과음 개수와 음색 종류 수를 합격 기준으로 만들지 않는다.
- 같은 key: 조성 정보는 후보를 줄일 뿐이다. 겹친 구간의 코드·멜로디·리듬과 실제 청감을 확인한다.
- 디자인/믹싱: 이 저장소에서는 같은 사운드 스킬이 설계와 믹싱을 수행한다.

## Resolve·Epidemic Sound 연결 근거

- [Blackmagic Resolve 21.1 발표](https://www.blackmagicdesign.com/media/partial/release/20260908-03): 2026.9 AI Assistant 사용 맥락. 실제 기능은 연결 도구와 설치 버전으로 확인한다.
- 연결된 Resolve MCP가 제공한 21.1 `DaVinciResolveScript.pyi`: `Timeline.DuplicateTimeline`, `AddMarker`, `GetMarkers`, `GetUniqueId`, 클립의 `AudioVolume`·`AudioPan`·`AudioPitchSemiTones` 확인. 실행 때 `get_whats_new`와 API 문서를 다시 확인하며 이것만으로 시간별 자동화 API를 보장하지 않는다.
- [Epidemic Sound Resolve 플러그인](https://www.epidemicsound.com/plugins/davinci-resolve-studio/): Resolve 안에서 음악·효과음을 검색·활용하는 경로.
- [Epidemic Sound 공식 MCP 문서](https://developers.epidemicsound.com/docs/mcp/): 서버 `https://www.epidemicsound.com/a/mcp-service/mcp`. 연결별 실제 도구 목록과 인증·권한을 확인한다. 음악/SFX 검색·다운로드, 제공 스템과 음악 길이 조정의 가용성은 반환 스키마로 확인한다. Resolve 타임라인 편집 자체는 Resolve 도구의 역할이다.

원본 자막·메타데이터·ASR·다운로드 자료는 저장소에 넣지 않는다. 이 분석의 임시 경로는 사용자 `Downloads/sound-design-reference-20260927/`이며 수동 정리 대상이다. 이 파일은 그 폴더 없이도 원칙과 원본 영상 탐색 지점을 찾을 수 있도록 유지한다.
