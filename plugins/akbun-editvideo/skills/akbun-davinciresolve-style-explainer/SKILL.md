# akbun-davinciresolve-style-explainer

공부·경험·기술 가이드를 목소리로 설명하는 영상의 편집 규칙이다. 화자는 얼굴을 내지 않는다. 본편은 차분한 바탕이고, 정보는 본편 위의 카드·글자·화면 녹화가 나른다. 무엇을 보여 줄지보다 **언제 무엇이 바뀌는지**가 이 스타일의 핵심이다.

수치는 참고 영상 2개(공부·경험 공유, 기술 가이드)를 분석한 시작점이다. 분석 범위와 근거는 [references/analysis.md](references/analysis.md)에 있다. 말의 이해·자료를 읽는 시간이 수치보다 먼저이며, 범위를 벗어나면 이유를 로그에 적는다. 기존 devtalk 스타일과의 차이: [davinciresolve-style-essay](../davinciresolve-style-essay/SKILL.md)는 전체 화면 카드로 주장을 세우고, 이 스타일은 본편을 유지한 채 그 위에 결과와 과정을 겹친다.

## 구조

| # | 비트 | 길이 | 화면 |
|---|---|---|---|
| 1 | 결과 먼저 | 5~40초 | 완성 결과만 빠르게 이어 붙인 몽타주(샷 0.3~1.7초) 또는 결과 카드 + 성과 수치 |
| 2 | 약속과 목차 | 10~20초 | 본편 + 2단 글자로 영상의 약속, 목차 3개를 한 줄씩 |
| 3 | 왜 필요한가(맥락) | 20~40초 | 본편 + 자료 카드, 필요하면 용어 정의 카드 |
| 4 | 단계 N (반복) | 단계당 40~120초 | 챕터 카드 → 화면 녹화·B-roll → 결과 카드 + 진행 표시 |
| 5 | 요약 | 10~15초 | 본편 아래쪽에 요약 카드 3장이 차례로 |
| 6 | 최종 결과 공개 | 10~30초 | 전후 비교 또는 결과 몽타주(샷 0.3~1.7초 10개 → 4초 1개) |
| 7 | 마무리와 다음 행동 | 10~30초 | 본편, 도입 샷으로 돌아가는 수미상관 선택 |

기본 길이는 5~8분이다. 단계가 늘어나면 단계를 줄이고 비트를 늘리지 않는다. 비트마다 Blue `CHAPTER` 마커를 둔다.

## 본편과 화면 비율

| 화면 | 시간 비율 | 규칙 |
|---|---|---|
| 본편만 | 35~45% | 고정 샷. 책상·작업 공간·손·모니터 뒤. 한쪽 절반을 비워 카드 자리로 둔다 |
| 본편 + 카드·글자 | 15~25% | 카드는 비워 둔 절반에 |
| 화면 녹화 | 20~30% | 아래 "화면 녹화" 규칙 |
| B-roll·결과 영상 | 5~15% | 결과·예시 |
| 전체 화면 그래픽 | 3~8% | 챕터·용어 정의·요약 |

얼굴 없는 본편은 참고 영상의 "말하는 사람 고정 샷"과 같은 역할을 한다. 정보 없이 호흡을 주는 바탕이다. 같은 공간을 두 각도(정면 와이드, 측면 클로즈업) 이상 찍어 두면 컷으로 오가며 지루함을 줄인다.

## 컷 리듬

| 지표 | 기준 | 허용 범위 |
|---|---|---|
| 샷 길이 중앙값(본문) | 4.5초 | 3.5~5.5초 |
| 첫 40초(결과 몽타주를 쓸 때) | 샷 중앙값 0.6초 | 0.3~1.7초 |
| 본편만 계속 | 16초 이하 | 넘으면 카드·글자·각도 전환 |
| 화면 녹화 한 구간 | 6초 전후 | 타이핑·스크롤이 있으면 30초까지 |
| 반복 절차 | 두 번째부터 2~4초 | 처음 한 번만 전부 보여 준다 |

전환은 컷이다. 긴 화면 녹화로 들어갈 때만 11프레임(0.45초) 디졸브를 쓴다.

## 움직임

- 본편은 고정이다. 이유 없는 느린 확대를 넣지 않는다.
- 카드가 들어올 때 본편을 6프레임 ease-out으로 100% → 115~125% 스냅 확대하거나, 컷 직후 135% → 110%로 가라앉힌다. 한 순간에 움직임은 하나만.
- 결과 카드는 컷 1~2프레임 뒤 5~6프레임 페이드로 들어온다. 크기 변화·튕김을 주지 않는다. 다음 컷에서 사라진다.
- 진행 표시(단계 완료 배지)만 튕김을 준다. 6프레임 pop, 120%까지 넘쳤다 돌아옴.
- 요약 카드의 상태 전환은 0.5초 ease-in-out 슬라이드.

## 오버레이

값은 [akbun-davinciresolve-overlay](../akbun-davinciresolve-overlay/SKILL.md)의 옵션 그대로다(x·y는 중심, 0~1).

| 요소 | 위치·크기 | 등장 | 유지 |
|---|---|---|---|
| 결과 카드(옆) | 폭 0.40, 중심 x 0.25(또는 0.75), y 0.5, `--radius 0.03` | `--in fade --in-frames 6` | 중앙값 5초(1~13초) |
| 결과 카드(가운데) | 폭 0.57, 중심 0.5, 0.5. 본편은 흐리게 | fade 5프레임 | 3~4초 |
| 세로 카드 2장 | 각 폭 0.22, 중심 x 0.2와 0.8 | fade 또는 `slide-up` 8프레임 | 5~7초 |
| 진행 배지 | 폭 0.12, 중심 x 0.87, y 0.86 | `--in pop --overshoot 0.2 --in-frames 6` | 3.6~4초, 단계 완료마다 1회 |
| 성과 수치 | 오른쪽 위, 키워드 글자 | 타이핑 | 3~5초 |
| 주석 + 화살표 | 카드 옆 빈 공간 | 타이핑 | 카드와 함께 |
| 입력한 문장 | 본편의 빈 절반에 주석 글자로 옮겨 적음 | 말에 맞춰 타이핑 | 말하는 동안 |
| 동그란 PiP | 화면 녹화 위 오른쪽 아래, 폭 0.16, `--radius 1` | fade | 화면 녹화 구간 |

- 한 화면의 카드는 2장까지. 첫 시도와 개선 결과는 같은 자리에서 카드를 바꿔 보여 준다.
- 대사 자막은 쓰지 않는 것이 기본이다. 짧은 단어 자막(2~6단어)을 쓸 때는 영상 전체에 일관되게 쓴다.

## 화면 녹화

- 전체 화면은 1초 안쪽만 보여 방향을 잡고, 1.25초 ease-in-out으로 1.65배까지 입력창·버튼으로 들어간다(`overlay.py push --to 1.65`는 클립 전체에 걸리므로 녹화 클립을 확대 구간 길이로 잘라 쓴다).
- 작은 UI는 3~4배로 잘라 보여 준다. 영역 사이 이동은 5~6프레임 빠른 이동 + 모션 블러.
- 커서는 녹화할 때 크게 한다. 실행 버튼을 누르는 순간에서 컷하고, 결과는 녹화 안이 아니라 본편 위 결과 카드로 보여 준다.
- 작은 글자가 가득한 화면을 확대·강조 없이 8초 넘게 두지 않는다.

## 전체 화면 그래픽

| 종류 | 구성 | 길이 |
|---|---|---|
| 챕터 카드 | 그 단계의 결과 이미지·풍경 전체 화면 + 왼쪽 아래(x 0.04~0.21, y 0.23~0.31) 굵은 `STEP N` + 부제 | 3~4초 |
| 챕터 요약 | 단색 배경, 세리프 문장이 단어 단위로 올라옴(단어당 약 2.5프레임), 점 3개 이하 | 6~8초 |
| 용어 정의 | 흐린 전체 화면 스틸 + 세리프 `용어 / 품사 / "정의"` | 4~6초 |
| 전후 비교 | 흰색 또는 어두운 단색 배경에 두세 장 나란히 | 4~6초 |

## 소리

사운드 배치의 실행 기준은 [davinciresolve-sfx-epidemicsound](../davinciresolve-sfx-epidemicsound/SKILL.md)다. 이 스타일의 출발점:

- 효과음은 분당 2~4개. 컷마다 넣지 않는다(참고 영상의 컷과 소리 onset 일치율은 우연 수준).
- 챕터 경계: 약 3초 전에 음악의 저역·드럼을 빼고, 챕터 카드 컷 0.1초 뒤 큰 소리 1개.
- 결과 공개: 짧은 shimmer·whoosh 1개. 진행 배지: 작은 pop 1개.
- 소리의 어택은 그래픽 시작 0~4프레임 뒤에 둔다.
- 핵심 주장·주의·요약 6~17초 동안 음악의 저역을 빼고, 시연·몽타주에서 되돌린다. 따라 하는 단계 구간은 음악을 가장 낮게 둔다.

## 하지 않는 것

- 얼굴이 보이는 화면, 참고 영상의 문구·로고·화면 구성의 복제
- 말하지 않은 수치·결과를 카드에 넣는 것, 실제로 만들지 않은 결과를 결과 몽타주에 넣는 것
- 본편의 계속되는 느린 확대, 모든 컷의 효과음
- 작은 글자 화면을 확대 없이 오래 두는 것
