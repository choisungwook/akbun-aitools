- 소리는 들을 수 없어 스펙트로그램·onset·대역 에너지로 추정했다. 효과음 종류는 추정이다.
- 배율·모서리·위치는 1280×720 프레임에서 읽어 ±10% 오차가 있다.
- 10·20초 간격 구간에서는 등장 프레임 수와 소리 위치를 모른다. 그 구간의 규칙은 배치와 구성만 채택했다.
- 두 영상은 같은 채널이다. 하나의 제작 관점으로 본다.

경험 공유 360~720초 정밀 분석:

- 시간 비율: 본편만 40%, 본편 + 오버레이 20%, 화면 녹화 29%, B-roll 7%, 전체 화면 그래픽 4%.
- 결과 카드: 폭 39~41%, 왼쪽 여백 3.5~5%, 모서리 폭의 약 1%, 5~6프레임 페이드, 유지 중앙값 5.3초.
- 진행 배지: 폭 12% × 높이 9%, 6프레임 pop, 120% 넘침, 3.6~4.0초, 7회.
- 화면 녹화: 전체 화면 1초 미만 → 1.25초 ease-in-out으로 약 1.65배. 작은 UI는 3~4배, 5~6프레임 이동.
- 반복 절차: 처음 28초 → 두 번째 3.4초, 세 번째 1.8초.
- 본편 스냅 확대 6프레임 ease-out 약 100→125%, 컷 뒤 약 135→110%. 느린 확대 없음.
- 오버레이 등장의 59%, 컷의 42%에 onset. 소리는 그래픽 시작 0~4프레임 뒤.
- 음악 저역이 6~17초 빠지는 구간 6곳: 핵심 주장, 주의, 요약, 비용 확인.

## 구성

- 기술 가이드: 요청 받은 이유(댓글 카드) → 촬영 원본 → 참고 자료 → 단계별 도구 화면 → 첫 시도와 개선 → 결과 공개(세로 카드 + 양옆 두 단어) → 3분할 전후 비교 → 마무리. 도구 화면 위에 동그란 PiP, 입력한 문장을 본편 빈 공간에 옮겨 적기, 용어 정의 카드 2회. 따라 하는 단계(218~332초)에서 음악 저역이 가장 낮다.
- 경험 공유: 결과 몽타주 40초 → 성과 수치 → 단계별 챕터 카드와 요약 → 결과 카드와 진행 배지 반복 → 결과 몽타주(920~960초 컷 28개) → 행동 유도.

## 채택하지 않은 것

- 도구·서비스 이름과 화면, 협찬으로 보이는 브랜드 화면, 채널 홍보
- 얼굴이 보이는 본편. 얼굴 없는 본편과 두 번째 각도로 바꿨다
- 확대 없이 작은 글자 화면을 13초 둔 구간

원본 영상·프레임·전사는 저장소에 넣지 않는다. 분석 폴더는 사용자 `Downloads/editvideo-style-refs/`이고 수동 정리 대상이다.
