# davinciresolve-audio-delivery

오디오 믹싱과 최종 출력을 맡는다. 현장음을 살리고 효과음과 음악은 그 뒤에 두는 것이 기준이다. 렌더 결과는 파일을 직접 검사해 확인하고, "렌더 완료"만으로 끝내지 않는다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 클립은 파일명 + 시작 타임코드, 대표 클립 선적용, 작업 로그)을 따른다. 게인·페이드·덕킹은 API가 없으므로 Fairlight 화면 조작이나 절차서로 하고, 렌더는 API로 한다.

## 오디오 트랙

트랙 레벨은 절대값이 아니라 현장음(A1) 기준 상대값이다. 최종 라우드니스는 마스터에서 맞춘다.

| 트랙 | 이름 | 내용 | A1 대비 레벨 |
|---|---|---|---|
| A1 | `LOCATION` | 촬영된 현장음 | 0 dB(기준) |
| A2 | `AMBIENCE` | 자연 환경 효과음(숲, 새, 바람, 비, 파도) | -12 dB |
| A3 | `SFX` | 장면별 효과음(조리, 발걸음, 문 소리) | -6 dB |
| A4 | `MUSIC` | 배경음악(Epidemic Sound) | -8 dB, 현장음 없는 구간 -2 dB |

트랙이 없으면 이 순서·이름으로 만든다. 이미 있는 트랙은 내용을 먼저 듣고 확인한 뒤 맞는 이름을 붙인다. 원본 A2에 두 번째 카메라 현장음이 있으면 `LOCATION_2`로 두고 A1과 같은 규칙을 적용한다. 내용을 모르는 트랙의 이름을 바꾸지 않는다.

## 믹싱

- 원래 현장음을 완전히 제거하지 않고 효과음과 섞는다. 현장음이 쓸 수 없을 만큼 나쁜 클립(바람 소리 클리핑 등)만 A1을 -18 dB까지 낮추고 A2로 대체하며, 로그에 이유를 적는다.
- 숲, 새, 비, 조리 소리 등 장면에 맞는 효과음을 쓴다. 장면에 없는 소리(도시 장면에 새소리)는 넣지 않는다.
- 효과음은 영상보다 먼저 눈에 띄지 않게 조절한다. A2·A3가 A1보다 크면 안 된다.
- 장면 전환에는 짧은 Constant Power 오디오 전환(12~24프레임)을 쓴다. 컷마다 현장음이 뚝 끊기지 않게 한다.
- BGM은 현장음을 가리지 않게 낮춘다. 현장음이 있는 구간은 A4를 A1보다 6 dB 이상 낮게 두고, 곡 전환 시 2초 이상 크로스페이드로 급격한 음량 변화를 막는다.
- 마스터 버스에서 통합 라우드니스 -14 LUFS(YouTube 정규화 기준)로 정규화하고 True Peak 리미터를 -1 dBTP로 건다. 트랙 상대 레벨을 지키면서 마스터 게인으로 목표에 맞춘다.
- 같은 장면 안 인접 클립의 음량 차이는 6 dB 이내로 둔다. 장면 전환(조용한 골목 → 드론쇼 함성)은 예외이며 로그에 "장면 전환"이라고 적는다.
- 라우드니스는 Fairlight 미터로 읽거나, 렌더 파일에 아래 명령을 돌려 `I`(통합)와 `Peak`를 읽는다.

```bash
ffmpeg -i "<렌더 파일>" -af ebur128=peak=true -f null - 2>&1 | tail -12
```

- 사용한 Epidemic Sound 곡명과 아티스트, 사용 구간을 작업 로그에 기록한다. 곡 정보를 모르면 `확인 필요`로 남기고 업로드 설명에 넣지 않는다.

## 컷 변경 반영

`davinciresolve-cut-travelflow`가 넘긴 바뀐 구간 목록(`파일명 | 이전 시작 TC | 새 시작 TC | 길이 변화(프레임)`)을 받으면 아래를 한다.

1. A1은 영상 클립에 링크돼 있으므로 함께 움직였는지 확인만 한다.
2. A2·A3·A4 클립은 영상과 링크되지 않으므로 이전 시작 TC 기준 상대 위치를 새 시작 TC로 옮긴다. 길이가 줄어든 클립에 걸린 효과음은 끝을 잘라 맞춘다.
3. 옮긴 뒤 클립 경계의 Constant Power 전환이 남아 있는지 확인하고 없으면 다시 건다.
4. 결과를 `8. 오디오` 표에 "재배치" 비고와 함께 적는다.

## 출력

렌더 전 사용 가능한 포맷·코덱을 확인한다. Resolve 무료판은 Windows·Linux에서 H.265 인코딩이 없고 Linux 무료판은 AAC가 없다.

```bash
python3 -c "import DaVinciResolveScript as dvr; p = dvr.scriptapp('Resolve').GetProjectManager().GetCurrentProject(); print(p.GetRenderFormats()); print(p.GetRenderCodecs('mp4'))"
```

| 항목 | 값 | 없을 때 |
|---|---|---|
| 해상도 | 3840×2160 | - |
| 프레임레이트 | 타임라인 프레임레이트(`davinciresolve-video-editor` 1단계에서 확정) | - |
| 비디오 코덱 | H.264(기본) 또는 H.265(사용자 지정) | H.265 없으면 H.264로 바꾸고 로그에 적음 |
| 비트레이트 | 30fps 이하: H.264 45 Mbps, H.265 30 Mbps. 60fps: H.264 68 Mbps, H.265 45 Mbps(YouTube 4K 권장) | - |
| 오디오 | AAC, 48 kHz, 320 kbps, 스테레오 | AAC 없으면 Linear PCM으로 렌더한 뒤 `ffmpeg -c:v copy -c:a aac -b:a 320k`로 변환하고 로그에 적음 |
| 파일명 | `<작업 타임라인 이름>_youtube4k.mp4` | - |
| 저장 위치 | `<출력 폴더>/render/` | 같은 이름 파일이 있으면 덮어쓰지 않고 사용자에게 알린다 |

렌더 후 파일을 검사한다. Resolve가 없어도 돌릴 수 있게 `ffprobe`를 쓴다.

```bash
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate,channels:format=duration -of default=noprint_wrappers=1 "<렌더 파일>"
```

| 항목 | 통과 기준 |
|---|---|
| 해상도 | 3840×2160 |
| 프레임레이트 | 타임라인과 동일 |
| 길이 | `duration`(초) × 타임라인 프레임레이트를 반올림한 프레임 수가 타임라인 프레임 수와 1프레임 이내 |
| 오디오 스트림 | AAC 스트림 1개, 48 kHz, 2채널 |
| 라우드니스 | 통합 -14 LUFS ±1, True Peak -1 dBTP 이하 |
| 재생 | 처음·중간·끝 프레임을 추출해 검은 프레임이 아님 |

하나라도 실패하면 렌더 설정을 고쳐 다시 렌더하고, 실패 항목과 원인을 로그에 적는다. 같은 항목이 2번 연속 실패하면 멈추고 사용자에게 알린다.

## YouTube 업로드

- 업로드는 사용자가 요청할 때만 하고, 실행 전 제목·공개 상태를 보여주고 확인을 받는다.
- 기본 공개 상태는 비공개(Private)로 설정한다. 사용자가 바꾸라고 하기 전에는 공개·일부 공개로 올리지 않는다.
- 제목, 설명, 챕터(`davinciresolve-subtitle-travelnote`의 챕터 목록), 장비(iPhone, Insta360 Luna Ultra), 음악 출처(Epidemic Sound 곡명·아티스트), 썸네일을 함께 적용한다. 썸네일은 사용자가 준 파일만 쓴다.
- 설명란 초안을 작업 로그에 남긴다.

## 작업 로그

작업 로그 `8. 오디오` 절과 `검증` 절에 아래를 채운다.

```markdown
| 구간(시작 TC~종료 TC) | A1 현장음 | A2 환경음 | A3 효과음 | A4 음악(곡명 - 아티스트) | 전환 | 비고 |
|---|---|---|---|---|---|---|
| 00:00:00:00~00:01:20:00 | 0 dB | 시장 웅성거림 -12 | 조리 소리 -6 | Morning Walk - Example Artist, -8 | 컷 12프레임 CP | |
| 00:01:20:00~00:03:40:00 | 0 dB | 없음 | 없음 | Night Lights - Example Artist, -8 | 곡 크로스페이드 2초 | 장면 전환, 6 dB 예외 |

마스터: 게인 +3 dB, 리미터 -1 dBTP → 통합 -14.2 LUFS, True Peak -1.0 dBTP
렌더 파일: <출력 폴더>/render/travel_edit_20250901_1030_youtube4k.mp4
ffprobe: 3840x2160, 30000/1001, 754.567초(22,614프레임, 타임라인 22,614) , aac 48000 Hz 2ch → 통과
```

## 하지 않는 것

- 현장음 전체 제거
- 장면에 맞지 않는 효과음
- 타임라인 프레임레이트 변경, 4K 미만 출력
- 렌더 파일 검사 없이 완료 보고
- 사용자 확인 없는 업로드, 비공개 아닌 기본 공개 상태
- 출처를 모르는 음악 사용
- 내용을 모르는 기존 트랙 이름 변경
