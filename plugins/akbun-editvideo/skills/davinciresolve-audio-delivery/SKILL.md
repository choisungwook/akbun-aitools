# davinciresolve-audio-delivery

오디오 믹싱과 최종 출력을 맡는다. 현장음을 살리고 효과음과 음악은 그 뒤에 두는 것이 기준이다. 렌더 결과는 파일을 직접 검사해 확인하고, "렌더 완료"만으로 끝내지 않는다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 클립은 파일명 + 시작 타임코드, 대표 클립 선적용, 작업 로그)을 따른다.

## 오디오 트랙

| 트랙 | 이름 | 내용 | 기본 레벨(피크) |
|---|---|---|---|
| A1 | `LOCATION` | 촬영된 현장음 | -12 dBFS |
| A2 | `AMBIENCE` | 자연 환경 효과음(숲, 새, 바람, 비, 파도) | -24 dBFS |
| A3 | `SFX` | 장면별 효과음(조리, 발걸음, 문 소리) | -18 dBFS |
| A4 | `MUSIC` | 배경음악(Epidemic Sound) | -20 dBFS, 현장음 없는 구간 -14 dBFS |

트랙이 없으면 이 순서·이름으로 만든다. 이미 있으면 이름만 맞추고 순서는 바꾸지 않는다.

## 믹싱

- 원래 현장음을 완전히 제거하지 않고 효과음과 섞는다. 현장음이 쓸 수 없을 만큼 나쁜 클립(바람 소리 클리핑 등)만 A1을 -30 dBFS까지 낮추고 A2로 대체하며, 로그에 이유를 적는다.
- 숲, 새, 비, 조리 소리 등 장면에 맞는 효과음을 쓴다. 장면에 없는 소리(도시 장면에 새소리)는 넣지 않는다.
- 효과음은 영상보다 먼저 눈에 띄지 않게 조절한다. A2·A3가 A1보다 크면 안 된다.
- 장면 전환에는 짧은 Constant Power 오디오 전환(12~24프레임)을 쓴다. 컷마다 현장음이 뚝 끊기지 않게 한다.
- BGM은 현장음을 가리지 않게 낮춘다. 현장음이 있는 구간은 A4를 A1보다 6 dB 이상 낮게 두고, 곡 전환 시 2초 이상 크로스페이드로 급격한 음량 변화를 막는다.
- 전체 라우드니스 목표는 -14 LUFS(YouTube 정규화 기준), True Peak -1 dBTP 이하.
- 사용한 Epidemic Sound 곡명과 아티스트, 사용 구간을 작업 로그에 기록한다. 곡 정보를 모르면 `확인 필요`로 남기고 업로드 설명에 넣지 않는다.

## 출력

렌더 설정이다. 타임라인 프레임레이트는 바꾸지 않는다.

| 항목 | 값 |
|---|---|
| 해상도 | 3840×2160 |
| 프레임레이트 | 원본 타임라인 프레임레이트 유지 |
| 코덱 | H.264 또는 H.265(사용자가 지정하지 않으면 H.264) |
| 비트레이트 | H.264 45 Mbps 이상, H.265 30 Mbps 이상(YouTube 4K 권장) |
| 오디오 | AAC, 48 kHz, 320 kbps, 스테레오 |
| 파일명 | `<작업 타임라인 이름>_youtube4k.mp4` |
| 저장 위치 | 프로젝트 폴더 `render/`. 같은 이름 파일이 있으면 덮어쓰지 않고 사용자에게 알린다 |

렌더 후 파일을 검사한다. Resolve가 없어도 돌릴 수 있게 `ffprobe`를 쓴다.

```bash
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate,channels:format=duration -of default=noprint_wrappers=1 "<렌더 파일>"
```

| 항목 | 통과 기준 |
|---|---|
| 해상도 | 3840×2160 |
| 프레임레이트 | 타임라인과 동일 |
| 길이 | 타임라인 길이와 1프레임 이내 |
| 오디오 스트림 | AAC 스트림 1개, 48 kHz, 2채널 |
| 재생 | 처음·중간·끝 프레임을 추출해 검은 프레임이 아님 |

하나라도 실패하면 렌더 설정을 고쳐 다시 렌더하고, 실패 항목과 원인을 로그에 적는다.

## YouTube 업로드

- 업로드는 사용자가 요청할 때만 하고, 실행 전 제목·공개 상태를 보여주고 확인을 받는다.
- 기본 공개 상태는 비공개(Private)로 설정한다. 사용자가 바꾸라고 하기 전에는 공개·일부 공개로 올리지 않는다.
- 제목, 설명, 챕터(`davinciresolve-subtitle-travelnote`의 챕터 목록), 장비(iPhone, Insta360 Luna Ultra), 음악 출처(Epidemic Sound 곡명·아티스트), 썸네일을 함께 적용한다. 썸네일은 사용자가 준 파일만 쓴다.
- 설명란 초안을 작업 로그에 남긴다.

## 작업 로그

작업 로그 `8. 오디오` 절과 `검증` 절에 아래를 채운다.

```markdown
| 구간(시작 TC~종료 TC) | A1 현장음 | A2 환경음 | A3 효과음 | A4 음악(곡명 - 아티스트) | 전환 |
|---|---|---|---|---|---|
| 00:00:00:00~00:01:20:00 | -12 dBFS | 시장 웅성거림 -24 | 조리 소리 -18 | Morning Walk - Example Artist, -20 | 컷 12프레임 CP |

라우드니스: -14.2 LUFS, True Peak -1.3 dBTP
렌더 파일: render/travel_edit_20250901_youtube4k.mp4
ffprobe: 3840x2160, 30000/1001, 00:12:34.567, aac 48000 Hz 2ch → 통과
```

## 하지 않는 것

- 현장음 전체 제거
- 장면에 맞지 않는 효과음
- 타임라인 프레임레이트 변경, 4K 미만 출력
- 렌더 파일 검사 없이 완료 보고
- 사용자 확인 없는 업로드, 비공개 아닌 기본 공개 상태
- 출처를 모르는 음악 사용
