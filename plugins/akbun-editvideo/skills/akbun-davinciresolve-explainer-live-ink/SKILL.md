# akbun-davinciresolve-explainer-live-ink

## 목적

계산 과정·공식·숫자가 바뀌는 순서를 손으로 적으며 설명하는 얼굴 없는 설명 영상을 만든다. 결과물은 Resolve에서 고칠 수 있는 타임라인이다. 장면마다 Fusion 클립 하나이고, 글자·써지는 시점·보이기·위치를 Edit 페이지 Inspector에서 바꾼다.

## 범위

- 사용자가 직접 호출할 때 실행한다.
- **스타일 원본**: 색·글꼴·펜 선·써지기 길이·펜 옮기기·시각 맞추기는 [akbun-draw-live-ink의 "스타일"](../../../akbun-draw/skills/akbun-draw-live-ink/SKILL.md#스타일)이 원본이다. 이 문서는 Fusion으로 옮기는 데 필요한 값만 옮겨 적는다. 어긋나면 draw skill을 따른다. Fusion 때문에 일부러 다르게 하는 것은 셋뿐이다.
  - 밑줄은 곡선이 아니라 직선이고, 기울기 0.3°로 수평을 살짝 벗어난다.
  - 동그라미는 쓰지 않는다. 강조는 밑줄과 이름표 화살표로 한다.
  - 화살표 머리는 그려지지 않고 몸통이 끝나는 프레임에 한 번에 보인다.
- **클립 구조**: [공통 "Resolve 구현"](../akbun-davinciresolve-explainer/references/resolve-core.md#resolve-구현)을 따른다. Fusion 타이틀 + Template 매크로, `Timing` 노드, 표현식 애니메이션, 제너레이터 길이 조정, Inspector 설계(글자마다 "보이기", 빌드마다 "써지는 시점(초)"·"위치 이동"), 마커 API, 성능 규칙이 여기에 포함된다. 공통 구현의 "사실 확인"과 "민감 정보 규칙"도 그대로 적용한다.
- **대신하는 것**: 공통 구현의 "내레이션 규칙"과 크로스 디졸브. 무엇을 어디에 몇 개 쓸지는 장면이 설명하는 관계가 정한다.
- 렌더된 MP4를 장면 대신 올리지 않는다. Resolve 밖에서 렌더한 영상이 필요하면 draw skill을 쓴다.
- 녹음 정리는 [akbun-davinciresolve-narration-cleanup](../akbun-davinciresolve-narration-cleanup/SKILL.md)을 부른다.

## 캔버스와 좌표

- 1920×1080이 기본이고, 쇼츠는 1080×1920 타임라인이다. px 값은 둘 다 그대로 쓴다. 글자와 선은 네 변에서 96px 안쪽에 둔다.
- fps는 대상 타임라인 값이고, 기준이 없으면 30이다. 표현식의 `fps`에는 소수까지 그대로 넣는다(예: 29.97).
- 좌표는 공통 구현의 "좌표와 단위"를 따르되 화면 폭 W, 높이 H를 쓴다. 가로 화면은 W = 1920, 세로 화면은 W = 1080이다.
  - 도형(sRectangle): X = (px − W/2) ÷ W, Y = (H/2 − py) ÷ W, 크기·선 굵기 = px ÷ W
  - Text+: Center = (px ÷ W, 1 − py ÷ H), Size = px ÷ W
  - RectangleMask: Center = (px ÷ W, 1 − py ÷ H), Width = px ÷ W, Height = px ÷ H(공통 구현의 "RectangleMask의 Height는 세로 기준". 대표 장면에서 마스크 높이가 글자 크기와 같은지 재서 확인한다)
- 모든 장면의 배경은 Background 노드 하나이고, 색은 BOARD(`#0C0C07`)다. 장면이 바뀌어도 배경이 같아서 하드 컷이 빈 판으로 넘어가는 것처럼 보인다.
- 화면 글자는 장면 안의 손글씨뿐이다. 별도 자막 트랙은 사용자가 요청할 때만 넣는다. 넣으면 Inspector → Track 탭에서 Font `Pretendard` Medium, 흰색으로 하고 배경·외곽선을 끈다(API로 바꿀 수 없다).

## Fusion 매핑

빌드 하나(글자 한 줄, 선 하나, 화살표 하나)는 노드 묶음 하나 → `레이어_목록` MultiMerge 레이어 1개다. 노드 이름 규칙(한글 종류 접두사, 밑줄)은 공통 구현를 따르고, 다음 접두사를 더한다: 글씨_, 펜_, 밑줄_, 화살표_.

| 빌드 | Fusion 구성 |
|---|---|
| 글자 한 줄 | Text+ 하나(Font `Nanum Pen` Style `Regular`, 왼쪽 정렬 `HorizontalLeftCenterRight = -1`, `VerticalTopCenterBottom = 0`, 크기·글자 간격은 draw skill 글꼴 표) + 그 Text+의 EffectMask에 RectangleMask `펜_…` 하나. 마스크 높이는 글자 크기 × 1.0, 세로 중심은 baseline − 0.22 × 크기 |
| 밑줄 | sRectangle 하나(Solid 켬, 높이 = 선 굵기, Angle 0.3) → sMerge → sRender |
| 화살표 | 몸통 sRectangle + 머리 sRectangle 두 개(길이 18px, 몸통 방향에서 ±35° 회전, 끝점에서 만남) → sMerge → sRender |

- Text+는 baseline이 아니라 글자 묶음 가운데에 Center가 놓인다. 대표 장면에서 한 줄을 렌더해 글자 baseline과 Center.Y의 차이(px)를 재고 글자 크기로 나눈 비율 k를 구한다. 모든 장면에서 Center.Y 위치(px)는 draw skill의 baseline `y` − k × 글자 크기다.
- 글자 폭 w는 draw skill의 식(Pillow `getlength` + 글자 간격 × 글자 수)으로 미리 계산해 `Timing`에 숫자로 둔다.
- Text+의 글자 간격은 `CharacterSpacing`이다. draw skill의 letter-spacing px를 그대로 넣지 말고, 대표 장면에서 한 줄을 렌더해 Pillow 폭 w와 화면 폭이 2% 안으로 맞을 때까지 값을 고르고, 그 값을 모든 장면에 쓴다.
- 색은 draw skill 색 표의 hex를 0~1 값으로 바꿔 넣는다(각 값 ÷ 255, 소수 넷째 자리에서 반올림). 도형 노드는 `Red`·`Green`·`Blue`, Text+는 `Red1`·`Green1`·`Blue1`에 넣는다.
- 그림자·블러·Glow·그라디언트 노드, Text+의 Write On, Blend 페이드를 쓰지 않는다. 글자는 마스크로만 드러난다.

## 모션

길이는 draw skill의 "써지기"를 따르고, 아래 식으로 옮긴다. `fps`는 숫자로 넣는다.

- `A` = `time - (comp.RenderStart + Timing.At{k} * fps)`
- `q(d)` = `min(1, max(0, A / (d * fps)))`

| 빌드 | 입력 | 식 |
|---|---|---|
| 글자 써지기 | `펜_…` RectangleMask의 Width·Center.X | p = `q(d)`. Width = `(w + 0.2 * 크기) * p / W`. Center.X = `(x - 0.1 * 크기 + (w + 0.2 * 크기) * p / 2) / W`. d는 한글 음절 수 × 0.3 + 그 밖 글자 수 × 0.2를 0.05초 단위로 올림, 최소 0.2 |
| 밑줄·화살표 몸통 그리기 | sRectangle의 Width·Translate | 공통 구현의 "실선 화살표 그리기" 식에 진행률 p = `q(d)`. d = 선 길이 ÷ 1500을 0.05초 단위로 올림, 최소 0.15 |
| 화살표 머리 | 머리 sRectangle 두 개의 Opacity | `iif(p < 1, 0, 1)`. p는 몸통의 진행률 |
| 보이기 끄기 | `Layer{n}.Blend` | `Timing.On{n}`. 글자 레이어에만 둔다 |

- 펜은 한 자루다. 빌드끼리 시간이 겹치지 않고, 다음 빌드는 앞 빌드 끝 + 0.15초 이상 뒤에 시작한다. 마지막 빌드 뒤 정지와 장면 길이는 draw skill의 "시각 맞추기"대로 정한다. 장면 하나는 90초 이하다.
- 장면 안에서 지우기·페이드·카메라 이동을 쓰지 않는다. 쓴 것은 장면 끝까지 남는다.
- 시점은 `Timing` 컨트롤로만 바꾼다. 키프레임을 쓰지 않는다.
- 장면 전환은 빈 판으로의 하드 컷이다. 크로스 디졸브를 넣지 않는다.

## 작업 흐름

1. **장면 표**: 대본을 장면으로 나눈다. 장면마다 다음을 적는다:
   - 빌드 순서대로 요소(글자·밑줄·화살표)와 색
   - 빌드별 신호 단어, 써지는 시점과 길이
   - 장면 길이

   신호 단어 고르는 법, 시각 계산, 겹칠 때 줄이거나 미루는 법, 장면 길이는 draw skill의 "시각 맞추기"를 따른다. 장면 표는 사용자에게 먼저 보여 주고 확인받는다.
2. **Resolve 준비**:
   - 다른 작업이 열어 둔 프로젝트·타임라인을 확인 없이 바꾸지 않는다.
   - 새 타임라인을 만든다. 트랙은 V1 장면, A1 내레이션, A2 BGM, A3 효과음이다.
   - Nanum Pen이 설치돼 있는지 `fc-list : family | grep -i "nanum pen"`으로 본다. 없으면 설치를 묻는다(배포처는 draw skill에 있다).
3. **대표 장면 하나**로 삽입·매크로·길이·Inspector·마스크 써지기·글자 간격·baseline 차이를 먼저 확인하고, 그다음 나머지를 만든다.
4. **장면 삽입과 빌드**:
   - 공통 구현의 "클립 길이 맞추기"로 장면을 차례로 끝에 붙인다.
   - "Fusion 매핑"대로 노드를 만들고 표현식을 건다.
   - Template 매크로로 감싸고, 공통 구현의 Inspector 설계에서 "등장 시점(초)" 이름을 "써지는 시점(초)"으로 바꿔 공개한다.
5. **마커**: 장면 시작마다 대본 메모 마커를 단다.
6. **녹음 뒤**: 음성 인식 단어 시각에서 신호 단어를 찾아 `Timing.At` 값과 장면 길이를 다시 맞춘다. 못 찾은 신호 단어는 추측하지 말고 목록으로 보고한다.
7. **검수**: 아래 표로 채점한다.

## 검수

장면마다 첫 글자가 반쯤 써진 순간·중간 빌드가 반쯤 써진 순간·마지막 프레임을 `ExportCurrentFrameAsStill`로 뽑고, 한 장으로 붙여 한 번만 본다. 항목마다 0·5·10점으로 채점하고, 80점 미만인 장면은 고친다.

| # | 항목 | 10점 기준 |
|---|---|---|
| 1 | 배경 | 모든 장면이 BOARD 단색, 무늬·그라디언트·상자 없음 |
| 2 | 색 | 쓰인 색이 draw skill 색 표 안이고, 색마다 맡은 역할(본문·규칙·이름표·비교 예시)에만 쓰임 |
| 3 | 글꼴 | 모든 글자가 Nanum Pen, 대체 글꼴 없음 |
| 4 | 써지기 | 반쯤 써진 스틸에서 글자가 왼쪽부터 일부만 보이고, 한 번에 튀어나오거나 흐리게 나타나지 않음 |
| 5 | 펜 한 자루 | 두 빌드가 동시에 진행되지 않고, 빌드 사이 0.15초 이상 |
| 6 | 선 | 굵기 6px(큰 글씨)·4px(작은 글씨), 화살표 머리가 몸통 끝에서 만남 |
| 7 | 시각 | 신호 단어 순서대로, 마지막 빌드 뒤 1.0초(예외 0.5초) 이상 정지 |
| 8 | 글자 길이 | 한 줄이 큰 글씨 10글자, 작은 글씨 14글자 이하 |
| 9 | 배치 | 글자가 잘리거나 겹치지 않고 96px 안쪽, 장면마다 같은 배치를 기계적으로 반복하지 않음 |
| 10 | 전환 | 빈 판으로의 하드 컷. 장면 안에서 지우기·페이드·카메라 없음 |

- 색은 숫자로도 본다. 장면 comp를 `ExportFusionComp`로 내보내고, 도형 `Red`·`Green`·`Blue`와 Text+ `Red1`·`Green1`·`Blue1` 값을 hex로 바꿔 draw skill 색 표와 대조한다.
- 빌드 시각은 내보낸 comp의 `Timing` 값과 써지기 길이로 겹침을 계산해 본다.
- 클립·마커 개수와 끝 프레임을 장면 표와 대조한다.
- Inspector에서 써지는 시점 하나를 바꿔 움직임이 옮겨지는지 확인하고 되돌린다. 확인이 끝나면 프로젝트를 저장한다.
- 알려진 영상 장면·캐릭터와 닮아 보이는 화면이 없는지 본다. 닮았으면 배치를 바꾼다.

## 완료 보고

다음을 적는다:

- 타임라인 이름·fps·길이
- 장면 표
- 장면별 채점 점수
- 색 대조·빌드 겹침 결과
- 글꼴 확인 결과
- 환경설정 복원 확인 결과

화면으로 보지 않고 스틸로만 확인한 것은 그렇게 적는다.

## 하지 말 것

- 렌더된 MP4·PNG로 장면을 대신하지 않는다.
- Glow·그림자·그라디언트, Blend 페이드, Write On, 키프레임 애니메이션을 쓰지 않는다.
- 다른 작업이 열어 둔 Resolve 프로젝트를 확인 없이 바꾸지 않는다.
