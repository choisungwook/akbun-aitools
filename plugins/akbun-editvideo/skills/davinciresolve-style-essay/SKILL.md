# davinciresolve-style-essay

주장과 근거가 뼈대인 영상의 편집 규칙이다. 화자는 얼굴을 내지 않고 목소리로 말하며, 화면은 B-roll·화면 녹화·근거 자료·그래픽 카드가 짧게 번갈아 나온다. 원리와 트레이드오프는 카드가 보여 준다. 말은 `davinciresolve-cut-devtalk`이 전사로 자르고, 이 문서는 "어떤 화면을 얼마나 자주, 어떤 글자를 어디에" 넣는지만 정한다.

B-roll의 종류는 정하지 않는다. 사용자가 가진 클립(대부분 집 안에서 찍은 손·책상·화면·물건)을 `davinciresolve-beats-devtalk`이 비트에 배정한다. 아래 표의 `B-roll`은 "그 자리에 어떤 화면 클립이든 하나"라는 뜻이다.

## 구조(비트 = 챕터)

| # | 비트 | 길이 | 화면 |
|---|---|---|---|
| 1 | 훅: 질문 한 문장 + 내 경험 한 문장 | 0:15 | B-roll + 키워드 Text+ |
| 2 | 왜 이 얘기를 하나 | 0:30 | B-roll + 자료 화면, 챕터 제목 카드 |
| 3 | 원리·트레이드오프 3~5개 | 항목당 0:35~0:45 | 항목마다 화면 녹화 또는 원리 카드 1개, 번호 제목 Text+ |
| 4 | 내 생각 | 0:40 | `내 생각` 카드 → B-roll |
| 5 | 근거 데이터(전후·수치) | 0:45 | 전후 비교표 카드 + 자료 하이라이트 |
| 6 | 흔한 오해·안 되는 이유 2~3개 | 0:30 | 번호 제목 Text+ + B-roll |
| 7 | 결론 | 0:20 | B-roll + 키워드 Text+ |
| 8 | 다음 행동(댓글 질문, 다음 편) | 0:15 | B-roll |

총길이 5~7분, 10분을 넘기지 않는다. 항목 수를 줄여서 맞추고 비트를 늘려 맞추지 않는다. 비트마다 Blue `CHAPTER` 마커.

## 컷 리듬

| 지표 | 기준 | 허용 범위 |
|---|---|---|
| 평균 샷 길이 | 3.3초 | 2.5~4.0초 |
| 첫 60초 컷 수 | 20개 | 15~25개 |
| 같은 화면 최대 연속 | 8초 | 넘으면 다른 화면·키워드·카드로 바꿈 |
| 카드·자료 비율(B-roll 아닌 화면) | 40% | 30~50% |

카드·자료는 원리·트레이드오프 카드 15%, 자료 화면 10%(원문 그대로 + 말하는 문장에 노란 반투명 형광펜, 3~5초), 표·수치 카드 10%(말하는 행에 빨간 원), 도구 로고·짧은 반응 클립 5%(1~2초, 사용자가 준 파일만)로 나눈다. 나머지 60%는 B-roll과 화면 녹화다. 전환은 컷이고 디졸브는 쓰지 않는다. 카드가 있는 비트 경계는 카드가 전환이 된다.

## 글자

카드는 `davinciresolve-gfx-hyperframes`, 화면 위 글자는 `davinciresolve-subtitle-devtalk`(Text+)이 만든다.

| 요소 | 만드는 곳 | 값 |
|---|---|---|
| 챕터 제목 카드 | 카드 | 전체 화면, 파스텔 단색 배경(`#EFE6F7` 계열), Pretendard Bold `#FFD400` + 외곽선 `#1A1A1A`(글자 높이의 6%), 글자 높이 화면 높이의 14%, 3~4초, 스티커 1~2개 |
| `내 생각` 카드 | 카드 | 챕터 제목 카드와 같은 값, 문구 고정 `내 생각`, 2초 |
| 원리·트레이드오프 카드 | 카드 | 흰 배경, 상자·화살표·라벨로 구조를 그림, 라벨 Medium `#1A1A1A` 글자 높이 3.5%, 말하는 요소가 0.3초 뒤 `#E53935`로 강조, 말하는 문장 길이만큼 |
| 전후 비교표 카드 | 카드 | 흰 배경, 3열(항목·전·후) 표, 머리글 Bold·본문 Medium `#1A1A1A`, 본문 글자 높이 3.5%, 말하는 행에 빨간 원(`#E53935`, 선 두께 글자 높이의 15%), 행 수 × 2초 |
| 번호 제목(화면 위) | Text+ | 화면 중앙, Bold 흰색 + 외곽선, 글자 높이 8%, `N. 제목`, 2~3초 |
| 키워드 강조(화면 위) | Text+ | 우상단 또는 중앙, Bold `#FFD400` + 외곽선, 1~3단어, 글자 높이 6%, 말한 순간 등장 0.8~2초 |
| 대사 자막 | - | 없음 |

화면 위 글자(Text+)의 글꼴과 최소 크기는 `davinciresolve-subtitle-devtalk`이 우선한다.

## 하지 않는 것

- 대사 전체 자막
- 같은 화면 8초 넘게 방치
- 10분 넘는 총길이
- 화자가 말하지 않은 수치·인용을 카드에 넣는 것
- 화자 얼굴이 보이는 화면
