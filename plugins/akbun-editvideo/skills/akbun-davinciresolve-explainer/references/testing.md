# 스킬을 고칠 때의 시험

채점 기준은 일관성이다. 같은 스킬로 장면 5개를 만들면 5개 모두 의도한 모양·색·위치·시점으로 나와야 한다. 사람이 보고 판단하는 항목은 두지 않는다. 판단이 필요한 규칙은 shapes.jsonl·layout.jsonl 값이나 `scene.py check` 항목으로 바꾼 뒤에 넣는다.

## 통과 기준

- `scene.py check`의 장면별 점수와 `set`(장면 사이 일관성) 점수가 모두 95% 이상. 장면 항목이 18개라 하나만 떨어져도 94%이므로 사실상 전부 통과해야 한다.
- 시험 5개를 한 번에 `check`로 묶어 돌린 `set` 점수도 95% 이상(서로 다른 사람이 만든 장면끼리도 같은 이름의 상자는 같은 색·크기).
- `scene.py --selftest` 통과. 체크 항목을 더하면 selftest의 "망가뜨린 장면" 사례가 그 항목에서 떨어지는지도 넣는다.

## 절차

1. shapes.jsonl·shape-styles.jsonl·palettes.jsonl·layout.jsonl·checklist.jsonl과 `scene.py`를 고치고 `--selftest`를 돌린다.
2. 서로 다른 주제 5개를 정한다. 예시(업로드 한도, 캐시)와 겹치지 않게 하고, 사람·상자·원통·코드 카드·이어받은 장면이 5개 안에 모두 한 번 이상 나오게 한다. palettes.jsonl의 팔레트와 shape-styles.jsonl의 도형 스타일도 5개 안에 각각 한 번 이상 쓴다(호출 문장에 "<팔레트> 색, <스타일> 도형"을 넣는다).
3. 주제마다 새 컨텍스트 agent 하나에 맡긴다. 모델은 2종 이상 섞는다. 지시: 이 SKILL.md에서 시작해 라우팅대로 읽고 spec 1~2개를 쓰고 `build`·`check`를 돌려 점수를 보고할 것, 저장소는 고치지 말 것, 출력 폴더 하나만 쓸 것, 이미지는 열지 말 것, 규칙이 모호하거나 충돌해 추측한 곳을 목록으로 적을 것.
4. 5개 결과를 한 출력 폴더에 모아 `check`로 한 번에 채점하고, 스틸 5장 이상을 한 장으로 붙여 부모가 한 번만 본다. 눈에 띈 문제가 점수에 안 잡혔으면 checklist.jsonl 항목부터 만든다.
5. agent가 적은 추측 목록을 spec.md·jsonl에 반영하고 2라운드를 돌린다. 5개 모두 95% 이상이고 추측 목록이 비면 끝.

결과(주제, 모델, 점수, 실패 항목, 고친 것)는 PR 검증 표에 남긴다.
