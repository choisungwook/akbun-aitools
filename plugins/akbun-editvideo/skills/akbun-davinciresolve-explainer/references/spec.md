# 장면 spec

장면 하나 = JSON 파일 하나다. spec은 무엇을, 어느 순서로, 언제 보일지만 정한다. 모양·크기·색·위치 계산은 `shapes.jsonl`·`shape-styles.jsonl`·`palettes.jsonl`·`layout.jsonl`과 `scripts/scene.py`가 한다. SVG를 손으로 쓰거나 고치지 않는다. spec 파일은 작업 폴더(예: `<작업 폴더>/spec/`)에 두고, 명령에는 그 경로를 그대로 넘긴다.

## 필드

아래가 필드 전체다. 표에 없는 필드는 쓰지 않는다.

| 필드 | 값 |
|---|---|
| `id` | 장면 이름(`s1`, `s2` …). 결과 파일 이름이 된다 |
| `theme` | `{"palette": palettes.jsonl id, "shape": shape-styles.jsonl id}`. 호출 문장의 "<id> 색"은 palette, "<id> 도형"은 shape다. 말하지 않은 쪽은 기본값(`night`, `gouache`)이고, "akbun 색"만 말했으면 shape는 `gouache`다. `extends`가 없는 모든 장면에 같은 값을 쓰고, `extends` 장면은 이어받으니 쓰지 않는다. 둘 다 기본값이면 생략한다 |
| `dur` | 장면 길이(초). `scene.py timing`이 준 값 |
| `subs` | `[[시작, 끝, "자막"], …]` 클립 시작 기준 초. 한 줄, 공백 포함 24자 이하(한글·영문·기호 모두 1자). 시각은 `scene.py timing`이 준 값 |
| `timed` | 녹음 후 실제 발화 시각으로 `subs`·`dur`를 채웠으면 `"recording"`. 그때만 timing 값과 달라도 된다 |
| `row` | 가로 한 줄에 놓을 object 레이어 `name`을 왼쪽부터. 항목이 이름 목록(`["server-a", "server-b"]`)이면 그 칸에 위에서 아래로 쌓는다. 위치 계산식은 layout.jsonl `use`. `extends` 장면의 row는 앞 장면 row 뒤에 새 이름만 붙는다 |
| `layers` | 아래부터 쌓는 레이어 목록. 항목마다 `name`(영문 소문자·숫자·하이픈), `shape`(shapes.jsonl id), shape별 필드, `at` |
| `extends` | 앞 장면 spec 파일 이름(이 spec과 같은 폴더 기준). 그 장면 레이어를 같은 자리·같은 색으로 처음부터 보이게(`at` -1) 이어받는다. 이어받은 레이어는 바꿀 수 없다 |
| `punch` | `{"targets": [레이어 이름…]}`. 펀치 인(그 대상들로 화면을 확대하는 줌)을 할 때만 쓴다. 장면당 0~1개. 강조할 대상과 그 태그·점선 상자를 모두 넣는다 |

shape별 필드는 다음과 같다.

| shape | 필드 |
|---|---|
| `person` | 없음 |
| `box` | `label`(영문 1~2단어. 폭 계산에서 공백도 1자), `role`(shapes.jsonl box.roles의 키. 각 role의 `examples`에서 가장 가까운 것을 고른다. 브라우저·클라이언트는 `external`) |
| `db` | `label`(영문 1~2단어, 기본 `DB`) |
| `code-card` | `file`(spec 기준 상대 경로), `lines`([첫 줄, 끝 줄], 1부터, 끝 포함). `$ cat` 줄과 `...` 줄을 합쳐 카드가 14줄 이하 |
| `arrow` | `from`, `to`(레이어 이름), 선택 `flow`(`forward` 기본, 응답·되돌아오는 흐름은 `reply`), 선택 `lane: "below"`(반대 방향 화살표가 이미 있는 두 대상 사이를 되돌아올 때) |
| `dashed-box` | `around`(감쌀 레이어 이름 목록). 지금 말하는 대상·상태를 짚는다 |
| `code-mark` | `card`(코드 카드 이름), `line`(파일의 줄 번호) |
| `cross` | `on`(화살표 이름). 그 길이 끊김·고장·대기임을 뜻한다 |
| `tag` | `text`(자막에 처음 나오는 용어 그대로, 20자 이하), `on`(태그를 올릴 레이어. 화살표도 된다). 자막에 처음 나온 설정·식별자 이름(예: `upload_max_filesize`)이 있을 때만, 장면당 하나 |

모든 object(사람·상자·원통)는 `row`에 넣는다. 위아래로 갈라지는 구도는 세로 묶음으로 그린다. `x`, `y`(bbox 왼쪽 위 px)는 쓰지 않는다. 상자 폭 = 글자 수 × 20 + 90(220~420), 높이 120. 사람 230×310, 원통 230×258(윗면 타원 전체 + 곧은 옆면 + 둥근 밑면).

## 시각(at)

자막 시각은 손으로 정하지 않는다. 장면마다 한 번씩, 그 장면의 자막 문장만 `scene.py timing`에 넘기면(이어받은 장면도 0초부터) `subs`와 `dur`가 나온다(길이 = 음절 / 5.5 + 0.4초를 0.1초 단위로 올림, 자막 사이 0.1초, 음절은 한글·숫자 1자 = 1, 대문자 약어 = 글자 수 × 1.3 올림, 그 밖의 영문 단어 = 모음 묶음 수). 녹음 뒤에는 실제 발화 시각을 넣고 `"timed": "recording"`을 준다. [resolve-core.md](resolve-core.md)의 "내레이션 규칙" 시각 식은 다른 스타일 스킬용이고 이 스킬에서 쓰지 않는다.

장면 자막 두 문장으로 subs·dur를 얻는 명령이다.

```bash
uv run --python 3.12 scripts/scene.py timing "사용자가 파일을 올립니다" "PHP가 크기 한도를 먼저 봅니다"
```

| 대상 | at |
|---|---|
| object·태그·점선 상자·code-mark·cross | 그 대상(cross는 끊김·고장·대기 상태)을 말하는 자막의 시작. 한 자막에서 둘 이상을 말하면 말하는 순서대로 +0.3초씩(최대 +0.9초). 태그는 그 태그가 붙은 대상과 같은 at |
| arrow | 쓰지 않는다. 두 끝 중 늦게 나오는 대상 + 0.3초로 정해진다. 예외 둘: `flow: "reply"` 화살표는 그 응답을 말하는 자막 시작(+0.3k)을 줄 수 있다. 두 끝이 모두 이어받은 대상이면 그 화살표가 나타내는 흐름을 말하는 자막 시작(+0.3k)을 반드시 준다 |
| 펀치 인 | 쓰지 않는다. max(마지막 등장 + 0.5, 장면 길이 - 2.0)초로 정해진다. 장면 끝 1.0초 전보다 늦으면 check가 떨어뜨리니 `punch`를 뺀다 |

같은 시각에 시작하는 레이어는 화살표를 포함해 2개까지다. 화살표가 대상보다 늦게 나오므로, 흐름을 말하는 자막에서 그 도착 대상도 함께 말하게 대본을 쓴다.

## 정하는 순서

1. 대본을 자막으로 나누고 `subs` 시각을 정한다.
2. 자막마다 그 문장이 말하는 대상을 고르고 shape·role을 정한다. 화면 object는 1~4개.
3. object를 `row`에 왼쪽부터 흐름 순서로 넣는다.
4. 강조는 `dashed-box`(대상) 또는 `code-mark`(코드 줄)로만 한다. 고장·끊김·대기는 그 길의 화살표에 `cross`를 단다. 컴포넌트 색은 장면이 바뀌어도 바꾸지 않는다.
5. 같은 소재를 이어 가는 장면은 `extends`로 앞 장면을 이어받고 새 레이어만 더한다.
6. `build` → `check`. 실패하면 출력의 이유를 보고 spec을 고친다.

## 새 모양이 필요할 때

shapes.jsonl에 없는 모양(노트북, 그래프 등)은 spec에 쓰지 않는다. 같은 변경에서 shapes.jsonl 줄(static이면 `prims` 좌표), 필요하면 palettes.jsonl 색 키(모든 팔레트에), `scene.py`의 그리기 분기, checklist.jsonl 항목을 함께 더하고 [testing.md](testing.md) 절차를 통과시킨다.

예시 spec은 [example/](example/)에 있다. `ex1`은 사람 → 컴포넌트 + 코드 카드, `ex2`는 세 대상 흐름 + 이어받은 장면이다.
