# akbun-edit-terminal-callout-amber

## 언제 쓰나

레이아웃은 고정하지 않는다. 상황에 맞는 부품을 고르고, 부품의 모양·색·글꼴·모션만 아래 "스타일"대로 지킨다.

| 상황 | 화면에 나오는 것 |
|---|---|
| 명령이 실패한 이유를 짚는다 | 터미널 녹화 카드 + 오류 줄 옆 화살표와 라벨 하나 |
| AI 코딩 도구가 답하는 과정을 보여 준다 | AI 도구 화면 녹화 카드. 답의 핵심 토큰 1~2개에 하이라이트 |
| 출력 속 값 하나를 강조한다 | 터미널 카드 + 값 토큰에 하이라이트, 카메라가 그 줄로 다가감 |
| 명령과 결과를 차례로 설명한다 | 녹화가 흐르는 동안 명령 줄 → 결과 줄 순서로 라벨 1~3개가 차례로 나타남 |

- 터미널·AI 출력은 **사용자가 녹화한 실제 화면만** 쓴다. 출력 글자를 지어내지 않는다. 녹화가 없으면 녹화를 요청한다. 예외는 사용자가 "코드를 네가 찾아서 보여 달라"고 할 때다. 저장소를 `git clone --depth 1`로 받고 실제 명령(`sed -n`, `cat`)을 실행한 출력을 Fusion 카드로 렌더한다. 프롬프트 줄은 사용자가 원하는 명령(예: `cat 파일명`)을 쓰되 출력은 실제 줄만 쓰고, 줄을 생략하면 `...`로 표시한다. 완료 보고에 "화면 녹화가 아니라 실제 명령 출력을 Fusion 카드로 렌더함"과 커밋 해시를 적는다. 코드를 그림으로 설명할 때는 [akbun-draw-code-window-lilac](../../../akbun-draw/skills/akbun-draw-code-window-lilac/SKILL.md)를 쓴다.
- 얼굴 화면(PIP)·웹캠·인물 촬영은 넣지 않는다. 녹화에 웹캠 창이 있으면 Crop으로 뺀다.
- 녹화에 비밀값(토큰·키·비밀번호·개인 경로의 사용자 이름)이 보이면 쓰기 전에 사용자에게 알리고 가림 또는 다시 녹화를 받는다.

## 녹음 전후 시각 맞추기

작업 흐름은 대본 → 영상 → 녹음 → 영상 수정이다. 라벨·하이라이트·카메라 키·클립 길이는 모두 대본의 "신호 단어"에 묶는다. plan의 시간은 클립 시작 기준 초이고, 클립의 0초는 그 장면 첫 문장의 시작이다.

- **녹음 전**: 대본을 초당 6.5음절로 읽는다고 보고 시각을 잡는다. 한글 한 글자 = 1음절, 영어 단어 = 모음 글자 묶음 수(a·e·i·o·u, 단어 끝이 아닌 y 포함, 붙어 있는 모음은 한 묶음, 최소 1, camelCase·snake_case는 단어로 나눠 센다), 숫자·기호 = 한국어로 읽는 소리 수. 띄어쓰기는 시간을 더하지 않고, 쉼표는 0.2초, 문장 끝은 0.4초를 더한다. 요소는 신호 단어 시작 0.1초 전에 시작한다(0보다 작으면 0). 클립 길이는 그 장면 마지막 음절이 끝나는 시각 + 0.4초다(문장 끝 쉼 0.4초를 한 번만 더한다).
- **녹화와 맞추기**: 라벨이 가리키는 줄은 녹화 안에서 그 줄이 나타난 뒤에만 나타난다. 녹화 속 줄 등장 시각이 신호 단어보다 늦으면 `trim_in`을 앞당겨 녹화를 당긴다. 녹화 속도는 바꾸지 않는다.
- **녹음 후**: 단어 시각(Resolve 전사, SRT, Whisper 단어 타임스탬프 중 있는 것)에서 신호 단어의 시작 시각을 찾아 plan의 `at`·`duration`·`start`·`trim_in`·`camera[].at`를 고치고 `retime`으로 다시 맞춘다.
- SRT처럼 문장 단위 시각만 있으면 문장 시작~끝을 음절 수 비율로 나눠 단어 시각을 추정하고 장면 표에 "추정"으로 표시한다. 신호 단어를 못 찾으면 시각을 추측하지 말고 목록으로 보고한다.
- **우선순위**: 녹화 속 줄 등장 > 신호 단어 시각 > 아래 모션 표의 길이 > 그 밖의 간격 규칙.
- 장면 표에는 요소마다 신호 단어, 녹화 속 줄 등장 시각, 녹음 전 시각, 녹음 후 시각 열을 둔다.

## 스타일

1920×1080 기준이다.

### 색과 글꼴

| 이름 | 값 | 쓰임 |
|---|---|---|
| CANVAS | `#EAEAEA` | 배경(`canvas_color`). 사용자가 단색을 정하면(예: `#202020`) 그 값 |
| 창 틀 | `frame` 명령 dark 테마(`#1B2224`) | 신호등 점, 제목줄에 셸·도구 이름 |
| CALLOUT | `#FFD84D` | 화살표(7px), 라벨 글자, 토큰 하이라이트 |
| TOKEN_FILL | `#FFD84D`, `alpha` 0.25 | 토큰 채움(`fill`) |

- 라벨은 `Gaegu` Bold 40~52px(Text+). 없으면 `Nanum Pen`을 쓴다. 둘 다 없으면 렌더하지 않고 설치할지 사용자에게 묻는다(Google Fonts 공식 배포처).
- 라벨은 2~10자 한 줄. 문장을 쓰지 않는다.
- 노랑 말고 다른 강조색을 쓰지 않는다. 녹화 화면 자체의 색은 그대로 둔다.

### 부품

| 부품 | 모양 |
|---|---|
| 터미널 카드 | dark 틀, 폭 1300~1560px. 녹화의 터미널 영역만 `crop`(메뉴 막대·독·웹캠 제외) |
| 화살표 | `arrow` 명령. 가리키는 줄 끝에서 오른쪽(줄이 길면 위나 아래) 24~60px 떨어진 곳을 끝점으로, 길이 120~260px, 라벨 쪽에서 출발 |
| 라벨 | 화살표 시작점 너머 20~40px, 카드 밖 캔버스 위 또는 터미널의 빈 오른쪽 영역. 화면 글자를 가리지 않는다 |
| 토큰 하이라이트 | `fill`(TOKEN_FILL) 한 장 + `box`(CALLOUT, 3px) 한 장을 같은 사각형으로. 토큰 글자에서 사방 4~6px. `resolve_cards.py` 밖에서 Fusion 노드를 직접 짜면 Background `TopLeftAlpha`만으로는 반투명이 안 되므로(Resolve 21.1.1 실측) 채움 없이 `box` 윤곽 + 밑줄로 만든다 |

- 한 화면에 화살표+라벨은 3쌍까지, 토큰 하이라이트는 2개까지다.
- 표시 좌표는 녹화 프레임 픽셀을 재서 `where` 명령으로 바꾼다. 녹화가 스크롤되면 줄 위치가 바뀌므로 표시가 보이는 시간 동안 그 줄이 같은 자리에 있는지 녹화를 확인한다.

### 모션

| 움직임 | 방식 | 길이 |
|---|---|---|
| 카드 등장 | `CARD_*_LAYOUT` Blend 페이드 | 0.25초 |
| 화살표 → 라벨 | 화살표 페이드, 0.25초 뒤 라벨 페이드 | 각 0.2초 |
| 토큰 하이라이트 | `fill`은 왼쪽→오른쪽 쓸기(`sweep: true`), `box`는 페이드 | 0.3초, 0.2초 |

- 카메라는 기본으로 정지한다. 오류 줄·토큰을 짚을 때만 0.6~0.8초 ease-in-out으로 zoom 1.3~1.6까지 다가가 머물고, 장면 끝까지 머물러도 된다. 확대 중 보이는 영역에 그 줄과 라벨이 다 들어간다.
- 녹화는 실제 속도로 흐른다. 빠르게 감기·정지 화면이 필요하면 사용자가 녹화를 편집해 준다.
- **캔버스 밖 금지**: 카메라 키마다 보이는 영역(x ± 960/zoom, y ± 540/zoom)이 캔버스(0~1920, 0~1080) 안에 있어야 한다. 대상이 가장자리에 가까우면 가운데를 안쪽으로 옮긴다(x는 960/zoom ~ 1920 − 960/zoom, y는 540/zoom ~ 1080 − 540/zoom).

## 작업 흐름

`<page-tour>`는 [akbun-edit-page-tour-lilac](../akbun-edit-page-tour-lilac/SKILL.md) 디렉터리다. 스크립트·plan 형식·노드 구성·21.1.1 실측·검증은 [fusion-cards.md](../akbun-edit-page-tour-lilac/references/fusion-cards.md)를 먼저 읽고 따른다.

1. **녹화 확인**: 녹화 파일의 해상도·fps·길이를 `ffprobe`로 재고, 가리킬 줄이 나타나는 시각과 프레임 픽셀 위치를 잰다. 프레임을 볼 때는 필요한 시각 몇 장을 한 장으로 붙여 한 번만 본다.
2. **장면 표**: 장면마다 "언제 쓰나"의 행, 녹화 `trim_in`, 라벨·하이라이트와 신호 단어·시각을 적는다.
3. **자산**: dark 틀, 화살표 PNG, 캔버스 영상을 만든다. 녹화 파일은 옮기지 않고 원래 경로를 쓴다(임시 폴더에 있으면 `edit-assets/`로 복사).
4. **plan.json**: 카드 `shot`은 녹화 파일, `shot_size`는 녹화 해상도, `trim_in`은 쓸 시작 초다. 표시 좌표는 `where`로 계산한다.
5. **빌드·검증·녹음 후**: `build` → `grab` → `retime`. 트랙 이름은 `TERMINAL_CALLOUT`이다.

예시 plan과 Resolve에서 만든 결과 시트는 [references/example/](references/example/)에 있다. 스타일 확인용이며 좌표·문구를 그대로 쓰지 않는다.

오류 줄 끝(1180, 520)을 가리키는 화살표를 라벨 쪽(1420, 430)에서 그리는 명령이다.

```bash
uv run --python 3.12 <page-tour>/scripts/resolve_cards.py frame --rect 180,110,1560,860 --theme dark --title zsh --out edit-assets/term01_frame.png
uv run --python 3.12 <page-tour>/scripts/resolve_cards.py arrow --start 1420,430 --end 1205,512 --color '#FFD84D' --out edit-assets/callout01_arrow.png
```

## 사용자가 고치는 법

Edit 페이지에서 `TERMINAL_CALLOUT` 트랙의 클립을 고르고 Fusion 페이지로 간다.

| 고치려는 것 | 노드 → Inspector |
|---|---|
| 라벨 글자·글꼴·크기·색·위치 | `CALLOUT_01_LABEL` → Text, Font, Size, Color, Center |
| 화살표 숨기기 | `CALLOUT_01` → Blend 0 (라벨은 `CALLOUT_01_TEXT`) |
| 화살표 모양·위치 | `arrow` 명령으로 다시 만들어 `CALLOUT_01_ARROW`의 Clip 경로 교체 |
| 토큰 하이라이트 위치·크기 | `MARK_01_SHAPE`, `MARK_02_SHAPE` → Center, Width, Height |
| 하이라이트 색 | `MARK_01_COLOR` → Color |
| 녹화 시작 지점 | `SHOT_01` → Trim In(Clip Time Start) |

캔버스 클립 모드에서는 Edit 페이지 Inspector에 이 값들이 나오지 않는다(21.1.1 실측).

**Edit Inspector에서 고치고 싶을 때(title 모드)**: plan에 `"mode": "title"`을 넣고 `build`하면 장면이 장면 전용 타임라인(`title_timeline`) 끝에 Fusion 타이틀로 붙는다. 그 클립을 고르고 Inspector → Video → Title 탭에서 `Mark 01 Color`·`Mark 01 Position`·`Mark 01 Width/Height`·`Card 01 Position/Size`·`Callout 01 Text/Position`을 바로 바꾼다. 대가는 장면이 본편 위 트랙이 아니라 별도 타임라인에 있어 사용자가 본편으로 복사해 붙여야 하고, `retime`이 안 돼 녹음 후에는 클립을 지우고 다시 `build`한다는 점이다(Inspector에서 고친 값은 plan 값으로 돌아간다). 자세한 절차는 [fusion-cards.md의 Edit Inspector 모드](../akbun-edit-page-tour-lilac/references/fusion-cards.md#edit-inspector-모드-title)다.

완료 보고에 어느 모드로 만들었는지와 해당 표(또는 Inspector 컨트롤 목록)를 적는다.

## 검수

- `build` 출력의 `frames` = 장면 길이 × fps이고, 다른 트랙 클립·마커 대조를 통과했다.
- `grab`: 화살표 시각 전 프레임에는 화살표가 없고, 뒤 프레임에는 있다. 라벨이 그 0.25초 뒤에 나타난다.
- 라벨·하이라이트가 나타나는 시각에 녹화 속 그 줄이 이미 있고 같은 자리에 있다(그 프레임을 시트로 확인).
- 화살표 끝이 가리키는 줄 끝에서 24~60px 안이고, 라벨이 녹화 글자를 가리지 않는다.
- 녹화에 비밀값·웹캠·얼굴이 보이지 않는다.

## 완료 보고

작업 타임라인·트랙·클립 시작 타임코드·길이, 녹화 파일 경로·`trim_in`, plan·자산 경로, 장면 표, `grab` 결과, "사용자가 고치는 법" 표를 적는다. 확인하지 않은 항목은 "확인하지 않음"으로 적는다.

## 하지 말 것

- 터미널·AI 도구 출력을 지어내지 않는다. 녹화 글자와 실제 명령 출력 줄을 바꾸지 않는다.
- 얼굴 PIP를 넣지 않는다.
- 원본 타임라인과 본편 트랙을 고치지 않는다. 표현식에 `comp.RenderStart`를 쓰지 않는다.
