# davinciresolve-style-project

시작·진행·결과의 시간 흐름이 뼈대인 영상의 편집 규칙이다. 화자는 얼굴을 내지 않고 작업 화면 위에서 길게 말하는 것을 허용하며, 사이사이 타임랩스가 쉼표가 된다. 말은 `davinciresolve-cut-devtalk`이 자르고, 이 문서는 화면과 글자 규칙만 정한다.

B-roll의 종류는 정하지 않는다. 사용자가 가진 클립(대부분 집 안 작업 공간)을 `davinciresolve-beats-devtalk`이 배정한다.

## 구조(비트 = 챕터)

| # | 비트 | 길이 | 화면 |
|---|---|---|---|
| 1 | 훅 + 맥락: 무엇을 왜 만드나 | 0:45 | B-roll + 오프닝 타이틀 |
| 2 | 목표 2~3개 | 0:20 | B-roll + 좌상단 목록 자막 |
| 3 | 계획·기술 선택과 이유 | 0:40 | 화면 녹화(빈 프로젝트·문서) |
| 4 | 작업 타임랩스 1 | 0:15 | 타임랩스 |
| 5 | 진행 보고 1: 했다 → 막혔다 → 풀었다 | 1:15~1:45 | 화면 녹화 + B-roll |
| 6 | 지금 결과 보여주기 | 0:45 | 화면 녹화 + 장면 코멘트 |
| 7 | 작업 타임랩스 2 | 0:15 | 타임랩스 |
| 8 | 진행 보고 2 | 1:00~1:45 | 화면 녹화 + B-roll |
| 9 | 전후 비교 스크롤스루 | 0:45 | 화면 녹화 2개 나란히 |
| 10 | 마무리: 배운 것, 조언 요청, 다음 편 | 0:30 | B-roll |

총길이 6~8분, 10분을 넘기지 않는다. 진행 보고 길이로 맞춘다. 비트마다 Blue `CHAPTER` 마커.

## 컷 리듬

| 지표 | 기준 | 허용 범위 |
|---|---|---|
| 평균 샷 길이(타임랩스 제외) | 8초 | 5~12초 |
| 첫 60초 컷 수 | 3개 | 2~6개 |
| 같은 화면 최대 연속 | 40초 | 넘으면 다른 화면 녹화 또는 B-roll |
| B-roll 비율(화면 녹화 아닌 화면) | 30% | 20~40% |
| 타임랩스 길이 | 비트당 15초 | 10~20초, 프레임당 0.3초 이하 |

전환은 컷. 타임랩스 앞뒤만 12프레임 디졸브. 음성이 잘린 자리의 화면은 그대로 붙인다.

## 글자

| 요소 | 값 |
|---|---|
| 오프닝 타이틀 | B-roll 위 중앙, 제목 Pretendard Bold + 부제 Medium, `#F2B84B`, 그림자 `#1A1A1A` 50%, 제목 높이 8%·부제 5%, 3~4초 |
| 장면 코멘트 | 하단 중앙, Medium `#F2B84B` + 그림자, 글자 높이 5%, 한 줄 18자 이내, 장면 설명·속마음 한 줄 |
| 목록 자막 | 좌상단(여백 8%), 같은 값, 제목 1줄 + 항목을 말할 때마다 한 줄 추가 |
| 대사 자막·카드 | 없음. 전후 비교는 화면 녹화 나란히 |

글꼴과 최소 글자 크기는 `davinciresolve-subtitle-devtalk`이 우선한다.

## 하지 않는 것

- 대사 전체 자막, 그래픽 카드
- 진행 보고에서 막힌 것을 빼는 편집
- 10분 넘는 총길이
- 시작 화면 녹화 없이 전후 비교 만들기
- 화자 얼굴이 보이는 화면
