# davinciresolve-style-project

작업이나 하루·한 주의 기록에서 목표·시도·막힘·선택·결과의 변화를 보여주는 편집 규칙이다. 화자는 얼굴을 내지 않고 내레이션으로 말할 수 있다. 시간순 나열은 실제 변화를 보여줄 때만 사용한다. 타임랩스는 변화가 눈에 보이거나 시간 경과를 전달할 때만 쓴다. 말은 `davinciresolve-cut-devtalk`이 자르고, 이 문서는 화면과 글자 규칙만 정한다.

B-roll의 종류는 정하지 않는다. 사용자가 가진 클립(대부분 집 안 작업 공간)을 `davinciresolve-beats-devtalk`이 배정한다.

## 구조(비트 = 챕터)

| # | 비트 | 길이 | 화면 |
|---|---|---|---|
| 1 | 콜드 오픈: 목표와 예상 밖의 순간 | 0:20 | 실제 결과/문제의 짧은 장면 + 타이틀 |
| 2 | 지금 왜 이 일을 하나, 시청자에게 필요한 맥락 | 0:45 | B-roll + 목표 목록 |
| 3 | 시작점과 이루려는 것 | 0:40 | 시작 화면·물건·문서 |
| 4 | 시도와 첫 장애물 | 1:00 | 작업 화면 + 행동 B-roll |
| 5 | 선택·수정 또는 받아들인 한계 | 1:10 | 결정에 앞뒤가 있는 화면/현장음 |
| 6 | 변화가 일어난 지점 | 0:40 | 과정 타임랩스(필요할 때) |
| 7 | 결과와 시작점 비교 | 0:50 | 전후 화면 또는 구체적 결과 |
| 8 | 돌아본 점과 다음 질문 | 0:35 | B-roll + 장면 코멘트 |
| 9 | 다음 편 약속(연재에 맞을 때) | 0:15 | 다음 주에 확인할 지점 |

총길이 기본 5–7분, 최대 10분 미만. 표의 합은 약 6분 15초이며, 기록할 사건이 적으면 비트를 억지로 늘리지 않는다. day diary·주차 diary는 계획·실행·변화의 순서를 실제 경험에 맞춰 바꾸거나 합칠 수 있다. 비트마다 Blue `CHAPTER` 마커.

## 컷 리듬

| 지표 | 기준 | 허용 범위 |
|---|---|---|
| 평균 샷 길이(타임랩스 제외) | 8초 | 5~12초 |
| 첫 60초 컷 수 | 3개 | 2~6개 |
| 같은 화면 최대 연속 | 40초 | 넘으면 다른 화면 녹화 또는 B-roll |
| B-roll 비율(화면 녹화 아닌 화면) | 30% | 20~40% |
| 타임랩스 길이 | 필요한 변화 구간만 | 완성 영상 10~20초부터 비교. 장면과 시간 경과에 맞춰 조정 |

전환은 컷. 타임랩스 앞뒤만 12프레임 디졸브. 음성이 잘린 자리의 화면은 그대로 붙인다.

## 글자

| 요소 | 값 |
|---|---|
| 오프닝 타이틀 | B-roll 위 중앙, 제목 Pretendard Bold + 부제 Medium, `#F2B84B`, 그림자 `#1A1A1A` 50%, 제목 높이 8%·부제 5%, 3~4초 |
| 장면 코멘트 | 하단 중앙, Medium `#F2B84B` + 그림자, 글자 높이 5%, 한 줄 18자 이내, 장면 설명·속마음 한 줄 |
| 목록 자막 | 좌상단(여백 8%), 같은 값, 제목 1줄 + 항목을 말할 때마다 한 줄 추가 |
| 대사 자막·카드 | 없음. 전후 비교는 화면 녹화 나란히 |

글꼴과 최소 글자 크기는 `davinciresolve-subtitle-devtalk`이 우선한다.

## 하지 않는 것

- 대사 전체 자막, 그래픽 카드
- 진행 보고에서 막힌 것을 빼는 편집
- 10분 넘는 총길이
- 시작 화면 녹화 없이 전후 비교 만들기
- 화자 얼굴이 보이는 화면
