# davinciresolve-face-privacy

얼굴과 개인정보(차량 번호판, 이름표, 화면에 뜬 개인 정보)를 약한 모자이크로 가린다. 영상 분위기를 해치지 않을 만큼 약하게, 대신 범위는 넓고 경계는 부드럽게 한다. 편집이 끝나면 사용자가 무엇을 어디에 가렸는지 타임라인에서 바로 찾을 수 있어야 한다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 클립은 파일명 + 시작 타임코드, 대표 클립 선적용, 작업 로그)을 따른다.

## 탐지

- 각 클립의 시작, 중간, 끝 프레임을 우선 분석한다. 클립이 10초를 넘으면 5초 간격 프레임을 추가한다.
- 사람이 작게 보이더라도 얼굴 식별 가능성을 확인한다. 4K 기준 얼굴 높이가 40px 이상이면 식별 가능으로 본다.
- 얼굴이 화면 가장자리로 이동하는 구간도 검사한다. 시작·끝 프레임에 없어도 중간 프레임에 있으면 대상이다.
- 탐지 수단은 `davinciresolve-video-editor`의 `references/agent-api.md` 대체 방법 표(프레임 추출 + 얼굴 탐지)를 따른다. 탐지를 돌릴 수 없는 클립은 모자이크를 추측으로 넣지 않고 `PRIVACY_CHECK` 마커를 찍는다.
- 탐지 결과는 클립별로 얼굴 수, 프레임 위치, 좌표 범위를 작업 로그에 남긴다.

## 적용 방식

1. Color 페이지에서 `WB` 노드 뒤, `LUT` 노드 앞에 새 Serial Node를 추가하고 이름을 `PRIVACY_MOSAIC`으로 지정한다.
2. 얼굴 하나하나가 아니라 얼굴이 지나가는 범위 전체, 관중석이면 관중석 전체를 포함하는 Power Window(Circle 또는 Rectangle)를 만든다. 탐지된 좌표 범위보다 상하좌우 15% 이상 넓게 잡는다.
3. 경계가 눈에 띄지 않도록 Softness를 높인다. 기본 Softness는 창 크기의 30% 이상이다.
4. Mosaic Blur(Resolve FX `Mosaic Blur`)를 적용한다.
5. 영상 분위기를 해치지 않는 약한 블록 크기를 쓴다. 기본 Pixel Frequency는 얼굴 높이의 1/4 크기 블록이 되도록 잡고, 얼굴 윤곽은 보이되 이목구비가 구분되지 않는 정도로 한다.
6. 카메라 움직임이 작으면(시작·끝 프레임의 얼굴 위치 차이가 화면 폭의 10% 이내) 범위를 넓혀 트래킹 없이 처리한다.
7. 넓은 범위로도 얼굴이 벗어나면 해당 클립만 Window Tracker로 트래킹한다. 트래킹 실패 프레임은 키프레임으로 보정하거나 `PRIVACY_CHECK` 마커를 찍는다.

한 클립에 여러 얼굴 묶음이 있으면 `PRIVACY_MOSAIC` 노드 하나에 Power Window를 여러 개 만든다. 노드를 여러 개 만들지 않는다.

## 편집 뒤 마킹

사용자가 나중에 모자이크 위치를 찾고 고칠 수 있게 세 곳에 남긴다.

| 위치 | 규칙 |
|---|---|
| 타임라인 마커 | 모자이크를 넣은 클립마다 시작 TC에 Purple 마커. 이름 `PRIVACY_MOSAIC <파일명> <창 개수>개`, 노트에 창 종류·트래킹 여부 |
| 검토 마커 | 탐지 불가, 트래킹 실패, 범위 확신 없음이면 Red 마커 `PRIVACY_CHECK <파일명> <사유>` |
| 작업 로그 | `6. 모자이크` 절에 아래 표. 마커 목록과 행 수가 같아야 한다 |

작업 로그 표 형식이다.

```markdown
| 파일명 | 시작 TC | 얼굴 수 | 창 종류 | 창 개수 | Softness | 트래킹 | 마커 | 비고 |
|---|---|---|---|---|---|---|---|---|
| IMG_1250.MOV | 00:03:10:00 | 3 | Rectangle(관중석) | 1 | 40% | 없음 | PRIVACY_MOSAIC | 카메라 고정 |
| IMG_1262.MOV | 00:04:05:12 | 1 | Circle | 1 | 35% | 있음 | PRIVACY_MOSAIC | 프레임 80~96 키프레임 보정 |
| IMG_1270.MOV | 00:05:00:00 | ? | - | 0 | - | - | PRIVACY_CHECK | 프레임 추출 실패 |
```

## 검증

- 클립 시작, 중간, 끝(추가 샘플 프레임 포함)에서 얼굴이 Power Window 밖으로 벗어나지 않는지 확인한다. 얼굴 좌표 범위와 창 좌표를 겹쳐 계산하고, 하나라도 벗어나면 창을 넓히거나 트래킹으로 바꾼다.
- 중요한 풍경이나 드론쇼를 불필요하게 가리지 않는다. 창이 화면의 40%를 넘으면 범위를 나누거나 트래킹으로 바꾼다.
- 모든 모자이크 노드 이름이 `PRIVACY_MOSAIC`인지 확인한다.
- Purple 마커 수 = 작업 로그 `PRIVACY_MOSAIC` 행 수, Red 마커 수 = `PRIVACY_CHECK` 행 수인지 확인한다.
- 사용자가 나중에 Power Window의 위치, 크기, Softness를 수정할 수 있게 창을 합치거나 노드를 잠그지 않는다.

## 하지 않는 것

- 탐지 근거 없는 모자이크 적용
- 이목구비까지 지워버리는 강한 블록이나 검은 박스
- 한 클립에 `PRIVACY_MOSAIC` 노드 여러 개
- 마커·로그 없는 모자이크
- 사용자가 지정한 인물(예: 사용자 본인)을 지정 없이 가리기. 사용자 본인은 시작 시 가릴지 물어보고 답이 없으면 가리지 않고 `PRIVACY_CHECK`로 남긴다
