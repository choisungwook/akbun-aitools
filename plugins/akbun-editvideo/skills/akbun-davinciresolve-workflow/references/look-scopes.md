# Look 스코프 측정 규약

네 look의 `SKILL.md`에 있는 수치는 스타일을 탐색하는 시작 범위다. 참고 영상에서 실측한 통계나 보편적인 합격 기준은 아니다. 아래 절차로 같은 프레임을 반복 비교하고, 장면 의도와 선택한 기본 노출을 우선한다.

## 측정 입력

1. 활성 타임라인의 입력·작업·출력 색공간, 감마, 데이터 레벨을 기록한다. 이 표는 최종 출력 변환을 지난 Rec.709 SDR 신호용이다. HDR 신호나 Log 픽셀에 직접 적용하지 않는다.
2. 대표 클립의 파일명·소스 TC·타임라인 TC를 고정한다. 전후는 같은 프레임과 같은 출력 변환으로 비교한다. 화면 캡처 대신 가능하면 그레이드가 적용된 출력 스틸을 사용한다. 디스플레이 프로파일이나 UI 배율이 적용된 캡처는 정밀 측정값으로 취급하지 않는다.
3. 레터박스·타이틀·자막·검은 전환 프레임은 제외한다. 유효 영상 영역 좌표를 기록하고, 원본 해상도에서 측정한다. 풍경 안의 실제 검은 그림자는 제외하지 않는다.

## 밝기와 하이라이트

- 범위가 확인된 비선형 Rec.709 RGB를 0–1로 정규화하고 `Y′ = 0.2126R′ + 0.7152G′ + 0.0722B′`, `IRE = 100Y′`로 계산한다. 감마를 역변환한 선형 RGB로 계산하지 않는다. 디코더가 이미 video range를 full range로 확장했다면 다시 확장하지 않는다.
- 유효 영상 영역 전체의 Y′를 정렬해 P10/P50/P95를 구한다. 표의 괄호 속 그늘·하늘 등은 해석을 돕는 예시이며, 퍼센타일이 그 물체만 측정한다는 뜻은 아니다. 건물·하늘의 면적이 다르면 같은 룩도 분포가 달라진다.
- `99 IRE 이상 비율 = 해당 픽셀 수 / 유효 영상 픽셀 수 × 100`이다. 밝은 픽셀의 비율이지 클리핑의 증거는 아니다. RGB Parade의 개별 채널 포화, 평평해진 파형, 디테일 손실을 별도로 확인한다. 특히 빨간 네온은 Y′가 99 IRE 미만이어도 R 채널이 포화될 수 있다.
- 표의 고휘도 상한은 대표 앵커의 시작 기준이다. 넓은 흰 벽·눈·광원 코어 때문에 초과해도 디테일이 남으면 자동으로 노출을 낮추지 않는다. 이유와 관찰을 기록하고 해당 항목을 예외로 둔다. 없어진 디테일을 수치만 낮춰 복구했다고 보고하지 않는다.

## 색 군집의 반경

1. 기본 보정 프레임에서 실제 수목·하늘·벽돌 등 표에 해당하는 물체 영역(ROI)을 고르고 좌표 또는 마스크를 저장한다. 전후에 같은 영역을 쓰며, 수치에 맞는 픽셀만 골라내지 않는다. 해당 물체나 신뢰할 중립 표본이 없으면 `해당 없음`이다.
2. 같은 Rec.709 RGB에서 `Cb = (B′ − Y′) / 1.8556`, `Cr = (R′ − Y′) / 1.5748`을 구한다. 각 픽셀의 반경은 `sqrt(Cb² + Cr²)`이다.
3. RGB의 R·Y·G·C·B·M 100% 컬러바 값을 같은 식으로 Cb/Cr에 투영한 육각형을 기준으로 한다. 중심에서 픽셀의 색상 방향으로 그은 선과 육각형 경계의 교점 반경을 100%로 두어 픽셀 반경을 정규화한다. 군집 값은 ROI 픽셀들의 정규화 반경 **중앙값**이다. 무채색 중심은 0%로 둔다.
4. Resolve Vectorscope를 눈으로 읽으면 표시 배율과 75%/100% target 설정을 기록한다. 위 정규화와 맞출 수 없으면 정밀 수치로 비교하지 않고 `추정`으로 남긴다. 화면의 100% 배율과 100% 컬러바 target은 같은 뜻이 아니다.

## 판정과 기록

룩별 ±IRE·±%p는 스타일 허용 폭이며 측정 불확실성을 뜻하지 않는다. 화면만 보고 percentile이나 ROI 중앙값을 정확히 알 수 없으면 `추정`, 신호·영역을 확인할 수 없으면 `미측정`으로 기록한다. 추정치가 경계 근처이면 통과라고 단정하지 않는다.

로그에는 프레임·유효 영역·색 ROI·측정 도구·출력 설정·노드 위치·전후 수치·목표와의 차이·예외 이유를 남긴다. 대표 프레임 뒤에는 같은 클립의 시작·중간·끝과 인접 컷을 재생해 깜빡임·색 깨짐을 확인한다. 모든 컷을 앵커의 픽셀 분포로 맞추지 않는다.

기존 `exposure_scope.py`는 8비트 JPEG의 Pillow 회색 변환을 4배 한 밝기 근사치다. 이 문서의 Rec.709 퍼센타일·IRE·색 ROI를 구현한 도구가 아니므로 Look 수치 측정에 그대로 사용하지 않는다.
