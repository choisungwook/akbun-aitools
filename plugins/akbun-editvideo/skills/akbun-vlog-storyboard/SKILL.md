# akbun-vlog-storyboard

촬영과 화면 녹화를 시작하기 전에 보는 영화식 스토리보드다. 컷 하나가 비트 하나다. 비트 시트가 있으면 그것을 그리고, 없으면 `akbun-vlog-shootplan`의 질문표와 스타일 선택으로 비트 시트를 먼저 만든 뒤 그린다. 카메라 샷의 구도·치수는 `akbun-vlog-shotsketch`의 샷 유형 표와 그림 규칙을 그대로 쓴다. 편집은 하지 않는다.

전제: 화자는 얼굴을 드러내지 않는다. 촬영은 대부분 집 안 책상이다. 장비는 종류로만 부른다(카메라, 마이크, 화면 녹화).

## 용어

- 음성(A-roll): 비트에서 말할 내용. 소리로만 쓰인다. 찍으면서 말하든 따로 내레이션으로 녹음하든 상관없다
- B-roll: 카메라로 찍는 화면 클립. 종류를 제한하지 않는다
- 화면 녹화: 컴퓨터 화면을 OBS 같은 녹화 도구로 담는 것. 무엇을 보여 줄지가 이 skill의 핵심 출력이다
- 카드: `davinciresolve-gfx-hyperframes`가 만들 모션 그래픽. 찍지 않으므로 스토리보드에는 자리와 내용만 적는다

## 출력

컷마다 그림 한 장 + 표 하나, 마지막에 화면 녹화 목록과 OBS 설정이다. 그림은 이미지 생성 도구가 있으면 `<출력 폴더>/storyboard/<번호>-<비트>.png`로 저장하고, 없으면 컷마다 영어 프롬프트를 낸다. 표와 목록은 항상 낸다. 전체를 `storyboard_<YYYYMMDD>.md`로 남긴다.

### 컷 그림 규칙

`akbun-vlog-shotsketch`의 그림 규칙(16:9, 회색 연필 선, 빨간 선은 카메라 축·시선만, 얼굴 없음)에 아래를 더한다.

- 컷 왼쪽 위에 번호와 비트 이름, 오른쪽 위에 분량(`0:45`)을 손글씨로.
- 화면 종류를 프레임 안 왼쪽 아래 작은 라벨로: `B-ROLL`, `SCREEN`, `CARD`.
- 화면 녹화 컷은 카메라 대신 모니터 화면 자체를 프레임으로 그리고, 보여 줄 창(터미널·에디터·브라우저)을 큰 사각형으로, 커서 위치를 빨간 점으로 표시.
- 카드 컷은 카드 레이아웃(제목·상자·화살표)을 굵은 선으로 대강 그린다.

### 컷 표

컷마다 내는 표 예시다.

```markdown
| 항목 | 값 |
|---|---|
| 컷 | 03 원리 1 namespace |
| 분량 | 0:40 |
| 음성(A-roll) | "프로세스가 보는 세계를 namespace가 나눕니다" 등 3문장, 첫 문장이 메시지 |
| 화면 | 화면 녹화 25초 → B-roll 15초 |
| 화면 녹화 내용 | 터미널에서 `lsns` 실행, 결과 표 중 pid 열을 커서로 훑는다. 에디터 창은 닫는다 |
| B-roll | 손이 노트에 상자 두 개를 그리는 탑다운(shotsketch 유형: 탑다운) |
| 카드 | 원리 카드: 상자 2개와 화살표, 라벨 `PID` `NET` |
| 자막·키워드 | 키워드 `namespace` 등장 |
| 확인 | 화면 녹화에 알림·개인 정보(이메일·토큰) 없음 |
```

## 화면 녹화 목록과 OBS 설정

스토리보드 끝에 화면 녹화만 모아 표로 만든다. 사용자는 이 표 순서대로 OBS를 켜고 한 번에 녹화한다.

```markdown
| 순서 | 컷 | 보여 줄 창 | 할 일(커서·입력) | 길이 | 준비 |
|---|---|---|---|---|---|
| 1 | 03 | 터미널 전체 화면 | `lsns` 실행 → 결과 위에서 pid 열 훑기 | 0:30 | 글꼴 18pt, 히스토리 비우기 |
| 2 | 05 | 브라우저 문서 | 해당 절로 스크롤 → 문장 드래그 | 0:20 | 북마크바 숨김 |
```

OBS 기본값이다. 사용자가 다른 값을 쓰면 그것을 따른다.

| 항목 | 값 | 이유 |
|---|---|---|
| 캔버스·출력 해상도 | 모니터 해상도 그대로(4K 모니터면 3840×2160) | 편집 타임라인 4K에서 흐려지지 않게 |
| 프레임레이트 | 30fps(타임라인과 같게) | 프레임 변환 없이 붙이기 |
| 소스 | 창 캡처(터미널·에디터·브라우저 각각) | 다른 창·알림이 들어오지 않게 |
| 커서 | 표시, 크게(OS 접근성 설정) | 무엇을 보는지 보이게 |
| 오디오 | 마이크 트랙과 시스템 소리 트랙 분리(트랙 1 마이크, 트랙 2 시스템) | 편집에서 음성만 A1에 쓰기 |
| 인코더 | 하드웨어 H.264 또는 H.265, CQP 18~20 | 글자 깨짐 없이 |
| 녹화 전 | 알림 끄기(집중 모드), 개인 정보가 보이는 탭·터미널 히스토리 정리, 에디터 글꼴 16pt 이상 | 재촬영 방지 |

## 하지 않는 것

- 얼굴이 보이는 컷, 장비 제품명
- 특정 종류의 B-roll 강요. 사용자가 찍을 수 있는 것으로 채운다
- 분량 없는 컷. 컷 분량의 합은 style skill의 총길이(10분 미만) 안이다
- 화면 녹화 내용을 "코드 화면"처럼 뭉뚱그리기. 어느 창에서 무엇을 실행하고 커서가 어디를 가는지까지 적는다
- 영상 편집
