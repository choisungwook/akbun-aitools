# akbun-davinciresolve-explainer-scribble-black

## 목적

설명하는 사람이 어두운 보드에 바로 써 내려가는 느낌의 얼굴 없는 설명 영상을 만든다. 결과물은 Resolve에서 고칠 수 있는 타임라인이다. 장면마다 Fusion 클립 하나이고, 글씨·등장 시점·보이기를 Edit 페이지 Inspector에서 바꾼다.

## 범위

- 사용자가 직접 호출할 때 실행한다.
- **스타일 원본**: 색·선·도형·글씨·그리는 속도·"한 번에 한 획" 규칙·시각 맞추기는 [akbun-draw-scribble-black의 "스타일"](../../../akbun-draw/skills/akbun-draw-scribble-black/SKILL.md#스타일)이 원본이다. 이 문서는 Resolve로 옮기는 데 필요한 값만 옮겨 적고, 어긋나면 draw skill을 따른다. Resolve 때문에 일부러 다르게 하는 것은 하나다: 도형 획은 경로를 따라 그려지지 않고 긋는 방향으로 드러난다.
- **클립 구조**: [공통 "Resolve 구현"](../akbun-davinciresolve-explainer/references/resolve-core.md#resolve-구현)을 따른다(Fusion 타이틀 + Template 매크로, `Timing` 노드, 표현식 애니메이션, 제너레이터 길이 조정, Inspector 설계, 마커 API, 성능 규칙). 공통 구현의 "사실 확인"과 "민감 정보 규칙"도 적용한다.
- **대신하는 것**: 공통 구현의 "내레이션 규칙"과 장면 전환 규칙. 무엇을 어디에 몇 개 둘지는 장면이 설명하는 관계가 정하고, 배치 고르는 기준은 draw skill의 "하지 말 것" 첫 줄을 따른다(흐름을 기본으로 왼쪽→오른쪽에 두지 않는다).
- 그리는 손·사람 얼굴·실사 컷을 넣지 않는다. 렌더된 MP4로 장면을 대신하지 않는다.
- 녹음 정리는 [akbun-davinciresolve-narration-cleanup](../akbun-davinciresolve-narration-cleanup/SKILL.md)을 부른다.

## 캔버스

- 1920×1080이 기본, 쇼츠는 1080×1920 타임라인이다. fps는 대상 타임라인 값(기준이 없으면 30)이고 표현식의 `fps`에는 소수까지 그대로 넣는다.
- Text+ 좌표·크기는 화면 폭 W(가로 1920, 세로 1080)로 쓴다: Size = px ÷ W, Center = (px ÷ W, 1 − py ÷ H).
- 모든 장면의 배경은 Background 노드 BOARD(`#0E0E10`) 하나다. 장면이 바뀌어도 같다.

## 획 레이어 만들기

draw skill의 SVG 규칙대로 장면을 그린 뒤, 획(또는 한 번에 그리는 도형 하나)마다 그것만 남긴 SVG(글씨·시간 속성 없음, 화면 전체 viewBox)를 만든다. 사물 채움(FILL과 점)은 별도 레이어 하나다.

레이어 SVG마다 장면 하나(길이 1프레임)를 둔 spec을 MOV로 렌더하면 `--stills`가 레이어별 투명 PNG를 만든다.

```bash
uv run --python 3.12 <doodle>/scripts/render_doodle.py <출력>/layers_spec.json <출력>/layers.mov --stills <출력>/layers
```

- `<doodle>`은 [akbun-draw-motion-doodle](../../../akbun-draw/skills/akbun-draw-motion-doodle/SKILL.md) 디렉터리다. 장면 `id`가 PNG 이름이 된다(`NN_<id>_1.png`).
- 획마다 bbox(px), 긋는 방향(왼→오, 오→왼, 위→아래, 아래→위), 획 길이(px)를 장면 표에 적는다. 원·구름처럼 닫힌 도형은 방향을 "왼→오"로 둔다.

## Fusion 구성

| 노드 | 이름 | 연결 |
|---|---|---|
| Background | `보드` | BOARD 단색 → MultiMerge Background |
| Loader + RectangleMask | `획_<이름>` / `드러남_<이름>` | 획 PNG에 마스크. 긋는 방향의 시작 변을 bbox에 고정하고 마스크 크기를 늘린다 |
| Loader | `채움_<사물>` | 사물 채움 PNG |
| Text+ | `글씨_<이름>` | Font `Gaegu`, Style `Bold`. 색은 draw skill 색 표(PEN·GRAY·SKY·ORANGE·YELLOW·RED) |
| MultiMerge | `레이어_목록` | 레이어 순서 = 채움 → 획 → 글씨 |
| Background | `Timing` | 화면에 연결하지 않는다. `Sig{k}`(신호 단어 시각), `At{k}`(실제 시작 시각, 둘째부터 표현식), `On{k}` 컨트롤 |

- 색은 hex를 0~1로 바꿔(각 값 ÷ 255, 소수 넷째 자리 반올림) Text+ `Red1`·`Green1`·`Blue1`에 넣는다.
- 그림자·Glow·그라디언트·질감 노드를 넣지 않는다.

## 모션

길이는 draw skill의 모션 표를 따른다. `fps`는 숫자로 넣는다.

- `A(t0)` = `time - (comp.RenderStart + t0 * fps)`, `q(t0, d)` = `min(1, max(0, A(t0) / (d * fps)))`

| 움직임 | 입력 | 식 |
|---|---|---|
| 획 드러나기 | `드러남_<이름>`의 Width(가로 방향) 또는 Height(세로 방향)와 Center | p = `q(Timing.At{k}, d)`, d = 획 길이(px) ÷ 600을 0.05초 단위로 올림(최소 0.25). 크기 = bbox 크기 × p, Center는 시작 변 + 크기 ÷ 2(Fusion 좌표) |
| 글씨 쓰기 | Text+ `Write On`의 End | `q(Timing.At{k}, d)`, d = 글자 수(공백 포함) ÷ 5를 0.05초 단위로 올림(최소 0.3). Start는 0 |
| 채움 나타나기 | `Layer{n}.Blend` | `iif(A(Timing.At{k}) < 0, 0, 1)` |
| 보드 지우기 | 다음 장면 | 하드 컷 |

- **한 번에 한 획**: 빌드는 겹치지 않는다. 다음 빌드의 `At` ≥ 앞 빌드의 `At` + 길이 + 0.1초. Inspector에서 시점 하나를 옮기면 뒤 빌드도 같이 밀리도록, 둘째 빌드부터 실제 시작 시각을 `max(Timing.Sig{k}, Timing.At{k-1} + d{k-1} + 0.15)` 표현식으로 둔다. `Sig{k}`는 그 획의 신호 단어 시각(초)이다.
- 글씨 레이어에만 `Timing.On{k}`(보이기)를 곱한다.
- 마지막 빌드는 장면 끝 1.0초 전까지 끝낸다(대본 마지막 단어 때문이면 0.5초까지). 장면 하나는 25초 이하다.
- 카메라는 쓰지 않는다. 같은 보드에 이어 쓰는 장면은 앞 장면 레이어를 새 장면 0초부터 다 그려진 채로 보이게(`Timing.At` = `-100`) 두고 새 획만 드러낸다.
- 시점은 `Timing` 컨트롤로만 바꾼다. 키프레임을 쓰지 않는다.

## 작업 흐름

1. **장면 표**: 장면마다 획 순서(획·글씨·채움), 색 글씨, 획별 신호 단어와 시작·끝 시각, 길이를 적는다. 시각은 draw skill의 신호 단어 규칙을 따르고, 획이 겹치지 않는지 표에서 확인한다. 사용자에게 먼저 보여 주고 확인받는다.
2. **획 레이어 PNG**: "획 레이어 만들기"대로 획·채움 레이어를 만든다.
3. **Resolve 준비**: 다른 작업이 열어 둔 프로젝트·타임라인을 확인 없이 바꾸지 않는다. 새 타임라인(V1 장면, A1 내레이션, A2 BGM, A3 효과음)을 만든다. `fc-list : family`로 Gaegu 설치를 본다.
4. **대표 장면 하나**로 삽입·매크로·길이·Inspector·획 드러나기·Text+ 써지기·시점 이어 밀기를 확인한 뒤 나머지를 만든다.
5. **장면 삽입과 빌드**: 공통 구현의 "클립 길이 맞추기"로 장면을 끝에 차례로 붙이고, "Fusion 구성"대로 노드를 만들어 표현식을 건다. Template 매크로로 감싸 공통 구현의 Inspector 설계대로 공개한다(글씨 칸, 보이기, 등장 시점).
6. **마커**: 장면 시작마다 대본 메모 마커를 단다.
7. **녹음 뒤**: 음성 인식 단어 시각에서 신호 단어를 찾아 `Sig` 값과 장면 길이를 다시 맞춘다(앞 획이 늦게 끝나면 뒤 획은 표현식으로 밀린다). 못 찾은 신호 단어는 추측하지 말고 목록으로 보고한다.
8. **검수**: 아래 표로 채점한다.

## 검수

장면마다 첫 획 직후·중간·마지막 프레임을 `ExportCurrentFrameAsStill`로 뽑아 한 장으로 붙여 한 번만 본다. 항목마다 0·5·10점, 80점 미만 장면은 고친다.

| # | 항목 | 10점 기준 |
|---|---|---|
| 1 | 보드 | 모든 장면이 BOARD(검정) 단색, 흰 선, 질감·그라디언트 없음 |
| 2 | 색 | 글씨 색이 draw skill 색 표 안, 색 글씨는 화면당 3가지 이하·노랑은 하나 |
| 3 | 글씨 | Gaegu Bold, 대체 글꼴 없음, 한 묶음 길이 규칙 안 |
| 4 | 획 | 레이어 PNG 그대로(번짐·잘림 없음), 긋는 방향으로 드러남 |
| 5 | 한 번에 한 획 | 두 곳이 동시에 그려지는 순간 없음 |
| 6 | 순서·모양 | 말풍선·구름 외곽선 → 꼬리 → 안의 글씨, 사물 외곽선 → 채움. 구름은 크기가 다른 혹, 말풍선은 타원 + 휜 꼬리 |
| 7 | 속도 | 획 길이 ÷ 600, 글자 수(공백 포함) ÷ 5 규칙과 0.05초 안에서 같음 |
| 8 | 인물 | 막대 인물 머리가 빈 원, 손·얼굴·실사 없음 |
| 9 | 배치 | 글씨가 도형 밖으로 넘치지 않음, 장면마다 같은 배치를 기계적으로 반복하지 않음 |
| 10 | 전환 | 하드 컷, 카메라 없음, 이어지는 장면은 앞 보드가 그대로 이어짐 |

- 클립·마커 개수와 끝 프레임을 장면 표와 대조한다.
- Inspector에서 첫 빌드 시점을 바꿔 뒤 빌드가 같이 밀리는지 확인하고 되돌린다. 프로젝트를 저장한다.
- 실제 로고·알려진 캐릭터·영상 장면과 닮아 보이는 화면이 없는지 본다. 닮았으면 도형이나 배치를 바꾼다.

## 완료 보고

타임라인 이름·fps·길이, 장면 표, 레이어 폴더 경로, 장면별 채점 점수, 글꼴 확인, 환경설정 복원 확인 결과를 적는다. 화면으로 보지 않고 스틸로만 확인한 것은 그렇게 적는다.

## 하지 말 것

- 렌더된 MP4로 장면을 대신하거나, 글씨를 PNG로 굽지 않는다.
- 빌드를 겹치게 두지 않는다.
- 카메라, 키프레임 애니메이션을 쓰지 않는다.
- 그리는 손·사람 얼굴·실사 컷을 넣지 않는다.
- 다른 작업이 열어 둔 Resolve 프로젝트를 확인 없이 바꾸지 않는다.
