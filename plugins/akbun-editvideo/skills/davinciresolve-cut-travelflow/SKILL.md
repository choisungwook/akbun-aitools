# davinciresolve-cut-travelflow

컷 편집 스타일 중 하나다. 이름의 travelflow는 "말소리 없는 여행 영상, 영상 흐름과 자연음이 편집의 기준"이라는 뜻이다. 다른 스타일(예: 인터뷰 중심, 빠른 몽타주)은 이 skill을 고치지 않고 `davinciresolve-cut-<스타일>`로 따로 만든다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인에서만 편집, 클립은 파일명 + 시작 타임코드로 지정, 대표 클립 1개 선적용, 작업 로그 기록)을 그대로 따른다.

## 장비별 기본값

클립의 카메라는 메타데이터에서 읽는다. 메타데이터에 없으면 파일명 패턴(iPhone `IMG_####.MOV`, Insta360 `VID_########_######_*.mp4`)으로 추정하고 작업 로그에 `추정`이라고 적는다.

| 장비 | 앞뒤 트림 | 안정화 | 이유 |
|---|---|---|---|
| iPhone | 앞부분 셔터 조절 구간 제거 후보(기본 약 1초) | 흔들림이 감지된 클립에만 | 녹화 시작 직후 노출·초점이 잡히는 동안 흰 화면이나 초점 이탈이 생김 |
| Insta360 Luna Ultra | 자르지 않음 | 적용하지 않음 | 짐벌 촬영이라 시작부터 안정적. 안정화를 더하면 크롭과 휘어짐만 생김 |

## 컷 편집

- 단순히 클립 길이만 줄이지 않는다. 클립마다 초점, 노출, 흔들림 상태를 먼저 분석한다. 분석 수단은 `davinciresolve-video-editor`의 `references/agent-api.md` 대체 방법 표를 따른다.
- iPhone 영상 앞부분에 흰 화면이나 초점 이탈이 있으면 해당 구간만 제거한다. 기본 후보 길이는 약 1초지만, 실제 정상 프레임이 시작되는 지점을 기준으로 자른다. 정상 프레임 판정 기준은 밝기 평균이 클립 중간 구간 평균의 ±20% 안에 들고 초점 지표(라플라시안 분산)가 중간 구간의 70% 이상인 첫 프레임이다.
- 판정 근거가 없는 클립(프레임 추출 실패 등)은 자르지 않고 검토 마커를 찍는다.
- 흔들림, 중복 장면, 구도 실패 구간은 삭제하기 전에 검토 마커를 추가하고 사용자 확인을 받는다. 확인 없이 삭제하지 않는다.
- 중복 장면은 같은 장소·같은 구도로 촬영 시간이 2분 이내인 클립 묶음이다. 묶음 안에서 초점·노출·흔들림이 가장 좋은 1개를 남기는 것을 제안한다.

검토 마커 규칙이다.

| 마커 색 | 이름 | 뜻 |
|---|---|---|
| Yellow | `CUT_REVIEW <사유>` | 삭제 제안. 사유는 `shaky`, `duplicate`, `framing`, `unknown` 중 하나 |
| Red | `CUT_DONE <사유>` | 사용자 확인 뒤 실제로 자른 구간의 시작점 |

## 안정화

- iPhone 영상 중 흔들림이 감지된 클립에만 Stabilization을 적용한다. 감지는 프레임 간 움직임 벡터의 표준편차 또는 Resolve Stabilizer 분석 결과로 하고, 근거 없이 "흔들려 보인다"로 적용하지 않는다.
- Insta360 Luna Ultra 영상은 기본적으로 안정화를 적용하지 않는다. 사용자가 특정 클립을 지정하면 그 클립만 예외로 하고 로그에 이유를 적는다.
- Resolve Stabilizer 기본값은 Mode `Similarity`, Cropping Ratio 0.5, Smooth 0.25, Zoom 켬이다. 결과에서 크롭이 10%를 넘거나 화면 가장자리가 휘면 Smooth를 0.1씩 낮추고, 0.05에서도 휘면 안정화를 끄고 검토 마커(`CUT_REVIEW shaky`)로 넘긴다.
- 안정화 전후를 같은 프레임 스틸로 비교하고 작업 로그에 적용값과 크롭 비율을 남긴다.

## 편집 결과 조정

- 컷이 바뀌면 자막, 효과음, 전환 효과의 위치도 함께 이동한다. 자막은 `davinciresolve-subtitle-travelnote`, 오디오는 `davinciresolve-audio-delivery`에 바뀐 구간 목록(파일명, 이전 시작 TC, 새 시작 TC, 길이 변화)을 넘긴다.
- 미리보기용 화면 분할이나 좌우 크롭은 명확한 목적이 없으면 쓰지 않는다.
- 장면 전환은 단순 컷을 기본으로 하고, 시간이나 장소가 크게 바뀌는 지점에만 짧은 디졸브(12~20프레임)를 쓴다. 영상 호흡을 해치는 화려한 전환은 쓰지 않는다.

## 작업 로그

작업 로그 `3. 컷·안정화` 절에 아래 표를 채운다.

```markdown
| 파일명 | 시작 TC | 장비 | 판정 | 조치 | 근거 |
|---|---|---|---|---|---|
| IMG_1234.MOV | 00:00:12:00 | iPhone | 앞 0.8초 흰 화면 | 00:00:00:24까지 제거 | 밝기 평균 238→112, 초점 지표 회복 프레임 24 |
| IMG_1240.MOV | 00:01:02:10 | iPhone | 흔들림 | Stabilizer Smooth 0.25, 크롭 6% | 움직임 표준편차 2.1 → 0.4 |
| VID_20250901_101010_00_001.mp4 | 00:02:30:00 | Insta360 | 정상 | 없음 | 짐벌 클립, 기본값 유지 |
```

## 하지 않는 것

- 사용자 확인 없는 클립 삭제
- Insta360 Luna Ultra 클립의 트림·안정화(사용자 지정 예외 제외)
- 근거 없는 안정화 적용
- 목적 없는 화면 분할·좌우 크롭·화려한 전환
- 컷 변경 뒤 자막·효과음 위치를 그대로 두는 것
