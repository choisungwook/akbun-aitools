# davinciresolve-subtitle-travelnote

자막 스타일 중 하나다. 이름의 travelnote는 "여행 노트처럼 장소·시간·분위기를 한 줄로 적는 담백한 자막"이라는 뜻이다. 다른 스타일(예: 대사 자막, 예능형 강조 자막)은 이 skill을 고치지 않고 `davinciresolve-subtitle-<스타일>`로 따로 만든다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 클립은 파일명 + 시작 타임코드, 대표 자막 1개 선적용, 작업 로그)과 마커 등록표를 따른다. 자막은 Fusion Text+로 만들고, 스크립팅 API가 있으면 `InsertFusionTitleIntoTimeline("Text+")` 뒤 `GetFusionCompByIndex(1)`로 Text+ 툴의 `StyledText`·`Font`·`Style`·`Size` 입력을 설정한다.

## 글꼴

- 기본 글꼴: Gmarket Sans. 시스템에 설치돼 있는지 먼저 확인하고(`fc-list | grep -i gmarket` 또는 Resolve 글꼴 목록), 없으면 멈추고 설치 경로를 안내한다. 다른 글꼴로 대체하지 않는다.
- 한글 자막은 Medium, 챕터 제목은 Bold를 쓴다.
- 자막 크기, 자간, 행간을 전체 영상에서 통일한다. 아래 표의 값을 대표 자막 1개에서 확정하고 모든 자막에 같은 값을 쓴다.
- 흰색 글자(`#FFFFFF`)에 약한 그림자 또는 반투명 배경을 기본으로 한다. Text+ Shading Element 2를 쓰고 값은 픽셀이 아니라 상대값이므로, 대표 자막 스틸에서 글자 가장자리가 밝은 배경·어두운 배경 모두에서 구분되는 최소 강도로 정해 로그에 적는다. 밝은 배경 위에서는 반투명 배경(검정, 불투명도 35%), 어두운 배경 위에서는 그림자를 쓴다.

## 크기

자막은 4K 화면에서 멀리서도 읽혀야 한다. Text+ 기본값(Size 0.08)보다 50% 큰 0.12를 쓴다. 글자 높이의 픽셀 값은 글꼴마다 다르므로 스틸로 잰다.

| 항목 | 값 | 정하는 방법 |
|---|---|---|
| Text+ Size(자막) | 0.12 | 고정. Fusion Text+ 기본값 0.08 × 1.5 |
| Text+ Size(챕터 제목) | 0.16 | 고정. 자막의 약 1.3배 |
| 글자 높이(4K 기준) | 측정값 | 대표 자막 스틸에서 한글 한 글자 높이를 재서 로그에 적는다. 화면 높이의 5% 미만이면 자막으로 작다고 보고 사용자에게 알린다 |
| 자간(Tracking) | 1.0(기본) | 한글은 자간을 벌리면 흐트러짐 |
| 행간(Line Spacing) | 1.2 | 2줄일 때 줄이 붙지 않는 최소값 |
| 한 줄 최대 글자 수 | 측정값 | Size 0.12에서 안전 영역 폭(화면 폭의 90%) 안에 들어가는 글자 수를 대표 자막 스틸로 재서 정한다. 시작 후보는 18자 |
| 최대 줄 수 | 2줄 | 화면을 가리지 않는 한계 |

크기는 줄이지 않는다. 문장이 안 들어가면 글자 수를 줄이거나 2줄로 나눈다. Text+가 아니라 레거시 Text 타이틀이나 Subtitle 트랙을 쓸 때는 대표 자막 스틸에서 글자 높이가 Text+ 0.12와 같아지게 크기를 맞추고 로그에 실제 값을 적는다.

## 위치와 안전 영역

- 기본 위치는 화면 하단 가운데. 하단 여백은 화면 높이의 8%(4K에서 약 173px), 좌우 여백은 화면 폭의 5% 이상.
- 화면의 주요 피사체와 얼굴을 가리지 않는다. 하단에 피사체가 있으면 상단 가운데(상단 여백 8%)로 옮기고 로그에 이유를 적는다.
- 챕터 제목은 장면 시작 0.5초 뒤 화면 하단 왼쪽(좌하단 여백 8%)에 3초 표시한다. 챕터 제목이 표시되는 동안에는 자막을 넣지 않는다. 자막은 챕터 제목이 끝난 뒤 시작한다.
- 좌우 크롭이나 과도한 애니메이션을 피한다. 등장·퇴장은 8프레임 페이드만 쓴다.

## 스타일

- 자막은 짧고 담백하게 쓴다. 장면을 그대로 설명("사람들이 걷고 있다")하지 않고 장소, 시간, 분위기("오전 9시, 시장 골목")를 전달한다.
- 한 화면에 긴 문장을 넣지 않는다. 한 줄 최대 글자 수(측정값) 안, 최대 2줄.
- 문장 부호는 쉼표만 쓰고 마침표·느낌표는 쓰지 않는다.
- 사실만 쓴다. 장소명·시간은 클립 메타데이터나 사용자가 준 정보에서 가져오고, 없으면 자막에 넣지 않고 로그에 `확인 필요`로 남긴다.

## 타이밍

- 표시 시간은 글자 수 × 0.15초와 2초 중 큰 값, 최대 6초.
- 자막은 컷 경계와 겹치지 않게 컷 시작 0.5초 뒤에 시작하고 컷 끝 0.3초 전에 끝낸다.
- 클립이 2.8초 미만이면 이 규칙을 지킬 수 없다. 같은 장소의 다음 클립까지 걸쳐 표시하거나(장소가 같을 때만), 그 클립에는 자막을 넣지 않는다. 어느 쪽인지 로그에 적는다.

## 컷 변경 반영

`davinciresolve-cut-travelflow`가 넘긴 바뀐 구간 목록(`파일명 | 이전 시작 TC | 새 시작 TC | 길이 변화(프레임)`)을 받으면 아래를 한다.

1. 자막 클립마다 어느 영상 클립에 붙어 있는지 파일명으로 찾는다.
2. 새 시작 TC 기준으로 자막 시작·종료를 다시 계산한다. 자막 클립 이동 API가 없으므로 새 위치에 다시 삽입하고 옛 자막을 삭제한다.
3. 챕터 타임라인 마커는 클립을 따라가지 않으므로 새 시작 TC로 다시 찍고 옛 마커를 지운다.
4. 옮긴 결과를 `7. 자막·챕터` 표에 "재타이밍" 비고와 함께 적는다.

## 챕터 마커

- 장소가 바뀌는 지점에 Blue 타임라인 마커 `CHAPTER <장소명·행사명>`을 추가한다. 첫 마커는 타임라인 첫 프레임(frameId 0, 시작 타임코드가 01:00:00:00이어도 첫 프레임)에 두고, 마커 사이 간격은 10초 이상(YouTube 챕터 최소 길이).
- YouTube는 챕터를 3개 이상 요구한다. 장소 변경이 2곳 이하면 시간대나 행사로 나눌 수 있는지 보고, 그래도 3개 미만이면 챕터를 만들지 않고 `확인 필요`로 남긴다.
- 마커 이름은 검색하기 쉬운 장소명과 행사명을 쓴다. 예: `광안리 드론쇼`, `부산 자갈치시장`. 분위기 표현("설레는 아침")은 자막에만 쓰고 마커에는 쓰지 않는다.
- 렌더 뒤 YouTube 설명란에 붙일 챕터 목록을 작업 로그에 남긴다. 형식은 `mm:ss 이름`, 영상이 60분을 넘으면 `hh:mm:ss 이름`.

## 작업 로그

작업 로그 `7. 자막·챕터` 절에 아래 표를 채운다.

```markdown
확정값: Size 0.12, 글자 높이 176px(화면 높이 8.1%), 한 줄 최대 16자, Shading Element 2 강도 0.6

| 시작 TC | 종료 TC | 종류 | 텍스트 | 위치 | 크기 | 비고 |
|---|---|---|---|---|---|---|
| 00:00:00:00 | - | 챕터 마커 | CHAPTER 부산 자갈치시장 | 타임라인 첫 프레임 | - | |
| 00:00:00:15 | 00:00:03:15 | 챕터 제목 | 부산 자갈치시장 | 좌하단 | 0.16 | |
| 00:00:04:00 | 00:00:07:00 | 자막 | 오전 9시, 시장 골목 | 하단 가운데 | 0.12 | |
| 00:01:20:00 | - | 챕터 마커 | CHAPTER 광안리 드론쇼 | 타임라인 | - | |
| 00:01:24:00 | 00:01:27:00 | 자막 | 저녁, 광안리 | 상단 가운데 | 0.12 | 하단에 인물 |
| 00:03:40:00 | - | 챕터 마커 | CHAPTER 해운대 야경 | 타임라인 | - | |

챕터 목록
00:00 부산 자갈치시장
01:20 광안리 드론쇼
03:40 해운대 야경
```

## 하지 않는 것

- Gmarket Sans 외 글꼴로 대체
- 자막마다 다른 크기·자간·행간, 문장을 넣으려고 크기 줄이기
- 장면을 그대로 설명하는 자막, 확인되지 않은 장소·시간
- 얼굴·주요 피사체 위의 자막, 챕터 제목과 겹치는 자막
- 좌우 크롭, 슬라이드·바운스 같은 애니메이션
- 컷 변경 뒤 자막·챕터 마커 타이밍을 그대로 두는 것
