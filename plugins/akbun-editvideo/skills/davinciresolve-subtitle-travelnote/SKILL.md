# davinciresolve-subtitle-travelnote

자막 스타일 중 하나다. 이름의 travelnote는 "여행 노트처럼 장소·시간·분위기를 한 줄로 적는 담백한 자막"이라는 뜻이다. 다른 스타일(예: 대사 자막, 예능형 강조 자막)은 이 skill을 고치지 않고 `davinciresolve-subtitle-<스타일>`로 따로 만든다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 클립은 파일명 + 시작 타임코드, 대표 자막 1개 선적용, 작업 로그)을 따른다.

## 글꼴

- 기본 글꼴: Gmarket Sans. 시스템에 설치돼 있는지 먼저 확인하고, 없으면 멈추고 설치 경로를 안내한다. 다른 글꼴로 대체하지 않는다.
- 한글 자막은 Medium, 챕터 제목은 Bold를 쓴다.
- 자막 크기, 자간, 행간을 전체 영상에서 통일한다. 아래 표의 값을 한 번 정하고 모든 자막에 같은 값을 쓴다.
- 흰색 글자(`#FFFFFF`)에 약한 그림자(검정, 불투명도 60%, 오프셋 2px, 블러 4px) 또는 반투명 배경(검정, 불투명도 35%, 좌우 패딩 글자 높이의 40%)을 기본으로 한다. 밝은 배경 위에서는 반투명 배경, 어두운 배경 위에서는 그림자를 쓴다.

## 크기

자막은 4K 화면에서 멀리서도 읽혀야 한다. Text+ 기본값(Size 0.08)보다 50% 크게 잡는다.

| 항목 | 값 | 근거 |
|---|---|---|
| Text+ Size(자막) | 0.12 | Fusion Text+ 기본값 0.08 × 1.5 |
| Text+ Size(챕터 제목) | 0.16 | 자막의 약 1.3배 |
| 글자 높이(4K 기준) | 약 화면 높이의 5%(약 108px) | Size 0.12에 해당하는 렌더 결과. 스틸로 확인 |
| 자간(Tracking) | 1.0(기본) | 한글은 자간을 벌리면 흐트러짐 |
| 행간(Line Spacing) | 1.2 | 2줄일 때 줄이 붙지 않는 최소값 |
| 한 줄 최대 글자 수 | 18자 | Size 0.12에서 안전 영역 폭 안에 들어가는 길이 |
| 최대 줄 수 | 2줄 | 화면을 가리지 않는 한계 |

Text+가 아니라 레거시 Text 타이틀이나 Subtitle 트랙을 쓸 때는 렌더된 글자 높이가 화면 높이의 5%가 되게 크기를 맞추고 로그에 실제 값을 적는다.

## 위치와 안전 영역

- 기본 위치는 화면 하단 가운데. 하단 여백은 화면 높이의 8%(4K에서 약 173px), 좌우 여백은 화면 폭의 5% 이상.
- 화면의 주요 피사체와 얼굴을 가리지 않는다. 하단에 피사체가 있으면 상단 가운데(상단 여백 8%)로 옮기고 로그에 이유를 적는다.
- 챕터 제목은 장면 시작 0.5초 뒤 화면 하단 왼쪽(좌하단 여백 8%)에 넣는다.
- 좌우 크롭이나 과도한 애니메이션을 피한다. 등장·퇴장은 8프레임 페이드만 쓴다.

## 스타일

- 자막은 짧고 담백하게 쓴다. 장면을 그대로 설명("사람들이 걷고 있다")하지 않고 장소, 시간, 분위기("오전 9시, 시장 골목")를 전달한다.
- 한 화면에 긴 문장을 넣지 않는다. 한 줄 18자, 최대 2줄.
- 문장 부호는 쉼표만 쓰고 마침표·느낌표는 쓰지 않는다.
- 사실만 쓴다. 장소명·시간은 클립 메타데이터나 사용자가 준 정보에서 가져오고, 없으면 자막에 넣지 않고 로그에 `확인 필요`로 남긴다.

## 타이밍

- 최소 표시 시간은 2초, 글자 수 × 0.15초와 2초 중 큰 값을 쓴다. 최대 6초.
- 자막은 컷 경계와 겹치지 않게 컷 시작 0.5초 뒤에 시작하고 컷 끝 0.3초 전에 끝낸다.
- 컷 변경 후 자막의 시작과 종료 시점을 다시 맞춘다. `davinciresolve-cut-travelflow`가 넘긴 바뀐 구간 목록(파일명, 이전 시작 TC, 새 시작 TC, 길이 변화)으로 자막 위치를 옮기고, 옮긴 결과를 로그에 적는다.

## 챕터 마커

- 장소가 바뀌는 지점에 YouTube 챕터 마커(Blue)를 추가한다. 첫 마커는 00:00:00:00에 두고, 마커 사이 간격은 10초 이상(YouTube 챕터 최소 길이).
- 마커 이름은 검색하기 쉬운 장소명과 행사명을 쓴다. 예: `광안리 드론쇼`, `부산 자갈치시장`. 분위기 표현("설레는 아침")은 자막에만 쓰고 마커에는 쓰지 않는다.
- 렌더 뒤 YouTube 설명란에 붙일 챕터 목록을 `mm:ss 이름` 형식으로 작업 로그에 남긴다.

## 작업 로그

작업 로그 `7. 자막·챕터` 절에 아래 표를 채운다.

```markdown
| 시작 TC | 종료 TC | 종류 | 텍스트 | 위치 | 크기 | 비고 |
|---|---|---|---|---|---|---|
| 00:00:00:12 | 00:00:03:12 | 챕터 제목 | 부산 자갈치시장 | 좌하단 | 0.16 | |
| 00:00:04:00 | 00:00:07:00 | 자막 | 오전 9시, 시장 골목 | 하단 가운데 | 0.12 | |
| 00:01:20:00 | 00:01:23:00 | 자막 | 저녁, 광안리 | 상단 가운데 | 0.12 | 하단에 인물 |

챕터 목록
00:00 부산 자갈치시장
01:20 광안리 드론쇼
```

## 하지 않는 것

- Gmarket Sans 외 글꼴로 대체
- 자막마다 다른 크기·자간·행간
- 장면을 그대로 설명하는 자막, 확인되지 않은 장소·시간
- 얼굴·주요 피사체 위의 자막
- 좌우 크롭, 슬라이드·바운스 같은 애니메이션
- 컷 변경 뒤 자막 타이밍을 그대로 두는 것
