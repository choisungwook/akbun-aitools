# davinciresolve-bgm-epidemicsound

배경음악을 고르고 넣는 단계다. 검색과 선택은 이 skill이 하고, 레벨·덕킹·마스터 라우드니스는 `davinciresolve-audio-delivery`가 한다. 선택 결과는 반드시 사용자에게 말한다. 후보 표 없이 한 곡만 넣거나, 넣고 나서 말하지 않는 것은 실패다.

`davinciresolve-video-editor`의 기본 원칙(작업 타임라인, 작업 로그, 되돌릴 수 없는 작업은 확인)을 따른다. 트랙은 `davinciresolve-story-devtalk`의 트랙 배치대로 A4 `MUSIC`이다.

## 실행 조건

| 항목 | 확인 | 없을 때 |
|---|---|---|
| Epidemic Sound 플러그인 | Resolve Studio에서 Workspace → Workflow Integrations 메뉴에 Epidemic Sound가 있고 로그인돼 있다 | 무료판·미설치·미로그인이면 멈추고 설치·로그인을 안내한다. 대신 고르지 않는다 |
| 조작 수단 | 플러그인은 스크립팅 API가 없으므로 화면 조작(computer use) | 화면 조작이 안 되면 검색어·후보 조건을 절차서로 남기고, 사용자가 내려받은 파일을 `MediaPool.ImportMedia`로 넣는 것까지만 한다 |

## 음악 브리프

style skill과 비트 시트에서 브리프를 만든다. 스타일별 기본값이고, 사용자가 말한 취향이 있으면 그것이 우선한다.

| 스타일 | 무드·장르 | BPM | 보컬 | 곡 수 |
|---|---|---|---|---|
| essay | 미니멀 일렉트로닉, lo-fi, 가벼운 퍼커션. 카드가 자주 바뀌므로 리듬이 또렷한 곡 | 90~110 | 없음 | 1곡, 결론 비트에서 다른 곡으로 바꿔도 된다(최대 2곡) |
| project | 밝은 lo-fi, 어쿠스틱, 칠 | 80~100 | 없음 | 2곡(작업 구간, 타임랩스 구간) |
| reflection | 피아노, 앰비언트, 스트링. 말이 계속 흐르므로 멜로디가 앞서지 않는 곡 | 60~80 | 없음 | 1곡 |

공통 조건이다. 길이는 영상 총길이 이상이거나 자연스럽게 반복되는 곡. 갑자기 커지는 드롭이 있는 곡은 뺀다.

## 검색

1. 플러그인을 열고 브리프를 문장으로 검색한다(예: `calm lo-fi no vocals for a coding explainer`). 결과가 안 맞으면 무드·장르·BPM·보컬 없음 필터로 좁힌다.
2. 상위 결과에서 30초 이상 들어 보고(플레이어 미리듣기) 후보 3~5곡을 고른다. 비트 시트의 훅과 결론 구간에 각 곡을 대 보고 어울리는지 본다.
3. 후보마다 곡명·아티스트·무드·BPM·길이·후보 이유 한 줄을 표에 적는다.
4. 1곡을 고른다. 근거는 브리프 일치, 말소리와 겹치는 주파수(보컬·중고역 멜로디)가 적은지, 반복해도 지루하지 않은지 세 가지다.

## 선택 보고

넣기 전에 사용자에게 아래 형식으로 말한다. 사용자가 "알아서 고르라"고 했어도 보고는 생략하지 않는다. 다운로드는 라이선스 사용 기록이 남는 되돌리기 어려운 작업이므로 사용자 확인 뒤 진행한다. 사용자가 미리 "확인 없이 진행"이라고 했으면 보고만 하고 넘어간다.

```markdown
BGM 후보 4곡 중 **<곡명> – <아티스트>**를 선택했다.
이유: <브리프 일치>, <말소리와 겹치지 않음>, <반복 가능>

| # | 곡명 | 아티스트 | 무드 | BPM | 길이 | 후보 이유 | 선택 |
|---|---|---|---|---|---|---|---|
| 1 | ... | ... | ... | 96 | 3:12 | ... | ✔ |
| 2 | ... | ... | ... | 104 | 2:40 | 드롭이 커서 제외 | |
```

## 삽입

- 플러그인에서 곡을 내려받아 타임라인에 넣는다. 플러그인이 넣는 트랙이 A4가 아니면 A4로 옮기고, 트랙 이름을 `MUSIC`으로 맞춘다(`Timeline.SetTrackName("audio", 4, "MUSIC")`).
- 영상 총길이에 맞춰 자른다. 끝은 결론 비트 끝에서 2초 페이드 아웃. 곡이 짧으면 박자 단위로 반복하고, 이음새는 `davinciresolve-audio-delivery`의 크로스페이드 규칙을 따른다.
- 2곡이면 바뀌는 자리는 비트 경계다.
- 레벨은 손대지 않는다. `davinciresolve-audio-delivery`가 `VOICE` 기준 상대 레벨과 마스터를 맞춘다.

## 작업 로그

`오디오` 절에 아래를 남긴다. 곡명·아티스트는 YouTube 설명란에 그대로 붙일 수 있게 적는다.

```markdown
BGM: <곡명> – <아티스트> (Epidemic Sound), 00:00:00:00–00:06:20:00, 후보 4곡 중 선택, 이유 ...
후보 표: (선택 보고의 표)
```

## 하지 않는 것

- 후보 표와 선택 이유 없이 곡을 넣는 것, 선택을 사용자에게 말하지 않는 것
- 사용자 확인 없는 다운로드(미리 허용한 경우 제외)
- 보컬 있는 곡, 큰 드롭이 있는 곡을 말소리 구간에 깔기
- 레벨·덕킹·라우드니스 조정(`davinciresolve-audio-delivery`의 일)
- Epidemic Sound 밖의 출처에서 곡 가져오기(사용자가 준 파일 제외)
