# davinciresolve-cut-devtalk

컷 편집 스타일 중 하나다. 이름의 devtalk은 "말(전사)이 컷의 기준"이라는 뜻이다. 말소리 없는 여행 영상은 `davinciresolve-cut-travelflow`가 맡는다.

`davinciresolve-video-editor`의 기본 원칙과 마커 등록표를 따른다. 입력은 `davinciresolve-beats-devtalk`이 남긴 구간 목록과 전사이고, 리듬 기준은 `davinciresolve-story-devtalk`이 정한 style skill의 컷 리듬 표다. 단독 호출로 구간 목록이 없으면 현재 작업 타임라인의 클립을 구간 목록으로 읽고, 전사가 없으면 `davinciresolve-beats-devtalk`의 전사 수단으로 먼저 전사한다.

## 컷 규칙

컷은 클립을 자르는 것이 아니라 구간 목록을 고쳐 타임라인을 다시 만드는 것이다(`AppendToTimeline`에 `startFrame`·`endFrame`). 침묵·재녹음·필러는 A1 음성 구간에서 자르고, 잘린 만큼 V1 화면 구간도 같은 길이로 줄여 음성과 화면의 `recordFrame`을 다시 맞춘다.

- 침묵: 전사의 `(...)` 또는 단어 사이 간격이 0.7초 넘는 구간은 0.25초만 남기고 제거한다. 문장 끝 호흡은 0.4초까지 둔다.
- 재녹음: `retake` 묶음은 마지막 테이크만 쓴다. 사용자가 지정한 테이크가 있으면 그것을 쓴다.
- 필러: "음", "어", "그", "뭐", "아니 그러니까"처럼 뜻 없는 단어만으로 된 세그먼트는 제거한다. 문장 안의 필러는 단어 타임코드로 잘라내되 앞뒤 단어 간격이 0.15초 미만이면 자르지 않는다(끊김이 들린다).
- 점프컷: 음성이 잘린 자리에서 화면이 같은 클립이면 프레임 그대로 붙인다. 화면이 튀는 것이 싫으면 사용자가 말했을 때만 그 자리에서 화면 클립을 바꾼다.
- 화면 교체: 같은 화면 클립이 style skill의 "같은 화면 최대 연속" 값을 넘으면 명사·동작이 나오는 문장 경계에서 다른 화면 클립이나 화면 녹화로 바꾼다(V1, 트랙 배치). A1 음성은 그대로 흐른다. 바꿀 화면이 없으면 Green 클립 마커 `TALK_REVIEW visual`을 찍고 로그 `확인 필요`에 남긴다.
- 얼굴: 구간 목록의 V1 클립에 `face` 표시가 있으면 넣지 않는다. 인벤토리에 얼굴 판정이 없는 클립은 넣기 전에 `davinciresolve-beats-devtalk`의 얼굴 탐지를 먼저 돌린다.
- 전환: 기본 컷. 디졸브를 쓰는 자리와 길이는 style skill의 컷 리듬 절을 따른다.

`TALK_REVIEW` 사유는 `visual`(바꿀 화면 없음), `face`(얼굴 판정 불가), `retake`(어느 테이크인지 불명확), `filler`(자르면 끊김), `unclear`(전사 불확실) 중 하나다.

## 리듬 확인

컷 뒤 평균 샷 길이와 첫 60초 컷 수를 계산해 style skill의 컷 리듬 표 범위 안인지 본다. 범위 밖이면 화면 교체 수를 조정하고 근거를 로그에 적는다. 카드는 확정 비트 시트의 것만 쓰고 여기서 늘리지 않는다. 타임라인 오디오를 아래 명령으로 검사해 0.7초 넘는 침묵이 남지 않았는지 확인한다(비트 경계 카드 구간 제외).

```bash
ffmpeg -i "<타임라인 오디오 또는 렌더 파일>" -af silencedetect=n=-35dB:d=0.7 -f null - 2>&1 | grep silence_
```

## 편집 결과 조정

컷이 바뀌면 `davinciresolve-subtitle-devtalk`, `davinciresolve-gfx-hyperframes`, `davinciresolve-sfx-epidemicsound`, `davinciresolve-bgm-epidemicsound`에 바뀐 구간 목록(`파일명 | 이전 시작 TC | 새 시작 TC | 길이 변화(프레임)`)을 넘긴다. `CHAPTER`·`GFX` 타임라인 마커는 클립을 따라가지 않으므로 새 시작 TC로 다시 찍는다.

## 작업 로그

`컷` 절에 채운다.

```markdown
평균 샷 길이 3.1초, 첫 60초 컷 18개, 제거한 침묵 41개(합계 38초), retake 2묶음, 필러 27개

| 비트 | 파일명 | 소스 TC | 타임라인 TC | 조치 | 근거 |
|---|---|---|---|---|---|
| 3 | IMG_2001.MOV | 00:01:12:04–00:01:13:20 | 00:02:05:00 | 침묵 1.6초 → 0.25초 | 단어 간격 |
| 5 | screen_k8s.mov | 00:00:10:00–00:00:35:00 | 00:04:10:00 | 화면 IMG_2002.MOV → screen_k8s.mov 교체 | 같은 화면 11초 > 8초 |
```

## 하지 않는 것

- 클립 원본 트림·삭제
- 기본값(마지막 테이크) 외의 테이크를 사용자 확인 없이 고르는 것
- 필러를 자르느라 말이 끊기게 하는 것
- 컷 변경 뒤 자막·카드·챕터 마커 위치를 그대로 두는 것
- 화자 얼굴이 있는 클립을 V1에 넣는 것
