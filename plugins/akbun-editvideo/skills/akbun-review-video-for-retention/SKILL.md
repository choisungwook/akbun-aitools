# akbun-review-video-for-retention

## 목적

시청자가 영상을 끝까지 보게 만드는 요소를 기준으로 기존 영상을 검토하고, 다시 만들 때의 재구성안을 낸다. 검토의 목적은 칭찬이나 총평이 아니라 "어느 시각에 무엇 때문에 나갈 수 있는가"를 근거와 함께 찾고, 그 구간을 고치는 구체적인 방법을 주는 것이다.

이 스킬의 용어로 흥미는 **시청 지속(retention)**이다. 클릭(제목·썸네일)은 시청 지속의 입구로만 다룬다. 썸네일 자체의 디자인 리뷰는 akbun-writing의 akbun-thumbnail-review를 쓴다.

## 입력

| 입력 | 필수 | 없을 때 |
|---|---|---|
| 영상 파일(mp4) 또는 렌더할 타임라인 | 필수 | 검토하지 않는다 |
| 제목, 썸네일(이미지 또는 문구) | 권장 | 영상 첫 화면과 첫 문장만으로 약속을 추정하고 "제목·썸네일 미제공"으로 적는다 |
| 대사(자막 파일 또는 음성 인식 결과) | 권장 | Resolve `CreateSubtitlesFromAudio`나 사용 가능한 음성 인식으로 만든다 |
| 시청 지속 그래프·이탈 시각(올린 영상) | 선택 | 없으면 추정이라고 표시한다. 숫자를 지어내지 않는다 |
| 참고 영상(사용자가 기준으로 삼고 싶은 영상) | 선택 | 아래 기준만 쓴다. 참고 영상을 주면 그 영상에서 뽑은 기준을 표에 더하되, 산출물에 그 영상의 장면·문구를 옮기지 않는다 |

## 평가 기준

| 구간 | 기준 | 무엇을 보나 |
|---|---|---|
| 약속 (plot promise) | 제목·썸네일이 "이 영상을 보면 무엇을 얻는가"를 약속한다. 검색어를 그대로 쓴 제목, 정의만 적은 썸네일은 약속이 없다 | 제목·썸네일 문구 |
| 첫 5초 | 첫 문장이 제목의 약속을 말하고, 첫 화면이 썸네일과 같은 구도·색이다. 소리 없이 봐도 주제가 보인다 | 0~5초 화면과 말 |
| 첫 20초 | 최소한의 맥락, 걸린 것(위험·보상), 호기심 갭이 있고, 20초 안팎(늦어도 45초)에 첫 본론이 시작된다. 인사말·목차·자기소개로 시간을 쓰지 않는다 | 첫 본론이 시작되는 시각 |
| USP | 전문성·노력·개성·증거 중 하나 이상이 인트로에서 보인다 | 인트로 화면과 말 |
| 화면 변화 | 3~5초마다 화면에 무언가 바뀐다. 5초 넘게 그대로인 구간이 없다 | `measure_pacing.py` 결과 |
| 화면 대비 | 한 종류의 화면만 계속되지 않는다. 다이어그램 사이에 다른 종류(실제 설정 화면, 모형, 캡처, 결론 카드)가 섞인다 | 장면 종류 목록 |
| 에너지 주기 | 새 주제·질문(높음)과 설명(낮음)이 2~4분 주기로 반복되고, 앞쪽 주기가 짧다. 무겁고 긴 설명은 뒤쪽 20%에 둔다. 가운데가 길게 처지지 않는다 | 챕터 길이와 순서 |
| 시청 경험 미리 보기 | 영상에서 가장 좋은 화면·애니메이션의 짧은 버전이 인트로에 나온다 | 가장 좋은 화면이 처음 나오는 시각 |
| 끝 | 큰 보상(정리된 결론, 약속의 회수)을 보여 주고 높은 에너지로 끝난다. 앞 내용을 길게 되풀이하지 않는다 | 마지막 장면 길이와 내용 |

## 작업 흐름

1. **약속 확인**: 제목·썸네일 문구를 적고, 영상이 약속하는 것을 한 문장으로 정리한다. 약속이 없으면 그렇게 판정한다.
2. **인트로 표**: 첫 60초를 `시간 | 화면 | 말` 표로 옮긴다. 첫 본론(처음으로 새 정보를 주는 문장)의 시각을 적는다.
3. **화면 변화 측정**: `scripts/measure_pacing.py`로 변화 횟수, 분당 변화, 첫 60·120초 변화, 평균 장면 길이, 5초 넘는 정지 구간을 잰다. 임계값이 영상에 맞는지 확인한다(아래 "측정 보정").
4. **구성 표**: 챕터·장면 순서와 길이를 표로 만든다. 가장 강한 문제나 위험이 처음 나오는 시각을 적는다. 교과서 순서(정의 → 원리 → 적용 → 운영)라서 가장 강한 문제가 뒤에 숨어 있는지 본다.
5. **채점**: 위 기준마다 1~5점과 근거를 적는다. 근거는 시각·측정값·인용(짧게)으로 쓴다. "지루하다" 같은 인상만으로 점수를 주지 않는다.
6. **잘한 점**: 지켜야 할 장치(예: 챕터마다 질문으로 작은 호기심 갭을 다시 연다, 말과 화면 등장이 맞는다)를 따로 적는다. 재구성에서 이것을 잃지 않게 한다.
7. **사실 점검**: 내레이션의 수치·용어 중 틀리거나 단정할 수 없는 표현을 시각과 함께 목록으로 남긴다. 다시 녹음할 때 고친다.
8. **민감 정보 점검**: 회사명, 고객·협력 관계, 특정 산업, 실제 장애 사례, 규제 이야기가 나오면 시각과 함께 표시하고 재구성안에서 뺀다. 사용자가 공개해도 된다고 한 것만 남긴다.
9. **재구성안**: 아래 "재구성안"의 순서대로 쓴다.

## 측정 보정

`measure_pacing.py`는 ffmpeg 장면 점수가 임계값을 넘는 프레임을 변화로 센다.

- 어두운 배경 슬라이드·다이어그램 영상은 `--threshold 0.01`(기본값)에서 단계별 요소 등장까지 잡힌다. 실사 영상은 0.1~0.3에서 시작한다.
- 결과의 첫 변화 시각과 타임라인 클립 경계를 몇 개 대조해 임계값을 맞춘다. 장면 전환이 빠지면 낮추고, 잡음·카메라 흔들림이 변화로 잡히면 높인다.
- 페이드·디졸브로 천천히 바뀌는 화면은 점수가 낮게 나온다. 그 자체가 시청자에게 변화가 약하게 보인다는 신호이므로 숫자를 억지로 올리지 않는다.

변화 횟수와 정지 구간을 잰다(경로는 이 스킬 디렉터리 기준).

```bash
uv run --python 3.12 scripts/measure_pacing.py video.mp4 --threshold 0.01 --static 5
```

## 재구성안

검토 결과 다음에 아래 순서로 쓴다. 각 항목에 "왜"를 한 줄 붙인다.

1. **약속을 하나로 정한다**: 영상에서 가장 강한 문제(위험·변화·의외의 사실)를 찾아 제목 후보 3개와 노리는 것(위험, 목록형 보상, 호기심)을 표로 낸다. 제목·썸네일·첫 문장·첫 화면을 이 약속 하나로 맞춘다.
2. **인트로를 20초 안팎으로**: `시간 | 듣는 것 | 보는 것` 표로 쓴다. 첫 5초 약속, 맥락 한 문장, 호기심 갭 1~2개, 보상 약속(예: "확인할 4가지"). 인사말·목차는 빼고 챕터 마커가 목차를 맡는다.
3. **본문 순서를 바꾼다**: 인트로에서 연 갭을 같은 순서로 회수하도록 챕터를 다시 배열한다. `새 챕터 | 기존 장면 | 목표 길이 | 바뀌는 점` 표. 앞쪽 챕터는 짧게, 무거운 이론·운영은 뒤에. 영상에 꼭 필요하지 않은 장면은 뺀다.
4. **화면 변화와 대비**: 5초 넘는 정지 구간마다 해결책(단계 등장 나누기, 해당 요소로 줌인, 등장을 뚜렷하게)을 적는다. 챕터마다 한 번은 다른 종류의 화면을 넣는다. 챕터 끝에 결론 한 줄을 둬서 설명 뒤에 높은 에너지 지점을 만든다.
5. **끝**: 긴 정리를 짧은 체크리스트 한 화면으로 바꾸고, 인트로에서 가려 둔 보상을 여기서 공개한다. 마지막 문장은 반복이 아니라 행동으로 끝낸다.
6. **다시 녹음할 대본**: 인트로는 그대로 읽을 문장으로, 본문은 챕터별 요점(질문 → 요점 → 결론 한 문장)으로 쓴다. 사실 점검에서 고친 표현을 반영한다.
7. **녹음 방법**: 챕터마다 별도 테이크, 테이크 앞뒤 1초 무음, 인트로는 3~4번 녹음해 고르기, 질문은 한 박자 쉬고 읽기. 녹음 후에는 자막 인식으로 장면을 다시 맞춘다.
8. **공개 후 확인**: 비공개 상태에서 다른 사람 1~2명이 보는 모습을 보고 지루해하는 지점을 표시한다. 공개 후에는 시청 지속 그래프에서 급하게 떨어지는 구간을 같은 방식으로 고친다.

## 산출물

하나의 마크다운 문서로 쓴다. 영상 파일 옆이나 사용자가 정한 폴더에 둔다.

```markdown
# {영상 이름} 시청 지속 검토와 재구성안

## 평가 기준
## 현재 영상 평가
### 인트로(0:00~첫 본론)
### 점수(5점 만점)
### 잘한 점
### 사실 점검
## 재구성 방향
## 다시 녹음할 대본
## 녹음 방법
## 공개 후 확인
```

점수 표는 `기준 | 점수 | 근거` 형식이고, 근거에는 시각이나 측정값이 최소 하나 들어간다.

## 하지 말 것

- 시청 지속 그래프·조회수·클릭률 같은 숫자를 받지 않았는데 지어내는 것
- 참고 영상의 장면·문구·구도를 재구성안에 옮기는 것. 기준만 가져온다.
- 근거 없는 인상 평가("전반적으로 지루함")
- 민감 정보가 나온 구간을 재구성안의 대본·장면에 그대로 남기는 것
- 재구성 때문에 잘한 점(질문으로 다시 여는 갭, 말과 화면의 일치)을 잃는 것
