# pptx 구성과 읽는 법

`storyboard.pptx`는 16:9(13.333 x 7.5 in)이고 모든 글자는 편집 가능한 글상자·표·도형이다. 글꼴은 Pretendard 하나이고 라틴과 동아시아 글꼴 둘 다 지정한다. Pretendard는 SIL Open Font License 1.1 글꼴이라 상업용 영상·문서에 써도 되고 비용이 없다. 글꼴을 바꿀 때도 상업용으로 쓸 수 있는 공개 라이선스(SIL OFL 등) 글꼴만 고르고, 컴퓨터에 설치돼 있다는 이유로 고르지 않는다. pptx는 글꼴 파일을 담지 않으므로 설치돼 있지 않으면 보는 쪽이 대체 글꼴로 본다. 이때는 Pretendard를 공식 배포처에서 받아 설치한다.

## 장 구성

분량 제한은 개요에만 있다. 개요는 한 장이고, 타임라인·사운드 표·스토리보드는 내용이 많으면 장을 계속 늘린다.

| 순서 | 장 | 내용 |
|---|---|---|
| 1 | 개요 | 제목, 장르·총 길이·컷 수, 핵심 메시지, 대상, 의도, 입력 요약, 답이 나오는 컷과 그 뒤 길이, 반응 요소, 파트 표(파트·시간 범위·컷 번호 범위) |
| 2~ | 타임라인 | DaVinci Resolve 타임라인을 읽듯이 보는 전체 그림. 한 장에 120초까지 담고, 넘으면 120초씩 다음 장으로 이어진다(제목에 `2/3 · 02:00–04:00`처럼 표시). 장 경계에 걸친 블록은 두 장에 나뉘어 보인다 |
| 그다음 | 사운드·후시녹음 계획 | BGM 표, 후시녹음 구간 표, 효과음 표. 표마다 장이 하나이고 행이 많으면 더 나눈다 |
| 이후 | 스토리보드 | 한 장에 컷 3개를 가로로. 발표자 노트에 그 장 컷들의 대본 |

## 타임라인 읽는 법

위에서 아래로 읽는다. 블록의 가로 위치와 너비는 시각에 비례하고, 컷 사이 가는 틈이 컷 경계다. 블록은 개별 도형이라 끌어서 고친다. 블록 안 숫자는 컷 번호다.

| 줄 | 보이는 것 |
|---|---|
| 파트 마커 | 파트가 시작하는 곳의 깃발과 파트 이름 |
| 시간 눈금자 | `mm:ss` |
| V2 모션그래픽·자막 | `overlay`가 있는 컷과 그 길이 |
| V1 영상 | 컷마다 블록 하나. `source`가 모션그래픽인 컷은 다른 색 |
| A1 현장음·녹화 음성 | `voice`가 `live`인 컷 |
| A2 후시녹음 | `voice`가 `adr`인 컷(눈에 띄는 색) |
| A3 배경음악 | `music` 범위마다 긴 블록 하나와 `id` |
| A4 효과음 | `sfx`가 있는 컷 시작점의 작은 블록 |

색은 트랙 종류마다 하나이고 스크립트 상수에서 정한다. 장 아래 범례가 색을 설명한다.

## 스토리보드 장

컷마다 위에서 아래로 번호 원, 시각 범위·파트 이름·`source`, 16:9 스케치 틀, 샷·움직임 한 줄, 화면(`desc`), 의도(`intent`), 대본(후시녹음이면 앞에 `[후시녹음]`), 있으면 얹는 것과 효과음이다. `sketches/cut_NN.png`가 있으면 틀 안에 그림이 들어가고, 없으면 회색 자리표시와 "스케치 없음"이 보인다. 글자 크기는 11pt이고 글상자는 줄바꿈된다.

스케치를 나중에 만들었으면 `build`를 다시 돌리면 그림이 들어간다. 컷 하나만 고칠 때는 pptx에서 그림만 바꾼다.
