# akbun-draw-night-gouache

## 목적

설명 영상 한 장면을 그린다. 화면은 거의 검은 어둠이고, 그 위에 외곽선 없이 물감·크레용 입자로 칠한 단순한 사물·인물이 1~4개 떠 있다. 색은 채도가 높고, 장면의 핵심 대상 하나만 빛(광·후광)으로 강조한다. 사물 사이는 짧은 흰 붓 화살표가 잇는다. 화면 글자는 아래 자막 한 줄과 작은 키워드 태그뿐이다.

결과물은 출력 폴더의 파일들이다.

| 파일 | 쓰는 곳 |
|---|---|
| `NN_<id>.svg` | 모델이 쓴 장면 원본. 글자·색을 고치려면 이것을 고쳐 다시 렌더한다 |
| `NN_<id>.png` | 배경·자막 미리보기까지 붙인 확인용 스틸(1920×1080) |
| `NN_<id>/` | 등장 단위별 투명 레이어 PNG(화면 전체 크기), `background.png`, `layers.json`(레이어 위치·중심, 태그 글자·위치, 자막) |

## 범위

- 사용자가 직접 호출할 때 실행한다. 이 스타일로 장면 그림(스틸)이나 영상용 레이어를 만들 때 쓴다.
- 움직임(등장·광 깜빡임·확대)과 Resolve 타임라인은 [akbun-davinciresolve-explainer-night-gouache](../../../akbun-editvideo/skills/akbun-davinciresolve-explainer-night-gouache/SKILL.md)의 범위다. 이 스킬은 정지 그림과 레이어만 만든다.
- 무엇을 그릴지(소재·배치)는 입력 내용에 맞춰 정한다. 이 스킬이 고정하는 것은 그림체·색·질감·강조 방식·글자 방식이다.

## 스타일

모든 숫자는 1920×1080 기준이다.

### 배경

- 기본 `night`: 가운데가 조금 밝고(`#1A1C21`) 가장자리로 갈수록 거의 검정(`#05070A`)이 되는 비네트 + 고운 필름 입자. 스크립트가 깐다. SVG에 배경 사각형을 그리지 않는다.
- 격자·점(도트)·모눈·줄무늬 같은 반복 무늬 배경은 쓰지 않는다.
- 데이터 차트 장면만 `paper`(밝은 회색 구김 종이)를 쓴다. 루트에 `data-bg="paper"`. 아래 "데이터 장면" 참고.

### 그림체

- 사물·인물은 외곽선 없는 평면 도형(원·타원·둥근 사각형·부드러운 `path`)으로 만든다. 검은 테두리를 긋지 않는다.
- 모든 색 면에 `filter="url(#paint)"`를 건다. 가장자리가 살짝 울퉁불퉁해지고 면 안에 밝고 어두운 입자가 생겨 손으로 칠한 질감이 된다. 필터는 그룹(`<g>`)에 한 번 걸고 도형마다 따로 걸지 않는다.
- 둥근 면에는 같은 도형을 하나 더 겹쳐 `fill="url(#shade)"`를 칠한다. 왼쪽 위가 밝고 오른쪽 아래가 어두운 에어브러시 음영이다. 평면만 남기지 않는다.
- 세부는 같은 계열의 더 어두운 색 선 2~6개(3~5px, `stroke-linecap="round"`)로만 넣는다. 예: 접힌 주름, 눈금, 마디. 얼굴·손가락·옷 주름을 자세히 그리지 않는다.
- 사물 하나는 도형 3~8개로 끝낸다. 알아보는 데 꼭 필요한 특징 하나(손잡이, 안테나, 뚜껑)만 남긴다.
- IT 컴포넌트가 아닌 실물 기계·장비의 생김새가 설명에 필요할 때만 "기기 묘사"로 그린다: 크림색 몸체 `#EDE6D3` + 강조색 패널 하나 + 버튼·화면·통풍구 같은 세부 6~12개, 그룹에 `filter="url(#pencil)"`(색연필 결). 한 장면에 기기 묘사는 하나까지. 기기 묘사는 "도형 3~8개" 규칙의 예외다. 노트북·휴대폰·문서·카드처럼 작은 사물은 기기 묘사가 아니라 일반 그림체로 그린다.
- 사용자가 사진(인물·제품)을 주면 배경을 지운 사진을 `<image>`로 넣고, 그 뒤에 지름이 사진 높이의 1.1~1.3배인 원을 `fill="url(#spot)"`으로 깔아 어둠 속 그림자 자리를 만든다. 사진에는 질감 필터를 걸지 않는다.

### IT 컴포넌트

로드밸런서·인스턴스·서버·Pod·게이트웨이·큐·캐시·API 같은 IT 컴포넌트는 그림으로 꾸미지 않고 이름을 적은 상자로 그린다. 데이터베이스·스토리지만 원통으로 그린다.

| 요소 | 모양 | 글자 |
|---|---|---|
| 컴포넌트 상자 | 둥근 사각형 `rx="16"`, 높이 110~130px, 폭 = 글자 수 × 20 + 90px(220~420px). 색 면에 `paint` + `shade` | 영어 이름 1~2단어, 상자 가운데 정렬 |
| 데이터베이스 원통 | 폭 200~260px, 높이 170~210px. 몸통 + 위 타원(세로 반지름 = 폭 × 0.14, 몸통보다 밝은 면) + 아래 호. `paint` + `shade` | 몸통 가운데에 영어 이름 |
| 그룹 상자(상자 안 상자) | 둥근 사각형 `rx="24"`, 채움 없음, `#F3F4F5` 3px `stroke-opacity="0.35"`, 점선 `stroke-dasharray="14 10"`. 안쪽 상자와 50px 이상, 위쪽은 라벨 자리로 70px 띄움. 필터 없음 | 왼쪽 위 안쪽(x+24, y+42)에 영어 이름, Inter Medium 24px GREY |
| 여러 대 | 같은 크기 상자를 40px 간격으로 나란히, 또는 같은 상자 3장을 14px씩 어긋나게 겹침 | 맨 앞 상자에만 이름 |

- 상자 색은 역할로 고른다: 트래픽 진입(로드밸런서·게이트웨이) MINT, 계산(인스턴스·Pod·함수) AMBER, 저장(데이터베이스·스토리지) COBALT, 메시지(큐·스트림) PINK, 사용자 바깥(외부 서비스·인터넷) SAGE, 문제가 난 컴포넌트 CORAL.
- 이름 글꼴은 SIL OFL인 Inter다(`font-family="Inter, Pretendard"`, `font-weight="600"`, 34px). 글자색은 밝은 면 위 `#0E1014`, COBALT 면 위 `#F3F4F5`. 세로 위치는 상자 가운데 + 12px를 기준선으로 둔다.
- 글자는 질감 필터 밖에 둔다. 상자 면만 `<g filter="url(#paint)">`로 묶고, `<text>`는 그 그룹 다음에 같은 레이어 안에 쓴다. 글자에 필터가 걸리면 가장자리가 번져 읽기 어렵다.
- 상자 안에 아이콘·로고·세부 선을 넣지 않는다. 제품 로고 대신 이름(`ALB`, `EC2`처럼 짧은 이름 허용)만 쓴다.
- 이름이 적힌 상자에는 키워드 태그를 달지 않는다.

### 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| MINT | `#17F0D8` (짙은 쪽 `#21D6A5`) | 빛나는 주인공 대상, 살아 있는·정상 상태 |
| COBALT | `#0F7DF5` (짙은 쪽 `#176FCF`) | 차가운 대상, 화면·물·정보 |
| CORAL | `#FC5E11` (짙은 쪽 `#9D2525`) | 문제·열·활동 중인 대상 |
| AMBER | `#F0A040` | 따뜻한 대상, 사람 피부 대신 쓰는 무난한 살색 계열 |
| SKIN | `#E6C494` (그늘 `#CCAE84`, 선 `#5D4029`) | 사람 피부 |
| SAGE | `#91CCA3` (그늘 `#6C9E7D`) | 옷·천·부드러운 사물 |
| PINK | `#FF5F8F` → VIOLET `#8B6CFF` | 한 사물 안에서만 쓰는 두 색 섞임(선형 그라데이션 하나) |
| NEON | `#11F58D` | 선·연결·흐르는 길 |
| SPARK | `#FFE14D` | 전기·신호·번쩍임(지그재그 선 + `url(#glow)`) |
| WHITE | `#F3F4F5` | 화살표, 자막, 사물의 흰 부분 |
| GREY | `#8A8F98` | 이미 지나간 단계의 화살표, 보조 선 |

- 한 장면의 주 색은 2~4개다. 표 밖의 색은 위 색의 명도만 바꾼 값(그늘·밝은 면)으로만 쓴다.
- 어두운 배경에서 잘 보이도록 큰 면은 밝고 채도 높은 색으로 칠한다. 회색·갈색 큰 면을 만들지 않는다.

### 강조

강조는 장면에 하나까지다. 지금 말하는 대상 하나만 빛나게 한다. 장면 표의 강조 칸이 "없음"이면 강조용 후광·광·번쩍임을 그리지 않는다(영상용 장면은 호출한 스킬이 강조 여부를 정한다).

| 방식 | 그리는 법 | 뜻 |
|---|---|---|
| 후광 | 대상 뒤에 반지름이 대상의 1.3~1.5배인 원, `fill="url(#halo-red)"`·`url(#halo-yellow)`·`url(#halo-mint)` | 빨강 = 문제·경고, 노랑 = 해결·좋은 변화, 민트 = 살아 있음·주인공 |
| 광 | 빛나는 선·작은 사물 그룹에 `filter="url(#glow)"` | 신호·흐름이 지금 지나감 |
| 번쩍임 | SPARK 지그재그 선(4~6px, 꺾임 6~12개) + `url(#glow)` | 전기·데이터가 오감 |

- 후광은 대상과 다른 레이어(`<id>-halo`)로 둔다. 영상에서 따로 켜고 깜빡이게 하기 위해서다.

### 화살표

- WHITE 붓 화살표: 굵기 10~12px, 둥근 끝, 살짝 휜 곡선(`Q` 하나), 길이 90~260px. 화살촉은 열린 두 획(각 30~40px). 그룹에 `filter="url(#brush)"`.
- 출발 대상과 도착 대상 가장자리에서 각각 25~50px 떨어져 멈춘다.
- "A가 B로 바뀐다"는 곧은 GREY 가는 화살표(4px, 길이 80~140px)로 쓴다.
- 한 대상에서 여러 대상으로 퍼질 때는 짧은 곡선 화살표를 방사형으로 2~4개 둔다.
- 연결이 끊김: 두 대상 사이에 WHITE 붓 선 두 토막(화살촉 없음)을 긋고 가운데를 80~140px 비운 뒤, 그 자리에 CORAL ✕(두 획, 10px, 한 변 50~70px)를 둔다. ✕는 강조 개수에 넣지 않는다.

### 인물

- 머리는 원, 몸은 둥근 사다리꼴, 팔은 굵은 둥근 막대(몸과 같은 색)다. 손은 둥근 덩어리나 장갑 모양 하나.
- 얼굴은 점 눈 두 개 + 짧은 입 선 하나. 표정은 눈 모양(점·반원·✕ 중 하나)과 입 선으로만 바꾼다.
- 머리 위 소품(모자·두건·머리카락)은 매번 내용에 맞춰 새로 고른다. 이미 알려진 캐릭터의 머리·옷·표정 조합을 따라 하지 않는다.
- 둥근 덩어리 하나에 다른 색 원을 속에 넣은 "핵이 있는 원"을 주인공 대상의 기본형으로 쓰지 않는다. 대상의 모양은 내용에서 고른다.
- 감정·상태를 여러 개 비교할 때는 "표정 원"을 쓴다: 지름 60~90px 평면 원(VIOLET·`#3CB4C8`·`#7CC63A`·`#E3A92A` 중 하나) + 점 눈 + 입 선.

### 글자

글꼴은 SIL OFL인 Pretendard만 쓴다(`font-family="Pretendard"`). 렌더 전에 `~/Library/Fonts`에 Pretendard가 있는지 확인하고, 없으면 설치할지 사용자에게 먼저 묻는다.

| 글자 | 넣는 법 | 모양 |
|---|---|---|
| 자막 | 루트에 `data-subtitle="..."` | 가운데 정렬, Medium 42px, WHITE, 기준선 y 950, 상자·외곽선 없음. 스크립트가 그린다 |
| 키워드 태그 | `<text class="tag" x=".." y="..">용어</text>`(x, y = 상자 왼쪽 위) | 어두운 반투명 상자 + 아래 노란 2px 선 + 왼쪽 위 노란 작은 네모, Bold 26px. 스크립트가 상자를 만든다 |

- 태그는 장면에 하나까지, 처음 나오는 용어에만 붙인다. 설명하는 대상의 위쪽 바깥(후광이 아니라 대상 가장자리에서 30~60px)에 둔다.
- 그림 안에 다른 글자(제목, 문장, 라벨 여러 개)를 넣지 않는다. 숫자·이름이 꼭 필요하면 태그 하나로 쓴다. IT 컴포넌트 상자·원통·그룹 상자의 영어 이름은 예외다.
- 자막은 한 줄, 공백 포함 24자 이하다. 사용자가 정한 문장은 그대로 쓰고, 넘으면 장면을 나누자고 제안한다(스크립트가 경고를 낸다).

### 구도

- 대상은 어둠 위에 떠 있다. 바닥선·방·하늘 같은 배경 풍경을 그리지 않는다.
- 대상은 1~4개. 가장 큰 대상의 긴 변은 250~520px. 화면 면적의 55% 이상은 빈 어둠으로 남긴다.
- y 880 아래는 자막 자리다. 그림을 두지 않는다.
- 대상 사이는 120px 이상 띄운다(화살표·후광은 예외).
- 영상에서 확대(펀치 인)할 대상은 태그·후광까지 포함해 화면 가장자리에서 220px 이상 안쪽에 둔다. 가장자리에 붙으면 확대할 때 잘린다.
- 같은 소재를 이어서 설명하는 장면들은 앞 장면 대상을 같은 자리에 두고 새 대상만 더한다. 영상에서 장면이 바뀌어도 그림이 이어져 보이게 하기 위해서다.

### 데이터 장면 (paper)

숫자 추세·분포를 보여 줄 때만 쓴다.

- 루트 `data-bg="paper"`. 격자선 `#C9D3D3` 1.5px, 축 숫자 `#555B5E` Pretendard 18px. 축 숫자에는 단위(`h`, `분`)를 붙여도 되고, 축 제목은 쓰지 않는다.
- 데이터 점·선은 TEAL `#1E9C96` 하나. 점은 지름 10~14px, `fill-opacity` 0.75. 특별한 점 3~6개에만 TEAL Bold 20px 이름표.
- 추세선은 `#222` 2px 점선(대시 8, 간격 6). 강조 구간은 `#9DB6D8` `fill-opacity` 0.45 사각형 + 구간 이름 `#2B3A4A` Bold 22px.
- 질감 필터(`paint`)와 `shade`는 데이터 장면에 쓰지 않는다. 자막은 스크립트가 어두운 테두리와 그림자를 붙여 그린다.
- 이 절의 글자(축 숫자, 점 이름표, 구간 이름)는 "그림 안 글자 금지"의 예외다.
- 레이어는 아래부터 `axes`(격자+축 숫자) → `band` → `trend` → `points` → `labels`(점 이름표+구간 이름) 순서다.

### 레이어

- 루트 바로 아래 자식은 모두 `<g data-layer="이름">`이다. 영상에서 따로 나타나는 단위 하나가 레이어 하나다(대상 하나, 그 후광, 화살표 하나, 태그 하나).
- 레이어 순서 = SVG 순서 = 아래부터 쌓이는 순서. 후광은 그 대상보다 앞(아래)에 둔다.
- 이름은 영문 소문자와 하이픈(`laptop`, `laptop-halo`, `arrow-1`, `tag`).

## 작업 흐름

### 1. 장면 표

장면마다 `id`, 자막 문장, 대상(1~4개), 강조 대상과 방식(후광 색·광·번쩍임, 또는 없음), 화살표, 태그, 배경(`night`/`paper`), 레이어 순서를 적는다. 사용자가 대본만 줬으면 문장 하나 = 장면 하나로 나눈다.

### 2. 출력 폴더

사용자가 정한 폴더, 없으면 작업 디렉터리 아래 `gouache-output/<작업명>/`.

### 3. SVG 쓰기

장면마다 `NN_<id>.svg` 하나.

- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1920 1080" data-subtitle="...">`로 시작한다. `width`·`height`는 넣지 않는다.
- 필터·그라데이션 id(`paint`, `brush`, `pencil`, `glow`, `shade`, `spot`, `halo-red`, `halo-yellow`, `halo-mint`)는 스크립트가 넣는다. SVG에 같은 id를 다시 정의하지 않는다.
- 한 레이어 안의 그리는 순서: 색 면 → `shade` 음영 → 어두운 세부 선.
- 예시: [references/example/](references/example/). 스타일 확인용이다. 소재·배치를 그대로 쓰지 않는다.

### 4. 렌더

`<skill>`(이 `SKILL.md`가 있는 디렉터리)의 스크립트로 스틸과 레이어를 만드는 명령이다. 영상에 쓰지 않을 장면은 `--layers`를 빼도 된다.

```bash
uv run --python 3.12 <skill>/scripts/render_gouache.py gouache-output/<작업명>/01_<id>.svg gouache-output/<작업명>/01_<id>.png --layers gouache-output/<작업명>/01_<id>
```

스크립트를 고쳤으면 아래 자체 검사가 `selftest ok`를 내는지 먼저 본다.

```bash
uv run --python 3.12 <skill>/scripts/render_gouache.py --selftest
```

### 5. 검수

스틸을 한 장씩 여러 번 읽지 말고 한 장으로 붙여 한 번만 본다.

스틸을 한 장으로 붙이는 명령이다. `tile=열x행`은 장면 수 이상이 되게 고른다.

```bash
ffmpeg -v error -y -pattern_type glob -i 'gouache-output/<작업명>/[0-9]*.png' -vf "scale=640:-1,tile=3x2" -frames:v 1 gouache-output/<작업명>/sheet.jpg
```

아래 채점표로 장면마다 채점한다. 항목마다 0(어김)·5(일부)·10(지킴)점이고 80점 미만인 장면은 낮은 항목을 고쳐 다시 렌더한다. 데이터 장면은 2·3·7번을 "데이터 장면" 절의 색·선·레이어 규칙을 지켰는지로 바꿔 채점한다.

| # | 항목 | 10점 기준 |
|---|---|---|
| 1 | 배경 | 비네트 어둠(또는 데이터 장면의 구김 종이). 격자·도트·무늬 없음 |
| 2 | 그림체 | 모든 색 면이 외곽선 없는 도형 + `paint` 질감. 검은 테두리 없음 |
| 3 | 음영 | 둥근 면에 `shade` 에어브러시 음영. 평면만 남은 큰 면 없음 |
| 4 | 단순화 | 사물마다 도형 3~8개, 세부는 같은 계열 어두운 선 몇 개. IT 컴포넌트는 이름 상자·원통·그룹 상자로만 그림 |
| 5 | 색 | 색 표 안에서 주 색 2~4개, 밝고 채도 높은 큰 면 |
| 6 | 강조 | 장면 표대로. 있으면 강조 대상 하나에만 후광·광·번쩍임, 색의 뜻이 내용과 맞음. "없음"이면 강조용 빛 없음 |
| 7 | 화살표 | WHITE 붓 곡선(또는 GREY 직선 변환), 대상 앞에서 멈춤 |
| 8 | 구도 | 대상 1~4개가 떠 있음, 빈 어둠 55% 이상, 바닥·풍경 없음, y 880 아래 비움 |
| 9 | 글자 | 자막 한 줄 + 태그 0~1개뿐, 크기·위치가 표대로 |
| 10 | 독창성 | 이미 알려진 캐릭터·마스코트·영상 장면과 닮지 않음 |

이 밖에 확인한다.

- `layers.json`의 레이어 수가 장면 표의 레이어 수와 같고, 경고(`data-layer 밖 요소`, `비어 있다`)가 없는가.
- 글자가 네모(깨진 글리프)로 나오지 않는가.

### 6. 완료 보고

출력 폴더, 장면 표(id·자막·강조·레이어 수), 장면별 채점 점수, 고친 항목, Pretendard 설치 여부를 적는다. 확인하지 않은 항목은 "확인하지 않음"으로 적는다.

## 하지 말 것

- 격자·도트·모눈 배경, 검은 외곽선, 단색 평면만 있는 벡터 아이콘 그림.
- 한 장면에 강조(후광·광) 두 개 이상.
- 그림 안에 제목·문장·라벨 여러 개.
- SVG에 배경 사각형을 그리거나 스크립트가 넣는 id를 다시 정의하는 것.
- 이미 있는 캐릭터·로고·영상 장면을 따라 그리는 것.
