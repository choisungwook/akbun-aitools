# Architecture

## Responsibility

Designs a mascot-based Electron desktop application icon prompt and guides production-size compression and integration.

## Boundary

Derive the mascot metaphor from the app's core function and keep the silhouette legible at dock and taskbar sizes.

The skill wiki records maintenance context. [SKILL.md](../SKILL.md) remains the executable instruction source and must not depend on an agent loading this wiki during an ordinary user request.

## Flow

Confirm the app identity and central function, choose a compact mascot metaphor, write the icon prompt, then explain required icon sizes, compression, and Electron integration.
