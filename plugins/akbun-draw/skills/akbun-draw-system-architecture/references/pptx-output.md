# PPTX 출력

사용자가 `.pptx`, PowerPoint, PPT slide를 명시했을 때만 읽는다. 요청하지 않은 PPTX는 만들지 않는다.

## 결과물

- 단일 주제는 슬라이드 한 장, 여러 독립 주제는 주제당 한 장으로 만든다.
- 기본 비율은 16:9다.
- 제목, 핵심 메시지, 컴포넌트, 경계, 관계 라벨, 연결선을 PowerPoint 기본 요소로 만들어 편집 가능하게 남긴다.
- 전체 슬라이드를 한 장의 PNG로 평면화하지 않는다. 사용자가 편집 불가능한 이미지 슬라이드를 명시한 경우만 예외다.
- PPTX와 PNG를 모두 요청했을 때만 두 형식을 함께 제공한다.

## PowerPoint 작업 방식

- 사용 가능한 PowerPoint 제작 skill이나 도구가 있으면 그 지침을 먼저 읽고 따른다.
- 로컬 PPTX 제작에서는 `@oai/artifact-tool` 기반 JavaScript를 사용하고 `python-pptx`를 사용하지 않는다.
- 사용자가 템플릿을 주면 템플릿의 master와 layout을 유지한다. 템플릿이 없으면 이 skill의 시각 스타일을
  명시적인 custom visual direction으로 사용한다.
- 단순 아키텍처는 PowerPoint 기본 도형과 connector로 만든다. connector를 먼저 만들고 컴포넌트 도형을
  나중에 올려 연결선이 박스와 라벨 위를 지나지 않게 한다.
- 파일 생성 기능이 없으면 가짜 PPTX를 만들지 않는다. 이미지 또는 생성 프롬프트로 대체할 수 있음을 알린다.

## 슬라이드 매핑

- 배경: 슬라이드 전체를 `#242424` 단색으로 채운다.
- 안전 여백: 좌우 0.6~0.8in, 상하 0.4~0.6in.
- 제목: 좌상단 한 줄, off-white, 36~44pt sans-serif medium/bold. 한 줄이 넘으면 문구를 줄인다.
- 핵심 메시지: 제목 아래 불릿 하나, light gray, 18~24pt. 최대 두 줄.
- 다이어그램: 슬라이드 중단과 하단에 배치한다. 컴포넌트 3~7개, 16~20pt 라벨, 넉넉한 간격을 둔다.
- 컴포넌트: 채움 없음, 직각 사각형, 1~2pt off-white 선.
- 경계: 채움 없음, 1~2pt 흰색 파선 사각형, 좌상단 근처에 작은 라벨.
- 기본 관계: 1~2pt off-white connector와 작은 삼각형 화살촉, light-gray 동사구 라벨.
- 장애 관계: 입력 근거가 있을 때만 `#F01818` connector, X, 짧은 문제 라벨을 쓴다.
- 단계 배지: 순서가 핵심이고 사용자가 번호를 금지하지 않았을 때만 쓴다. 번호 금지 요청이 있으면 모두 생략한다.
- 로고, 아이콘, 3D, 그림자, 그라데이션, 사진, 장식 패턴, 범례를 넣지 않는다.

## 여러 장 구성

- 모든 슬라이드가 같은 배경, 여백, 제목 크기, 선 두께, 연결 의미를 사용한다.
- 한 슬라이드에는 핵심 메시지 하나만 둔다. 설명이 복잡하면 글씨를 줄이지 말고 슬라이드를 나눈다.
- 반복되는 컴포넌트 이름과 관계 라벨의 철자를 슬라이드 간 동일하게 유지한다.

## QA

1. 최종 PPTX의 모든 슬라이드를 PNG로 렌더링한다.
2. 각 슬라이드를 전체 크기로 보고 텍스트 잘림, 예상 밖 줄바꿈, 도형 겹침, connector 교차를 수정한다.
3. 슬라이드 바깥으로 나간 요소와 의도하지 않은 겹침이 없는지 검사한다.
4. 사용자가 요청한 주제 수와 슬라이드 수가 맞고 각 슬라이드에 메시지가 하나인지 확인한다.
5. 최종 PPTX 경로를 반환한다. 외부 자료를 사용했다면 speaker notes의 `[Sources]` 블록에 출처를 남긴다.
