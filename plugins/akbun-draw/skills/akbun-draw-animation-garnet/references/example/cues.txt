# energy·sfx 뜻
# energy-0: 정적: 팔레트 화음의 낮은 지속음만. 시작, 막이 바뀐 직후의 숨, 마지막 여운
# energy-1: 맥박: 지속음 + 박자마다 작은 높은 음. 장소를 보여 주거나 이야기가 시작될 때
# energy-2: 추진: + 박마다 킥, 엇박마다 하이햇. 사건이 굴러가고 긴장이 쌓일 때
# energy-3: 절정: + 2·4박 스네어와 베이스. 가장 큰 사건과 감정이 터질 때
# hit: 충격음: 컷이 보이는 첫 순간 둔탁한 타격과 낮게 떨어지는 음. 절정·놀람·무언가 닫히거나 부딪힐 때
# whoosh: 휙: 컷 직전 0.35초 공기를 가르는 소리. 빠른 움직임이나 장소가 확 바뀔 때
# riser: 상승음: 컷 내내 음이 올라가 다음 컷에서 터진다. 절정 바로 앞, 다음 컷에 hit가 있어야 함
# heartbeat: 심장 박동: 박마다 두 번 쿵. 숨죽인 긴장, 공포 속 정지
# sting: 찌르는 화음: 컷 첫 순간 높은 불협 화음. 이상한 것을 발견하거나 깨달을 때
