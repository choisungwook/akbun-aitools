# akbun-contentcreator-blog-converter

한 번의 공부를 영상과 글 두 결과물로 만든다. 영상은 질문 하나와 실험 장면, 글은 버전·명령·전체 출력과 참고 링크다. 결과는 마크다운 글 하나와 영상 설명란용 링크 문장이다.

## 채널 전제

아래는 글을 쓸 때 지키는 전제다.

```yaml
channel:
  name: 악분일상
  blog: https://malwareanalysis.tistory.com/
  roles:
    video: 가장 중요한 질문 하나와 실험. 핵심 확인
    blog: 재현 가능한 전체 기록. 코드·버전·명령·참고 링크
  structure: [문제, 예상, 실험, 결과]
  never:
    - 대본·노트에 없는 명령·출력·수치를 채운다
    - 키워드를 반복하거나 해시태그를 도배한다
    - 회사 도메인·계정 ID·토큰·실제 로그의 개인정보를 옮긴다
```

## 언제 쓰는가

- 영상을 올렸거나 올릴 예정이고 같은 주제의 글이 없을 때
- 영상에서 "블로그 참고"로 접은 설치·전체 명령을 글로 남길 때

## 입력

아래는 시작 전에 확인할 입력이다.

```yaml
inputs:
  - id: script
    description: 영상 대본(akbun-contentcreator-script-builder 출력이면 가장 좋다)
    when_missing: ask
  - id: note
    description: 원본 옵시디언 노트. 영상에서 접은 전체 명령·출력의 출처
    when_missing: 대본에 있는 것만 쓰고 접힌 부분은 "[노트 필요]"로 표시한다
  - id: video_url
    description: 영상 주소
    when_missing: "{영상 링크}" 자리표시자로 두고 업로드 후 바꾸라고 적는다
  - id: existing_post
    description: 같은 주제의 기존 글 URL
    when_missing: 새 글로 쓴다. 있으면 새 글 대신 기존 글 상단에 영상 링크 문단만 만든다
  - id: style
    description: 글 문체 skill(akbun-writing이 설치돼 있으면 그 규칙)
    when_missing: 존댓말(-습니다)로 쓰고 문장은 짧게 한다
```

## 단계

아래는 글을 만드는 순서다.

```yaml
steps:
  - step: 1
    name: 역할 나누기
    do:
      - 대본에서 영상에만 두는 것(훅·화면 지시·말투)을 지운다
      - 대본에서 "블로그 참고"로 접은 것을 노트에서 찾아 전체 명령·출력으로 채운다
  - step: 2
    name: 구조 옮기기
    do:
      - 제목. 영상 제목과 같은 기술명을 쓰되 검색되는 오류 문구·설정 이름을 자연스럽게 넣는다
      - 첫 문단. 영상 링크와 역할 안내 한 줄. "영상으로 핵심 확인 / 글로 코드·버전·명령 확인"
      - 문제 → 예상 → 실험 → 결과 순서로 H2 절을 둔다. 실험마다 명령과 출력을 코드블록으로, 코드블록 위에 설명 한 줄
      - 결과 절에 공식 문서 근거 링크를 붙인다
      - 마지막 절은 참고 링크. 공식 문서·관련 글·이전 영상
  - step: 3
    name: 교차 링크 만들기
    do:
      - 글 상단용. "이 내용은 영상으로도 정리했습니다. {영상 링크}"
      - 영상 설명란용 첫 줄. "전체 명령과 버전은 블로그에 있습니다. {블로그 링크}". 블로그 링크는 발행 후 채운다
      - 기존 글이 있으면 그 글 상단에 넣을 문단만 만든다
  - step: 4
    name: 검수 표시
    do:
      - 버전·날짜·숫자는 [검수] 표시
      - 노트에도 없는 것은 [노트 필요]
      - 가린 정보(계정·도메인)는 샘플 값으로 바꿨다고 적는다
```

## 체크리스트

아래를 모두 만족해야 끝난다.

```yaml
done_when:
  - 첫 문단에 영상 링크(또는 자리표시자)와 역할 안내가 있다
  - 영상 설명란용 블로그 링크 문장이 있다
  - 문제·예상·실험·결과 절이 모두 있고 코드블록마다 위에 설명과 언어 표시가 있다
  - 모든 명령·출력·수치가 대본 또는 노트에 있다. 없는 것은 [노트 필요]다
  - 기존 글이 있으면 새 글이 아니라 상단 문단만 만들었다
  - 해시태그 나열·키워드 반복이 없다
  - 회사·계정 식별 정보가 샘플 값으로 바뀌었다
```
