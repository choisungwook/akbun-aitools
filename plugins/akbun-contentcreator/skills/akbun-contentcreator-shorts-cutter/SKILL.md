# akbun-contentcreator-shorts-cutter

본편의 질문 중 하나의 결과나 오해만 떼어 60초 안에 독립적으로 설명한다. 본편을 보지 않은 사람도 답 하나를 얻고, 본편 안내는 마지막 한 줄이다. 결과는 쇼츠 대본 2~3개다.

## 채널 전제

아래는 쇼츠를 만들 때 지키는 전제다.

```yaml
channel:
  name: 악분일상
  faceless: true                       # 출연·표정 컷을 전제로 하지 않는다. 화면 녹화·그림·자막·목소리
  shorts_role: 예고편이 아니라 작은 답변. 질문 하나 → 그림 → 한 문장씩 → 본편 안내
  length: 60초 이하. 30~60초가 시작용 제안
  never:
    - 본편에 없는 결과·수치를 만든다
    - 본편 전체를 짧게 우겨 넣는다
    - 쇼츠 조회수가 본편 시청자로 바뀐다고 가정한다
```

## 언제 쓰는가

- 본편 대본이 확정됐고 같은 공부로 짧은 영상도 만들 때
- 본편의 한 오해·한 결과만 따로 설명하고 싶을 때

## 입력

아래는 시작 전에 확인할 입력이다.

```yaml
inputs:
  - id: script
    description: 본편 대본(akbun-contentcreator-script-builder 출력이면 가장 좋다)
    when_missing: ask
  - id: count
    description: 만들 개수
    when_missing: 3개. 혼자 서는 순간이 2개뿐이면 2개
  - id: video_url
    description: 본편 주소
    when_missing: "{본편 링크}" 자리표시자
  - id: speech_rate
    description: 사용자의 말 속도(초당 글자 수)
    when_missing: 한국어 초당 4.5자로 길이를 가늠하고 "가정"으로 표시한다
```

## 단계

아래는 쇼츠 대본을 만드는 순서다.

```yaml
steps:
  - step: 1
    name: 혼자 서는 순간 고르기
    candidates:
      - 실험 결과가 나오는 장면. 바꾼 것과 관측한 것이 한 화면에 있는 곳
      - 예상이 틀린 순간. "처음엔 ~인 줄 알았는데"
      - 결과 절의 조건 한 줄. "~일 때만 된다"
    do:
      - 본편 대본의 실험·결과 칸에서 후보를 전부 뽑는다
      - 본편의 앞 내용 없이도 질문 → 답이 되는 것만 남긴다
      - 같은 질문에 답하는 후보는 하나로 합친다
  - step: 2
    name: 60초 구조
    do:
      - 0~3초. 질문 한 문장을 자막으로. 기술명을 넣는다
      - 3~10초. 답 한 줄을 먼저 말한다
      - 10~45초. 그림 또는 화면 하나로 왜 그런지. 한 문장에 한 요소
      - 45~55초. 조건·주의 한 줄
      - 마지막 3~5초. 본편 안내 한 줄과 링크. 구독 요청은 넣지 않는다
  - step: 3
    name: 길이 재기
    do:
      - 말할 글자 수 ÷ 초당 글자 수로 초를 계산해 적는다. 60초를 넘으면 10~45초 구간을 줄인다
      - 세로 화면(9:16)에서 보일 요소를 한 컷에 하나로 제한한다. 터미널 전체 화면은 쓰지 않고 핵심 줄만 키운다
  - step: 4
    name: 제목·첫 자막
    do:
      - 쇼츠 제목은 질문 그대로. 기술명 포함, 40자 안쪽
      - 첫 자막은 제목과 다른 말로 답의 방향을 보여 준다
```

## 출력 형식

아래는 결과의 형식이다. 대화에 보여 주고 사용자가 원하면 `shorts-{주제-슬러그}.md`로 저장한다.

```markdown
# 쇼츠 대본: {본편 가제}

본편: {본편 링크} · 말 속도 가정: 초당 4.5자

## 쇼츠 1: {질문 제목}

- 본편에서 가져온 순간: {실험 N 결과 / 예상이 틀린 순간}
- 예상 길이: 48초 (말 215자)

| 시간 | 화면(9:16) | 자막 | 말 |
|---|---|---|---|
| 0~3초 | 질문 카드 | ... | (무음 또는 질문) |
| 3~10초 | 답 한 줄 | ... | ... |
| 10~45초 | 그림/핵심 줄 확대 | ... | ... |
| 45~55초 | 조건 한 줄 | ... | ... |
| 55~60초 | 본편 카드 | 전체 실험은 본편에 | ... |

## 쇼츠 2: ...

## 뽑지 않은 후보

- ...: 앞 내용 없이는 질문이 서지 않음
```

## 체크리스트

아래를 모두 만족해야 끝난다.

```yaml
done_when:
  - 쇼츠마다 질문 하나와 답 하나가 있고 본편 없이도 뜻이 통한다
  - 쇼츠마다 계산한 길이가 60초 이하이고 글자 수와 속도 가정이 적혀 있다
  - 모든 결과·수치가 본편 대본에 있다
  - 한 컷에 요소가 하나이고 터미널 전체 화면 컷이 없다
  - 본편 안내가 마지막 한 줄이고 구독 요청이 없다
  - 출연·표정을 전제로 한 컷이 없다
  - 뽑지 않은 후보와 이유를 적었다
```
