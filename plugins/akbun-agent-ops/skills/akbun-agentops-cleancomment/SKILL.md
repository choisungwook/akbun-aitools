# akbun-agentops-cleancomment

## 의도

틀린 주석은 주석이 없는 것보다 나쁘다. 읽는 사람과 agent가 코드 대신 주석을 믿고 잘못 고친다. 이 skill은 디자인 문서·의사결정 기록(ADR 등)이나 실제 코드와 충돌하는 주석을 찾아 과감히 지운다.

## 원칙

- 기준은 코드와 문서다. 주석은 그 둘과 어긋나면 진다.
- 고쳐 쓰기보다 삭제가 기본이다. 코드가 이미 말하는 내용, 지난 동작을 설명하는 내용, 문서와 다른 이유를 대는 내용은 지운다.
- 코드만 봐서는 알 수 없는 이유(왜 이렇게 했나)가 맞는 주석만 남긴다.
- 코드나 문서는 고치지 않는다. 문서 자체가 틀려 보이면 지우지 말고 사용자에게 알린다.
