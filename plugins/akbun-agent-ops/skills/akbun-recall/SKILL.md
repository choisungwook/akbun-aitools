# akbun-recall

작업을 시작하거나 재개하기 전에 최근 작업 맥락을 다시 세우고, 지금 어디에 있고 다음에 무엇을 할지를 짧은 브리프로 돌려준다. 읽기 전용이다. 파일을 만들거나 고치지 않는다.

맥락은 세 곳에 있다. 이 프로젝트의 기억 디렉터리(`akbun-memory-setup`이 만든 구조, AGENTS.md가 읽기 순서를 안다), 저장소의 실제 상태(브랜치·커밋·PR·이슈), 그리고 이전 세션 transcript(무엇을 하려 했고 어디서 막혔는지). 셋 중 하나만 보면 틀린 브리프가 나온다. transcript는 의도를, git은 실제를, 기억 디렉터리는 결정을 담고 있다.

## 1. 범위를 고정한다

- 기간: 사용자가 말하지 않으면 최근 7일. "전부"를 조용히 "최근 N개"로 바꾸지 않는다.
- 주제: 사용자가 이름을 댔으면(기능·파일·브랜치·PR·이슈) 그 주제만. 인접 주제는 이 주제를 막고 있을 때만 넣는다.
- 워크스페이스: 현재 프로젝트만. 다른 프로젝트의 transcript는 요청 없이 읽지 않는다.
- 사용자가 이미 상태를 다 말해 줬으면(경로, 브랜치, 바꾼 것) 그대로 쓰고 채굴을 건너뛴다.

고정한 범위를 한 줄로 되돌려 말하고 진행한다.

## 2. 세 곳을 읽는다

**기억 디렉터리.** AGENTS.md의 읽기 순서를 따라 이 주제에 해당하는 조건의 파일만 읽는다. 조사 상태 파일(예: `incident/CURRENT.md`)이 있으면 확정 사실과 다음 행동을 그대로 가져온다. 결정 기록이 있으면 "왜 그렇게 했는가"의 출처로 쓴다.

**저장소 상태.** 다음을 확인한다.

- 현재 브랜치, 작업 트리의 미커밋 변경, 최근 커밋 로그
- 열린 PR과 그 CI·리뷰 상태, 최근 머지된 PR, 언급된 이슈. GitHub MCP나 `gh`가 있으면 사용한다.
- transcript가 언급한 브랜치·PR·파일이 지금도 그 상태인지. transcript의 "했다"는 주장이 아니라 git이 증거다.

**이전 세션 transcript.** Claude Code는 `~/.claude/projects/<slug>/*.jsonl`에 세션을 저장한다. `<slug>`는 프로젝트 절대 경로에서 `/`를 `-`로 바꾼 것이다(`/home/user/proj` → `-home-user-proj`). 한 줄이 메시지 하나이고 `type`이 `user`·`assistant`인 줄만 대화다. `message.content`는 문자열이거나 `text`·`tool_use`·`tool_result` 블록의 목록이다. Codex 등 다른 환경의 세션 저장 위치는 그 환경 문서로 확인하고, 모르면 `확인 필요`로 남긴다.

- 수정 시각 순(`ls -t`)으로 후보를 고른다. 파일명(UUID)은 순서 정보가 없다.
- 주제가 있으면 먼저 grep으로 걸러 해당 세션만, 그 세션 안에서도 관련 구간만 읽는다.
- 현재 세션 파일과 subagent·eval·테스트 세션은 건너뛴다.
- 세션이 3개 이상이면 subagent에 나눠 읽힌다. 원문은 subagent에 남고 본 스레드에는 아래 스키마의 결과만 올라온다. 세션이 1~2개면 직접 읽는다.

세션마다 같은 스키마로 뽑는다. 주제, 사용자의 목표, 내린 결정, 열린 스레드, 막힌 곳과 사용자의 교정, 산출물(PR·이슈·브랜치·파일). 각 항목에 세션 파일명을 출처로 붙인다.

## 3. 대조한다

transcript에서 나온 PR·브랜치·파일을 git과 GitHub에서 확인한다. "PR 열었다"고 했는데 없으면 없는 것이다. "고쳤다"고 했는데 커밋이 없으면 미커밋 변경인지 사라진 것인지 구분한다. 되돌려진 커밋과 닫힌 PR은 실패한 시도로 기록해 다음 시도가 같은 곳에서 실패하지 않게 한다.

## 4. 브리프를 쓴다

한국어 개조식. 아래 순서와 상한을 지킨다. 넘치면 세부를 자르고 스레드는 자르지 않는다.

- **캡슐.** 최대 5줄. 이 작업이 무엇이고 전체가 지금 어디 있는가.
- **스레드.** 한 줄에 하나, 앞에 상태 태그 하나. `[merged #N]`, `[open PR #N]`, `[in flight <branch>]`, `[verified, uncommitted]`, `[reverted #N]`, `[planned, not started]`. 태그 없는 스레드는 끝나지 않은 것이다.
- **문제.** 최대 5개. 반복된 것만. 시도했다가 되돌린 것을 포함한다.
- **다음 행동.** 딱 하나. "로그 더 보기"가 아니라 "`E-017`과 `E-018`의 endpoint 분포 비교"처럼 대상이 특정된 것.

주장마다 출처를 붙인다. transcript는 세션 파일명, 저장소는 커밋·PR·이슈 번호, 기억 디렉터리는 파일 경로. 확인 못 한 것은 `확인 필요`로 표시하고 확인된 것처럼 쓰지 않는다. 공개 채널에 낼 때는 개인 정보와 비밀값을 지운다.
