# akbun 오늘 하루 iCalendar Recap

맥 내장 캘린더나 아이캘린더(.ics) 데이터에서 오늘 00:00~23:30 일정을 가져와 오늘 뭐 했는지 정리하는 스킬이다. 별도 파서 스크립트 없이 캘린더 내용을 직접 읽고 판단한다. 출력은 문장이 아니라 PPT 슬라이드처럼 짧은 단답형 숫자 리스트다.

## 일정 가져오기

아래 순서로 시도한다. 하나가 성공하면 다음 단계로 넘어가지 않는다. 캘린더 데이터 없이 내용을 지어내지 않는다.

1. macOS에서 `icalBuddy`가 설치되어 있으면 사용한다.

    오늘 일정을 제목·시간·장소만 뽑는 명령이다.

    ```bash
    icalBuddy -nc -b "" -iep "title,datetime,location" eventsToday
    ```

2. `icalBuddy`가 없으면 macOS 캘린더 로컬 캐시의 `.ics` 파일을 직접 읽는다.

    오늘 날짜의 DTSTART를 가진 이벤트 파일을 찾는 명령이다(`YYYYMMDD`는 오늘 날짜로 치환).

    ```bash
    grep -l "DTSTART.*YYYYMMDD" ~/Library/Calendars/*.calendar/Events/*.ics 2>/dev/null
    ```

    - 찾은 파일들을 읽고 VEVENT의 SUMMARY, DTSTART, DTEND, LOCATION, STATUS, RRULE을 직접 해석한다.
    - 권한 오류(Operation not permitted)가 나면 터미널 앱에 "전체 디스크 접근" 권한이 필요하다고 안내하고 3번으로 넘어간다.

3. 위가 안 되면(권한 문제, macOS가 아님) 사용자에게 `.ics` 파일 경로나 캘린더 구독 URL(예: Google Calendar 비공개 iCal 주소, iCloud 공개 캘린더 주소)을 물어보고, 받은 원문을 읽어 직접 해석한다.

    URL이면 아래처럼 원문을 가져온다.

    ```bash
    curl -sL "<ICS_URL>"
    ```

## .ics 해석 규칙

원문을 직접 읽을 때 다음을 지킨다.

- 오늘 00:00~23:30에 걸치는 일정만 남긴다. 23:30 이후 시작 일정은 제외한다.
- `DTSTART;VALUE=DATE`(날짜만)는 종일 일정으로 본다.
- UTC(`...Z`)나 다른 TZID 시각은 사용자 로컬 시간대로 환산한다.
- `RRULE` 반복 일정은 규칙상 오늘이 발생일인지 판단해서 포함한다(EXDATE에 오늘이 있으면 제외).
- `STATUS:CANCELLED` 일정은 제외한다.
- 이어지는 줄(줄바꿈 후 공백으로 시작)은 앞 줄에 붙은 내용이다(RFC 5545 folding).

## recap 다듬기

- 시간 순서대로 정렬한다(종일 일정이 맨 앞).
- 같은 일정의 중복 표기, 불필요한 접두어(예: "[회의]", "Re:")를 정리한다.
- 일정 제목을 단답형 구절로 압축한다. 문장 금지, 조사·서술어 최소화.
- 내용을 추측해서 덧붙이지 않는다. 캘린더에 있는 정보(제목, 시간, 장소)만 사용한다.

## 출력 형식

항상 이 구조를 따른다.

```markdown
## 오늘 한 일 (YYYY-MM-DD, 00:00~23:30)

1. HH:MM~HH:MM 항목명
2. HH:MM~HH:MM 항목명 (장소)
3. 종일 — 항목명
```

- 숫자 리스트로만 정리한다.
- 한 항목은 한 줄, 단답형. 예: "10:00~11:00 팀 주간회의", "점심 — 팀 회식".
- 종일 일정은 시간 대신 `종일 —`로 표기한다.
- 일정이 없으면 "오늘 캘린더 일정 없음" 한 줄만 출력한다.
- 요청이 있을 때만 마지막에 한 줄 총평(예: "회의 3건, 개인 일정 1건")을 추가한다.

## 예시

Input: 오늘 일정 — 09:30 스탠드업(30분), 12:00 점심 약속(강남), 14:00~16:00 프로젝트 리뷰, 종일 일정 "재택"

Output:

```markdown
## 오늘 한 일 (2026-07-27, 00:00~23:30)

1. 종일 — 재택
2. 09:30~10:00 스탠드업
3. 12:00~13:00 점심 약속 (강남)
4. 14:00~16:00 프로젝트 리뷰
```
