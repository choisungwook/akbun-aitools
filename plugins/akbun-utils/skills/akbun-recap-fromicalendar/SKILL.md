# akbun 오늘 하루 iCalendar Recap

아이캘린더(.ics) 데이터에서 오늘 00:00~23:30 일정을 가져와 오늘 뭐 했는지 정리하는 스킬이다. 출력은 문장이 아니라 PPT 슬라이드처럼 짧은 단답형 숫자 리스트다.

## 입력

`.ics` 파일 경로 또는 구독 URL이 필요하다.

- 사용자가 경로/URL을 주면 그대로 사용한다.
- 없으면 `.ics` 파일 경로나 캘린더 구독 URL(예: Google Calendar의 비공개 iCal 주소, iCloud 공개 캘린더 주소)을 물어본다.
- 캘린더 데이터 없이 내용을 지어내지 않는다.

## workflow

1. 오늘 일정을 가져온다.

아래 명령으로 오늘 00:00~23:30 사이 일정을 JSON으로 얻는다.

```bash
python3 scripts/fetch_today_events.py "<ICS_PATH_OR_URL>"
```

- 다른 날짜를 요청하면 `--date YYYY-MM-DD`, 다른 종료 시각을 요청하면 `--end HH:MM`을 붙인다.
- 스크립트는 종일 일정, 반복 일정(DAILY/WEEKLY/MONTHLY/YEARLY), 취소된 일정 제외를 처리한다.
- 스크립트 실패 시(네트워크, 형식 오류) 오류 내용을 알려주고 `.ics` 원문 일부를 확인해 원인을 짚는다.

2. 일정을 recap 항목으로 다듬는다.

- 시간 순서대로 정렬한다(종일 일정이 맨 앞).
- 같은 일정의 반복 표기, 불필요한 접두어(예: "[회의]", "Re:")를 정리한다.
- 일정 제목을 단답형 구절로 압축한다. 문장 금지, 조사·서술어 최소화.
- 내용을 추측해서 덧붙이지 않는다. 캘린더에 있는 정보(제목, 시간, 장소)만 사용한다.

3. 아래 형식으로 출력한다.

## 출력 형식

항상 이 구조를 따른다.

```markdown
## 오늘 한 일 (YYYY-MM-DD, 00:00~23:30)

1. HH:MM~HH:MM 항목명
2. HH:MM~HH:MM 항목명 (장소)
3. 종일 — 항목명
```

- 숫자 리스트로만 정리한다.
- 한 항목은 한 줄, 단답형. 예: "10:00~11:00 팀 주간회의", "점심 — 팀 회식".
- 종일 일정은 시간 대신 `종일 —`로 표기한다.
- 일정이 없으면 "오늘 캘린더 일정 없음" 한 줄만 출력한다.
- 요청이 있을 때만 마지막에 한 줄 총평(예: "회의 3건, 개인 일정 1건")을 추가한다.

## 예시

Input: 오늘 일정 — 09:30 스탠드업(30분), 12:00 점심 약속(강남), 14:00~16:00 프로젝트 리뷰, 종일 일정 "연차 아님/재택"

Output:

```markdown
## 오늘 한 일 (2026-07-27, 00:00~23:30)

1. 종일 — 재택
2. 09:30~10:00 스탠드업
3. 12:00~13:00 점심 약속 (강남)
4. 14:00~16:00 프로젝트 리뷰
```
