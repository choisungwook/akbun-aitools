# 정적 그림체는 skill이 아니라 디자인 토큰이다

Scope: akbun-draw / akbun-draw-explainer-svg

## Decision

16:9 정적 SVG의 그림체는 `akbun-draw-explainer-svg` skill 하나가 라우팅하고, 그림체마다 `styles/<짧은 이름>.json` 디자인 토큰 하나로 정의한다. 토큰은 색·선·글꼴·효과·여백만 고정하고 구도는 고정하지 않는다. 모션·영상 스타일과 이미지 생성 프롬프트 스타일은 기존대로 skill 하나씩이다.

## Reason

처음에는 그림체마다 skill을 만들었다(`akbun-draw-style-tech-minimal` 등 3개). 캔버스·자막 영역·여백·검수 규칙이 세 SKILL.md에 중복됐고, 구도 문장("흐름은 한 방향")이 스타일 규칙에 섞여 들어가 두 모델 시험에서 응답 흐름을 생략하는 결과가 나왔다. 토큰으로 바꾸면 공통 규칙은 라우터 한 곳에, 그림체는 JSON 한 파일에 있고, 검사 스크립트 하나가 모든 토큰을 읽어 색·글꼴·여백·중심을 같은 기준으로 검사한다. 트레이드오프는 skill 이름 규칙(끝에 스타일 단어 하나)과 어긋나 보인다는 것과, 토큰 JSON이 SKILL.md보다 발견성이 낮다는 것이다. 그래서 AGENTS.md 플러그인 변경 규칙과 리뷰 지침에 토큰 추가 절차를 적었다.
