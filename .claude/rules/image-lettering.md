# 이미지 글자 규칙

## 적용 범위

- 이미지 생성 모델로 만드는 그림(만화 대사·효과음·컷 번호, 제목, 라벨 등)에 들어가는 모든 글자에 적용한다.
- 편집용 SVG(Figma/Canva에서 글자를 고칠 `text`)와 SVG를 렌더한 그림은 대상이 아니다. 그쪽은 AGENTS.md의 SIL OFL 글꼴 규칙을 따른다.

## 규칙

- 글자는 폰트로 얹지 않는다. 이미지 생성 모델이 그림의 일부로 직접 쓴다.
- 폰트 파일을 받거나 설치하지 않고, Pillow·SVG `<text>`로 그림 위에 글자를 합성하지 않는다.
- 프롬프트에 폰트 이름(상용·OFL 모두)과 `font`·`typeface` 같은 말을 쓰지 않는다. 글씨 모양은 획으로 묘사한다(예: "그림과 같은 펜으로 쓴, 굵기가 고른 둥근 손글씨 획").
- 프롬프트에는 "주어진 글자를 철자 그대로, 다른 글자 없이"를 늘 넣는다.
- 이미지 모델이 한글을 틀리기 쉬우므로 글자는 짧게 둔다. 틀리면 같은 프롬프트로 다시 생성하고, 계속 틀리면 문구를 줄인다.
- 근거 예시: `.claude/commands/repo-make-titleskillfromassets.md`, `plugins/akbun-draw/skills/akbun-draw-template-cartoon/`.
